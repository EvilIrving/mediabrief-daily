Docker Agent is an open-source tool from Docker for building and running AI agents. Docker describes it as being to AI agents what docker run is for containers. You describe an agent in a YAML file, with the model it uses, its instructions and the tools it's allowed to use, and then you run it with one command. Docker Agent handles the agent loop for you: it calls the model, runs the tools, feeds the results back and repeats until the job is done.

So this is an example of a complete agent. The model line can point at OpenAI, Anthropic, Gemini, OpenRouter, or a local model through Docker Model Runner. You can also give it some tools, which come from the toolsets section. That covers built-ins like file access and shell commands, and any MCP server you want to hook up. An agent can also have sub-agents, so one coordinator can hand work off to specialists.

Docker's own docs actually have a good comparison here. On the left is the Python code you'd normally write to make a model call tools in a loop, and on the right is the same agent written for Docker Agent. Look how much cleaner it is on the right side.

There are also three big things that are really cool about Docker Agent. The first is that agents become configuration. You can version them, review them in pull requests, and swap the model by just changing one line. The second is distribution. You can push an agent to Docker Hub or any other OCI registry, and anyone can run it with docker agent run and the image name, the same way you share a container. And the third is that agents can run as services. With one command, an agent becomes an HTTP API, an MCP server, or an A2A server that other agents can call. That third one we're actually going to see in action later in this video.

If you're on Docker Desktop 4.63 or newer, Docker Agent is already installed by default. Otherwise, you can install it with Homebrew and symlink it into the Docker CLI plugins folder, so it runs as docker agent.

Here's the smallest agent you can write: a model, a description, and an instruction. I just have to run docker agent run agent.yaml, and I get a terminal UI where I can talk to it.
