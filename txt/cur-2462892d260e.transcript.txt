缩放定律是深度学习中最关键的经验发现之一。这一观察在形式上很简单：当我们扩大模型规模 $N$、数据集规模 $D$ 和算力 $C$ 时，训练损失 $L$ 会按照幂律曲线可预测地下降，在双对数坐标图上表现为一条直线。我们可以把缩放定律看作一个描述算力、损失、模型规模和数据之间关系的框架；其核心在于如何在 $N$ 和 $D$ 之间最优地分配宝贵的算力。

这种可预测性让缩放定律在实践中极具价值。一种常见的工作流程是：在少量小规模训练上拟合缩放定律，然后外推，估算更大模型所需的 token 量和算力。

| 符号 | 说明 |
|---|---|
| $N$ | 模型规模，以参数量衡量。 |
| $D$ | 训练数据集规模，通常以 token 数衡量。 |
| $C$ | 以 FLOPs 计的训练算力。一个有用的近似是 $C \approx 6ND$（Kaplan 等 2020），其中 $2ND$ 对应前向传播，$4ND$ 对应反向传播。 |
| $E$ | 不可约损失 |
| $L, \hat{L}(.)$ | 测试损失 / 测试损失预测函数；也可以指训练损失，因为二者高度相关。 |
| $\epsilon$ | 泛化误差。 |

# 早期：机器学习损失的可预测性

在缩放定律成为主流概念之前，泛化误差随规模变化的可预测性就已经被研究过了。

Amari 等（1992）用贝叶斯方法和退火近似推导出四类学习曲线：

1. 确定性学习算法、无噪声数据、唯一解：$\epsilon \sim c \cdot D^{-1}$，其中 $c$ 是某个常数。
2. 确定性学习算法、无噪声数据、多个等价解：$\epsilon \sim c \cdot D^{-2}$；每个新数据点都让学习更快，因为模型只需学到参数的最优流形，而不必找到唯一的解点。
3. 确定性学习算法、有噪声数据：$\epsilon \sim c \cdot D^{-1/2}$；数据中的噪声让学习更难。
4. 随机性学习算法、有噪声数据：$\epsilon \sim c \cdot D^{-1} + E$；这里的不可约损失 $E$ 是随机学习器无法进一步降低的残差，比如模型在大数据上容量耗尽时。四类学习曲线都服从幂律：

〔补〕$\epsilon \sim c \cdot D^{\alpha} + E$

其中 $E$ 可以为 0，$\alpha = -2, -1, -1/2$。尽管他们的理论设定基于一个简化的二分类任务，但它为构建经验性的机器学习损失预测模型指出了一个有用的方向。

Hestness 等（2017）最早的经验研究之一解释了泛化误差、模型规模和数据之间的关系。对于给定的训练数据规模，他们通过网格搜索找出最佳拟合的模型规模，然后绘制损失随训练数据集规模的变化。在深度学习的四个不同领域（神经机器翻译、图像分类、语言建模和语音识别）中，观察到一个反复出现的模式：

- 泛化误差随一系列因素（如数据规模）按幂律缩放。
- 模型改进会平移误差曲线，但似乎不影响幂律指数。
- 有趣的是，架构会改变幂律拟合的偏移量（$E$），但不改变指数（$\alpha$）。幂律的斜率似乎是问题领域的属性，而不是模型架构的属性。
- 拟合规模为 $D$ 的数据集所需的模型参数量 $N$ 也按幂律缩放。

一张概念示意图把学习曲线分为三个阶段。在小数据区，学习信号不足，模型表现只比随机猜测略好。在中间（“幂律区”），我们观察到损失、数据和模型规模之间的幂律关系。最后的不可约误差区可以归因于数据中的噪声等因素。

Rosenfeld 等（2020）更进一步，尝试在一系列不同的架构（ResNet、WRN、LSTM、Transformer）和优化器（Adam、SGD 变体）上，把误差建模为模型规模 $N$ 和数据规模 $D$ 的联合函数。他们在经验上观察到，固定一个轴时，误差在另一个轴上按幂律衰减：

〔补〕$L(N) \approx A N^{-\alpha} + E_N$，$L(D) \approx B D^{-\beta} + E_D$

二者可以合并为一个联合形式：

〔补〕$\hat{L}(N, D) = E + \dfrac{A}{N^{\alpha}} + \dfrac{B}{D^{\beta}}$

其中 $A > 0, B > 0, \alpha \geq 0, \beta \geq 0$ 是标量常数，$E$ 既不依赖于 $N$ 也不依赖于 $D$。

因此，他们可以构建一个以简单参数化函数为形式的预测模型，参数为 $\boldsymbol{\theta} = \langle A, B, E, \alpha, \beta \rangle$，只需在一组较小的训练配置（$(D, N)$ 小于某些阈值）上训练，就能预测 $(D, N)$ 大于某些阈值时的期望损失。

旁注：这些早期工作依赖经典学习理论的直觉，比如把 VC 维（模型能够打散的最大点集的基数）作为容量的代理指标，但在现代深度学习工作中，VC 维往往太粗糙，无法解释实际行为，而经验幂律被证明比理论给出的最坏情况界限要干净和实用得多。

# 数据无限区域中的缩放定律

## Kaplan 等的缩放定律

Kaplan 等（2020）让缩放定律的概念在语言建模界流行起来。他们发现，交叉熵测试损失 $L$ 在许多个数量级上，分别随模型规模 $N$（不含嵌入层）、数据集规模 $D$ 和训练算力 $C$ 按幂律缩放。这些发现与上一节的早期工作一致，但 Kaplan 等以 Transformer 语言模型为重点，在更大规模上做了经验实验，把这一概念形式化：模型规模从 768 到 15 亿个非嵌入参数，数据集规模从 2200 万到 230 亿个 token。（原文写作“768M”，据 Kaplan 等论文应为 768 个参数。）论文中所有训练都使用了 3000 步线性预热、随后余弦衰减到零的学习率调度。

主要发现列表：

- 损失 $L$ 分别随 $N$、$D$ 和 $C$ 按幂律缩放；要获得最佳性能，三者必须同步扩大。
- 训练曲线遵循可预测的幂律，其参数大致与模型规模无关。
- 更大的模型样本效率更高，即与小模型相比，它们用更少的优化步数和更少的数据点就能达到给定损失。
- 架构细节（宽度、宽深比等）远不如纯粹的规模重要。
- 训练损失与测试损失正相关。（听起来很平常，但这是预训练工作的基础。另一方面，预训练损失的改进能否迁移到后训练评估，需要单独研究。）
- 在固定算力预算下，训练一个非常大的模型并在*收敛之前*停止，比把一个较小的模型一直训练到收敛更高效。**这一发现正是 Chinchilla 缩放定律（下一节）持不同意见之处：Kaplan 等高估了最优模型规模，因为他们拟合出的指数偏大。**

他们用一个方程概括了对 $N$ 和 $D$ 的联合依赖：

〔补〕$L(N, D) = \left[\left(\dfrac{N_c}{N}\right)^{\frac{\alpha_N}{\alpha_D}} + \dfrac{D_c}{D}\right]^{\alpha_D}$

这一形式的一个好处是，过拟合的程度（即模型复杂或数据少）主要取决于比值 $N^{\alpha / \beta} / D$，这表明数据需要按特定比例随模型规模增长，才能避免训练受数据限制。

最有影响力、事后看也最具争议的结论是算力最优分配。Kaplan 等发现 $N_\text{opt} \propto C^{0.73}$，并得出模型规模应该比数据集规模增长得更快的结论。具体来说，算力每增加 10 倍，他们建议模型规模扩大约 5.5 倍，而训练 token 只增加约 1.8 倍。Chinchilla 论文后来推翻了这一建议，认为它会让大模型严重*训练不足*。

Kaplan 等的另一个有用分析，是根据 $D$ 和 $N$ 近似估算所需的训练 FLOPs。每次乘加运算计为约 2 FLOPs。

在 $d_\text{attn} = d_\text{model} = d_\text{ff}/4$ 的标准配置下，不把嵌入层计入 $N$，每个 token 的前向计算量为：

〔补〕$C_\text{forward} \approx 2N + 2 n_\text{layer} n_\text{ctx} d_\text{attn}$，其中 $N \approx 2 d_\text{model} n_\text{layer}(2d_\text{attn} + d_\text{ff}) = 12 n_\text{layer} d_\text{model}^2$；上下文相关项在 $d_\text{model}$ 远大于 $n_\text{ctx}/12$ 时可忽略，故约为 $2N$

然后，我们把反向传播的 FLOPs 计为前向传播的两倍，因为反向传播要做两次矩阵乘法，分别计算对输入激活和对权重的梯度。因此，每个 token 的训练 FLOPs 总计约为 $6N$，在 $D$ 个 token 上训练的总 FLOPs 为 $C \approx 6ND$。

## Chinchilla 缩放定律

Chinchilla 论文（Hoffmann 等 2022）以更严谨的实验设计，研究了在*固定*算力预算 $C$ 下，最优模型规模 $N$（总参数，*包含*嵌入层）与 token 数 $D$ 之间的关系，得出了与 Kaplan 等有所不同的答案。

核心问题是：在约束 $\text{FLOPs}(N, D) = C \approx 6ND$ 下，资源分配的最佳策略是什么？换句话说，当我们只有有限的 FLOPs（一定数量的 GPU 运行一定时间）时，应该如何在更多数据 token 和更多模型参数之间取舍？

Chinchilla 论文提出了三种设计精巧的缩放定律拟合方法。

经验实验扫描了 400 多个模型，规模从 7000 万到超过 160 亿参数，训练 token 从 50 亿到 5000 亿。实验假设每个训练 token 都是独特的（无限数据情形）。所有训练都使用在训练周期内衰减 10 倍的余弦学习率调度。扫描不同的模型规模，就勾勒出了算力最优前沿。

### 方法一：固定模型规模，改变 token 预算

对每个参数量 $N$，用不同的 token 预算训练多次，记录每个 FLOP 预算 $C$ 下达到的最小损失。

### 方法二：等算力（IsoFLOP）曲线

固定一个算力预算 $C$，绘制最终损失随参数量 $N$ 的变化。每条等算力曲线在对数空间中大致是一条抛物线，其最低点标出了该算力预算下的最优模型规模。然后在不同预算上重复，就在图中勾勒出一条幂律直线。

### 方法三：参数化拟合

直接拟合与 Rosenfeld 等（2020）相同的参数化函数：

〔补〕$\hat{L}(N, D) = E + \dfrac{A}{N^{\alpha}} + \dfrac{B}{D^{\beta}}$

通过在约束 $\text{FLOPs}(N,D) = C \approx 6ND$ 下最小化 $\hat{L}(N, D)$，我们实际上可以得到最优 $N_\text{opt}(C), D_\text{opt}(C)$ 的闭式近似。

首先把表达式化简为只含 $N$：

〔补〕代入 $D = C/(6N)$，得 $\hat{L}(N) = E + A N^{-\alpha} + B\left(\dfrac{C}{6N}\right)^{-\beta}$；令导数为零，解得 $N_\text{opt}(C) = G\left(\dfrac{C}{6}\right)^{\frac{\beta}{\alpha+\beta}}$，$D_\text{opt}(C) = G^{-1}\left(\dfrac{C}{6}\right)^{\frac{\alpha}{\alpha+\beta}}$，其中 $G = \left(\dfrac{\alpha A}{\beta B}\right)^{\frac{1}{\alpha+\beta}}$

当 $\alpha \approx \beta$ 时，模型规模和训练 token 应以相同速率扩大。

为了求得最优的 $\boldsymbol{\theta} = \langle A, B, E, \alpha, \beta\rangle$，Chinchilla 论文采用了 Huber 损失（对离群点稳健；$\delta=10^{-3}$）和 L-BFGS 算法（适合参数较少的曲线拟合）。

Chinchilla 通过三种相互补充的方法得出答案，而这三种方法的最终结果彼此一致，这正是其结论相当有说服力的部分原因。

Chinchilla 论文关于大多数大模型（在当时，约 2022 年）训练不足的论断，得到了一个著名演示的支持：在与 Gopher（Rae 等 2021；2800 亿参数，3000 亿 token 预算）相同的算力预算下，他们训练了 Chinchilla（700 亿参数，1.4 万亿 token 预算），这个模型小了 4 倍，但训练的 token 多了约 4 倍，结果全面超越了 Gopher。

## 调和 Kaplan 与 Chinchilla

Chinchilla 缩放定律与 Kaplan 等的分歧如下：

- 不是“让模型比数据增长得更快”（$N_\text{opt} \propto C^{0.73}$），而是模型规模每翻一倍，训练 token 数也应翻一倍（$N_\text{opt} \propto C^{0.5}$）。
- 不是“训练一个大模型并在收敛前停止”，而是应该用更多数据训练一个更小的模型。

两篇论文仍然认同同一个基本原则，但在规模与 token 之间最优权衡点的位置上存在分歧。它们为什么分歧这么大？

**差异一：Kaplan 等主要在小模型上做实验。**
Kaplan 等主要在较小的模型上做实验，而 Chinchilla 论文的实验规模大了 10 倍以上。当我们在双对数空间中外推时，拟合上的微小差异可能导致巨大的差别（见玩具模拟）。

**差异二：对小模型而言，嵌入参数的计数很重要。**
在小参数区间，嵌入参数占总参数的比例不可忽略，因此是否计入它们很重要。Pearce 和 Song（2024）沿着这条思路做了详尽的分析。我们用 $N_{\setminus E}, C_{\setminus E}$ 表示不含嵌入层时的模型规模和算力，用 $N, C$ 表示计入全部参数的情况。

- Kaplan 等：$N^*_{\setminus E} \propto C^{0.73}_{\setminus E}$（不含嵌入）
- Chinchilla：$N^* \propto C^{0.50}$（总参数）

为了连接二者，他们拟合了总参数 $N_T$ 与非嵌入参数 $N_{\setminus E}$ 之间的关系，其中 $\omega$ 为某个常数：

〔补〕$N_T = N_{\setminus E} + \omega N_{\setminus E}^{1/3}$

这一形式有很好的性质：严格递增，且 $\lim_{N \to \infty} N = N_{\setminus E}$（因为 $\frac{N}{N_{\setminus E}} = 1 + \omega {N_{\setminus E}}^{- \frac{2}{3}}$，$\lim_{N_{\setminus E} \to \infty} \frac{N}{N_{\setminus E}} = 1$）。

## 为什么是幂律？

幂律在 AI 之外的许多领域都广泛存在，比如齐普夫定律、无标度网络、城市缩放定律以及许多其他复杂系统。反复出现的模式是：大事件罕见，小事件常见，而规模与频率之间的关系在双对数坐标下往往呈一条直线。

**为什么 LLM 的缩放定律也呈幂律形状？**

部分受到不同领域表现出不同指数（Hestness 等 2017）的启发，Sharma 和 Kaplan（2020）提出的一个早期解释假设：语言建模可以被看作在一个低维数据流形上做回归。更多的模型参数可以对数据流形做更精细的划分，从而带来更小的泛化误差。用最简单的话说，如果一个有效规模为 $N$ 的模型把一个 $d$ 维流形划分为 $O(N)$ 个区域，那么典型的线性分辨率按 $\sim N^{-1/d}$ 缩放。这与上面的缩放定律有着相似的幂律形式。这一理论在无限数据、欠拟合的情形下最为适用，但在现实中，估计数据流形的内在维度相当困难。

后来的一个假设（Michaud 等 2023，Brill 2024）认为，知识或技能是以离散的块（“量子化”）被学习的，而这些技能的频率分布服从幂律。模型先学会常见技能，后学会罕见技能，从而使损失呈现平滑的幂律衰减。

我在这里只列出了两种假设，但还有更多研究试图通过数据的谱尾、核特征值、自然语言统计规律或训练动态中的相变来解释幂律缩放的形状。

# 数据受限区域中的缩放定律

经典缩放定律假设实际上拥有*无限的独特数据*，没有重复，也没有多轮训练。随着模型规模大幅增长，我们正在耗尽足够的高质量独特 token。事实上，一些关于 AI 缩放还能持续多久的争论，正是围绕我们是否正在撞上“数据墙”展开的。

同样值得强调的是，$D$ 背后的数据集应当是已经清洗过的。预训练数据管线往往是一个有效预训练流程的重要组成部分，常见步骤包括去重（精确去重和模糊去重）、质量过滤、去除样板内容、安全过滤、个人身份信息/版权内容屏蔽、基准测试去污染，以及根据语言、质量、内容类型等对数据混合中的各组成部分进行精心的权重调整。即使两个数据集包含相同的 token 数 $D$，一个高质量数据集和一个充斥互联网垃圾内容的数据集，也可能产生截然不同的算力效率。

Hernandez 等（2022）的研究聚焦于一个受控版本：一个大部分独特、只有一小部分重复数据的数据集。从一个大数据集出发，数据混合中 90% 保持不重复，其余 10% 则替换为原始数据中一小部分的重复。通过训练一个 Transformer 模型 1000 亿 token，他们观察到一种双下降现象：测试损失随着重复数据被强调的程度，实际上可能先*变差*再变好，而且重复比例越大，这种效应越明显。

训练中段平坦或上升的趋势，可能是由于对重复数据的记忆。这种形状的学习曲线会让缩放定律的拟合不那么准确。他们还得出结论，重复数据会损害一些分布外（OOD）评估和下游微调。不过，他们的数据混合是以一种更像实验室的方式构建的，而现实世界数据中的重复往往更加微妙（例如不同数据有不同程度的重复、语义上的重复等）。

与其说数据重复会损害训练，我们更感兴趣的是：既然独特的高质量数据不是无限的，而我们很可能不得不在训练中重复数据，那么该如何拟合缩放定律？

Muennighoff 等（2023）研究的问题是：当模型训练受数据约束时，应该如何最优地分配算力。具体来说，他们在大约 400 个实验中经验性地研究了数据重复的影响，参数规模从 1000 万到 90 亿，数据规模最高达 9000 亿 token，最多训练 1500 轮。每一轮都重复使用完全相同的数据集，轮次之间打乱顺序，并在留出的测试集上评估。

关键的建模调整，是把总 token 数 $D$ 分解为两部分：(i) 独特 token 数 $U_D$，(ii) 重复次数 $R_D$（即轮数 - 1）。于是有 $D = U_D(1 + R_D)$。给定独特数据预算 $D_\text{uniq}$，按定义 $U_D = \min \{ D_\text{uniq}, D\}$，$R_D = (D / U_D) - 1$。他们用 Chinchilla 缩放定律找出拟合 $U_D$ 的最优模型规模 $U_N$，并通过重复定义多余的模型规模 $R_N = (N / U_N) - 1$。

然后，他们更新了 Chinchilla 的参数化拟合（方法三），用有效（打了折扣的）数据量 $D'$ 和模型规模 $N'$ 代替原始数量：

〔补〕$\hat{L}(N', D') = E + \dfrac{A}{N'^{\alpha}} + \dfrac{B}{D'^{\beta}}$，其中 $D' = U_D + U_D r_D\left(1 - e^{-R_D / r_D}\right)$

直觉是，一个 token 的价值会随着重复而*指数*衰减。在他们的建模中，每重复一次，该 token 会损失其剩余价值的 $(1 - 1/r_D)$ 比例，其中 $r_D$ 是一个可学习的“半衰期”参数。当 $R_D = 0$ 或 $R_D \ll r_D$ 时，我们恢复 $D' \approx D$。

一个对称的公式处理多余的模型规模，$N' = U_N + U_N r_N(1 - \exp(-R_N / r_N))$，体现了“较大的模型在重复数据上更快过拟合”以及“模型可能对其数据集而言过大”的想法。这个组成部分不那么直观，我也没能找到令人满意的解释，说明为什么模型规模需要以与重复数据如此对称的形式出现。Lovelace 等（2026）的后续工作改变了这一假设。

他们的经验拟合发现，*多余参数的价值比重复数据衰减得更快*，即 $r_N < r_D$，因此我们应该把更多资源分配给更多训练轮数，而不是更多模型参数。正如作者也指出的，这种建模的一个弱点是，它会显著低估失败模型（即损失在训练中途上升的模型）的最终测试损失，比如训练了 44 轮的模型。

最近，Lovelace 等（2026）用另一种方法重新审视了同一问题。Lovelace 等没有把过度参数化建模为有效模型规模的收益递减，而是显式地建模了模型规模 $\times$ 数据重复之间的相互作用。在经验上，他们训练了约 300 个模型，参数规模从 1500 万到 10 亿，独特 token 从 5000 万到 60 亿。

当他们针对固定的模型规模、在一系列数据重复水平上绘制拟合残差时，观察结果很直观：轮数越多，损害越大；而有趣的是，*较大的模型对重复更加敏感*。这暗示损失惩罚很可能同时是模型规模和数据规模的函数。

# 现实中拟合缩放定律的棘手之处

尽管形式简洁，但在实践中，缩放定律的拟合可能对一些看似琐碎的流程选择出奇地敏感，比如如何计算参数、如何对精度取整、如何对损失求和或取平均等等。

因为缩放定律只是在我们负担得起的（相对小、相对便宜的）模型上拟合的，而预测却要*外推*到大几个数量级的模型上。在这种设置下，看起来像舍入误差的选择，可能导致预测上的巨大差异。

同时，缩放定律的拟合假设唯一变化的因素是*规模*，这意味着模型架构、优化器、学习率调度、批量大小递增策略、数据混合、分词器以及其他设计选择都应保持不变。另一个潜在假设是，所有这些设置都应该经过了仔细调优，因为像训练不足这样的情况可能导致不同的结论。

Kaplan 等与 Chinchilla 结果之间的分歧，就是展示缩放定律拟合之棘手的一个例子。

第二个例子是一项后续分析，研究为什么 Chinchilla 的方法三与另外两种方法略有偏差。Besiroglu 等（2024）从 Hoffmann 等（2022）的图 4 中提取了原始的 $(N, D, L)$ 数据点，重新进行了方法三的参数化拟合。他们发现了几个具体问题：

- L-BFGS-B 最小化器中的损失尺度过高，原因是对各样本的 Huber 损失取了平均而不是求和，导致优化过早终止。在原始拟合和自助法（bootstrapping）中，损失最小化的过早停止都产生了不一致的估计，以及窄得不合理的置信区间。
- 报告的 $\alpha$ 和 $\beta$ 被四舍五入到 2 位小数，这让推导出的 $A, B$ 看起来比实际偏差更大。

## 玩具模拟

这里有一个由 ChatGPT 制作的玩具模拟小部件，旨在演示三种具体的失败模式。

我们假设真实函数为：

〔补〕$L(N, D) = 1.8172 + \dfrac{482.01}{N^{0.3478}} + \dfrac{2085.43}{D^{0.3658}}$

因此 $N_\text{opt} \propto C^{0.5126}, D_\text{opt} \propto C^{0.4874}$。这是 Besiroglu 等（2024）的估计。

该模拟绘制损失预测 $\hat{L}$ 随数据集规模 $D$ 的变化，并提供一组滑块来展示：

- 损失精度：把损失从高位小数舍入到低位小数，可能改变拟合出的参数值。
- 损失噪声：仅以千分之一损失（0.001）为单位的倍数扰动损失值，就会得到不同的拟合。
- 拟合区间敏感性：只拟合小模型、只拟合中等模型或拟合所有模型，会得到不同的表观缩放定律。
