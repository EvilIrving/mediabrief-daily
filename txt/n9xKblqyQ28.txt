YC Paper Club 举行“Harness 之夜”技术研讨，系统梳理了智能体外层运行框架（Harness）的历史演进与底层架构，论证了在相同基座模型权重下，外层循环、工具沙箱、分层记忆与动态评估框架对智能涌现的决定性作用。

## 一、Harness 的决定性价值与 ARC-AGI 突破

在相同的预训练模型权重下，外层 Harness（涵盖执行循环、工具沙箱、记忆持久化、子 Agent 调度与上下文动态管理）的设计优劣能够拉开决定性的性能代差。在评估流动智力与快速适应未知任务的 ARC-AGI 权威基准测试中：
- 裸 Claude Opus 模型的基线通过率仅约 30%；
- 接入专用 Harness 的 Prime Agent 系统将得分飙升至 95.5%；
- NVIDIA 的自研框架方案则达到了 100% 满分。
这彻底打破了“Harness 仅是外围套壳与提示词微调”的工程偏见，确立了其作为智能涌现核心驱动力的研究地位。

## 二、Harness 架构演进史：从静态循环到自适应进化

系统梳理了 Harness 自大模型诞生以来的技术演化代际：
1. 基础单循环：GPT-2 时代的简单 EOS 终止判断生成循环；
2. 线性引导：Few-shot 上下文示例与链式思维（CoT）推理；
3. 工具闭环：WebGPT 与 Toolformer 引入外部 API 检索调用；
4. 状态增删改查：MemGPT 实现对上下文窗口的主动读写与持久化管理；
5. 技能库沉淀：Voyager 确立了可沉淀、可复用的模块化技能资产库（Skill）；
6. 动态自愈：ReAct 循环、多 Agent 拓扑协作与递归语言模型（RLM）；
7. 自主进化 Harness：以 DSPy 遗传算法调优提示词为代表，演进至类似 Darwin 机器直接在运行时重构 Harness 源码，乃至在测试阶段（Test-time）实施在线权重更新。

## 三、Prime Agent：递归语言模型与冯·诺依曼计算隐喻

普林斯顿大学研究团队阐述了 Prime Agent 的底层架构设计：
- 冯·诺依曼架构映射：裸模型类似于图灵机的原始纸带，而 Harness 将其升维为具备外部存储读写能力的现代冯·诺依曼计算机；
- 分层存储管理：区分活跃上下文压缩（Compaction）与外部冷存储，引入 Python REPL 沙箱让变量与复杂状态常驻内存运行，避免无效 Token 上下文膨胀；
- 持久化子会话：子 Agent 抽象为具备独立上下文栈的轻量级实体，支持随时挂起与唤醒；
- 垃圾回收机制：周期性对过期技能、提示词冗余与无效记忆实施自动化剪枝与精炼。

## 四、评测平台期与真实闭环约束

设计先进 Harness 的核心准则在于赋予模型足够泛化的表达能力，而非将其锁死在“规划-执行-反思”的僵化线性流程中。在评估系统上限时，必须严密监测“性能平台期”（追加计算 Token 带来边际收益归零的拐点）。同时，测试环境必须配置严格的受控沙箱隔离，防范模型在自主演进中利用未隔离环境漏洞发生评测作弊，确保生成的推理轨迹能够真实反哺下一代基座模型的后训练优化。
