OpenAI 在年度开发者大会（DevDay）上集中发布了涵盖常驻个人智能体、团队协作工作区、高性价比模型与开发者基础设施在内的全栈产品矩阵，系统展现了从模型 API 向常驻 Agent 平台的战略跃迁。

## 一、常驻 Agent 载体：Dots 与 ChatGPT Spaces

发布会的旗舰产品为 Dots：具备高任务处理能力、全天候常驻运行的个人 AI 智能体，配合新推出的多智能体协作工作区 ChatGPT Spaces。Spaces 颠覆了单人单轮对话交互，支持团队成员与多个 Dot 在统一画布页面内协同编写规划、生成图像、检索数据与构建应用；现场演示了当成员在反馈频道抛出 Bug 报告时，Dot 能够自动接管环境复现并在 GitHub 上提交修复 PR 的闭环能力。

Spaces 引入了全新的团队协同心智：团队成员拥有各自专属的 Dot，不同 Dot 在共享画布中实时交换上下文。例如设计团队的 Dot 可负责生成界面渲染图，工程团队的 Dot 同步拉起代码沙箱验证交互逻辑，实现了人与人、人与 Agent、Agent 与 Agent 之间的三维网状协作。

## 二、模型矩阵与超低延迟推理

模型与计算层面推出了核心升级：
1. GPT-6.1 Sol：主打极致性价比与高工程能力，以接近前代旗舰 Astra 的智能基线，将 API 价格压缩至前者的五分之一，针对规模化代码构建进行了端到端优化；
2. Ultrafast 档位：将推理吞吐提升至基准档位的 8 倍，达到每秒 300 Token 的流式输出速度。在现场火箭生成渲染任务的对比中，Ultrafast 档位瞬间完成三维模型编译升空，而标准档位仍在编译准备，为高并发交互与快速 Agent 迭代提供了关键算力支撑；
3. Decisions API：针对 Luna 模型开放亚秒级决策端点，通过在预设选项空间内执行高确定性受限推理，大幅缩短复杂流程的响应耗时。

## 三、开发者平台、云端环境与商业化闭环

面向开发者生态推出了系列企业级基础设施：
- Codex Cloud 与安全扫描：Codex 全面云端化，支持跨设备无缝接续编程任务；Codex Security Cloud 持续对代码库执行漏洞扫描并自动准备修复方案；
- Agents API 公测：内置标准 Agentic Loop、长周期托管运行时、持久化记忆库、多 Agent 路由协调及系统级电脑屏幕操作（Computer Use）能力；
- Private Intelligence 数据隔离：强化企业级数据管控，保障私有数据在 Agent 编排过程中的零保留与零训练泄露；
- 商业化与分发渠道：推出“Sign in with ChatGPT”身份集成方案，允许终端用户将其 ChatGPT 个人订阅额度无缝携带至第三方 SaaS 应用；上线 OpenAI Marketplace，首批接入逾 30 家企业级合作方，构建基于 OpenAI 账户额度的采购与分发闭环。现场还演示了多模态旗舰 Astra 仅凭一张手绘草图即可自主生成 3D 太空游戏并完成交互通关。
