这一期 Darknet Diaries 讲的是 2008 年 Windows 漏洞 MS08-067：微软如何从自己的崩溃遥测里把它揪出来、为何带外发补丁，以及几个月后 Conficker 如何把它变成史上最大蠕虫之一。主持人 Jack Rhysider 采访的是微软的 John Lambert——他曾在可信计算组做了十年安全，日常工作就是把安全研究那套方法嵌进微软各产品的开发流程，而不只盯着 Windows 或 Office。

故事从补丁星期二和公告编号讲起。MS07-029、MS08-067 这类名字里，前两位是年份，后三位是当年公告序号。公告按产品归组，并标严重、重要、中等。2008 年多数人还在用 Windows XP（Vista 采用率不高），代码量约四千五百万行，bug 几乎不可能清零。前一年的 MS07-029 是 Windows DNS 的零日：客户拿着野外攻击工具找上门，MSRC 验证后出了公告。John 当时在看 Windows 错误报告（WER，内部也叫 Dr. Watson）里 DNS 相关的崩溃，发现那些本不该出现的崩溃其实都是攻击——如果能更早从每天数百万、每月逾十亿条崩溃里把“针”挑出来，本可以比客户来报更早发现。Vista 时代可信计算侧还靠静态分析改过约十万处、靠 WER 再揪出约五千个漏网问题；John 想的是把同一套遥测当成安全传感器。

利用常在 Word 打开文档、浏览器加载页面这类路径失败，失败模式也有规律（比如英文版利用打到中文版上会歪），可以把漏斗从十亿收到数千。2008 年 9 月 25 日，一份 Service Host 崩溃引起他注意。表面像旧的 MS06-040 余波，但栈上带着利用痕迹，还有他从未在该漏洞上见过的“寻蛋”手法——先把载荷送进内存，真正触发时只用极小一段代码去搜，以绕过缓冲区装不下完整指令的约束。更关键的是，报告里的 netapi32 版本已经打满补丁，不可能是旧洞。他几乎可以肯定这是新零日，却一时定位不到出错代码，只好把案子推给 MSRC 工程侧的 Andrew Roths。Andrew 起初怀疑是误报、不愿从已确认漏洞上抽人，仍接过来查了几天，最后带着“找到了、而且很严重”的表情进门：漏洞可远程代码执行，且可蠕虫化，影响当时已发布的每个 Windows 版本。

两人立刻拉响危机响应，找到危机经理 Phillip，搭起跨部门电话桥：工程修洞、反恶意软件做特征、客服与赛门铁克、McAfee 等伙伴同步。John 继续盯崩溃桶做态势感知——攻击从马来西亚扩到日本、新加坡，载荷连向日本同一 IP，更像有组织的定点利用而非已失控的蠕虫；他只看见失败样本，不知道成功一次对应多少次崩溃。补丁很快做好。发不发带外成了权衡：补丁星期二 IT 最有准备，但野外已有利用；一公开又会有人逆向补丁跟风。他们选择带外，于是有了 MS08-067。公开当天，原先那套指纹的攻击消失；随后先是安全公司的复现崩溃，再过几天是僵尸网络把洞收作传播手段。Windows Update 首周给约四亿台机器打上补丁，约占当时全球约十亿台 Windows 的四成。

真正的风暴在十二月：Conficker 把 MS08-067 收作主传播通道（另有 U 盘、文件共享等路径），最终波及一百九十多国、感染约一千万台，成了有史以来最大的蠕虫之一。John 的教训是：厂商出补丁只是一半，没打上的那 1% 仍是数百万台。节目后半对照了后来的 EternalBlue / MS17-010 / WannaCry——影子经纪人泄出前 NSA 曾提前知会微软——以及 NSA 偶发向微软报洞（含节目录制前不久的 Windows 10 加密 API 问题）时那种别扭关系，并强调没有证据表明 MS08-067 本身来自 NSA。Conficker 作者一度成谜：感染后长期不接指令，2009 年 4 月 1 日的“大日子”也无事发生。微软联合 Verizon、Neustar、赛门铁克、F-Secure、Shadowserver 等组成“微软小集团”围堵，悬赏 25 万美元。FBI 动过乌克兰三人组（Sergey、Yevgen、Dmytro）与瑞典人 Mikael 等线索；Mikael 因恐吓软件诈骗获刑约两年，与 Conficker 的直接关系在公开记录里并不清晰。Mark Bowden 的《Worm》记录了这段猫鼠戏。时至今日仍有约四十万台机器带毒；该编号在伦理黑客培训里仍常被当作历史案例提及，但生产环境中已少见。

收尾回到开头的道路安全比喻：发现漏洞、发补丁是厂商的职责，把补丁打到每一台机器上则是整条链条的事。医院、电厂一类环境不能随便升级，说明“尽快更新”说起来简单、做起来难；但就个人与多数企业而言，保持系统与软件在最新修复版本，仍是最有效的自我防护之一。音乐全部由 Breakmaster Cylinder 制作。
