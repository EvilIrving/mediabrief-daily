写给普通人的代数效应（Algebraic Effects for the Rest of Us） ｜ Overreacted, Dan Abramov ｜ 文章 ｜ https://overreacted.io/algebraic-effects-for-the-rest-of-us/

Dan Abramov 用 JavaScript 读者能懂的方式介绍代数效应。他读学术论文一直没弄懂，直到 React 团队的 Sebastian 反复拿它当 React 内部设计的心智模型。他强调用 React 完全不必懂它，这是研究阶段的语言特性，了解它有点像 1999 年去思考 async/await。

他从 try/catch 讲起：错误会穿过中间层冒泡到最近的 catch，但进了 catch 就回不去了。他虚构了一种语法：用 perform 执行一个效应，外层 handle 捕获后可以 resume with 一个值，让程序回到原处继续执行，可以先理解为"可恢复的 try/catch"。它对异步的意义在于：JavaScript 里一个函数变成 async，所有调用者都得跟着变，而效应处理器可以等一秒、查完数据库再恢复，中间的函数一行都不用改。它还能把"做什么"和"怎么做"分开，比如遍历目录的函数只管 perform 记日志、读文件，具体实现由外层决定，测试时换成假的就行。效应通常会写进类型签名，所以不会失控。至于要不要加进 JavaScript，他坦言不知道，可能太强大了。

最后他有点牵强地联系 React：Suspense 让组件在数据未到时抛出 Promise，React 等它解决后重渲染；Hooks 靠 React 记录"当前组件"来知道 useState 属于谁。两者都不是真正的代数效应，却达成了类似目标。他说 Monad 一直没懂，代数效应却一下就通了，并推荐了 OCaml 等资料。
