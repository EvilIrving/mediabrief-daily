Redis 冒险的终点（The End of the Redis Adventure） ｜ Hacker News ｜ 文章 ｜ http://antirez.com/news/133

Redis 作者 antirez（Salvatore Sanfilippo）2020 年宣布卸任 Redis 维护者的告别信，后来在 Hacker News 上广为流传。

他回忆 Redis 诞生的环境：十多年前，他和合伙人做了意大利两个主要的 Web 2.0 服务，为了扩展性自己发明了很多东西，其实业内早有，但他们既不知道也不在乎，想解决问题，更想找乐子。可 Redis 后来成了无数系统的核心，他的工作也从"造东西"变成审阅别人对代码的意见，让它更正确、更快、更安全。他说自己从来不想当软件维护者：写代码是为了表达自己，代码是一件作品，有用只是副作用，"宁愿被记成一个糟糕的艺术家，也不愿是个好程序员"。项目需要的恰恰是更多维护、更少表达，而他已经撑得够久了。

所以他退后一步，在 Redis Labs 担任"出点子的人"并留在顾问委员会，把项目交给同事 Yossi Gottlieb 和 Oran Agra，连新的开发治理模式怎么定也交给他们，因为那正是他最想躲开的"元维护"工作。他希望 Redis 那种社区精神和另一种写软件的方式能延续下去。

他说 Redis 是他职业生涯里压力最大、也可能最重要的事；他不太喜欢这些年地下编程圈的变化，但感谢一路上的人，以及 Redis Labs、VMware、Pivotal 给他写开源的自由。未来没什么计划，先四处看看、玩玩爱好、多写博客，也许继续拍面向大众讲技术的意大利语视频，不过他很怀疑自己真能不再写代码，"太好玩了"。
