这是张小珺商业访谈录对游凯超的一期近三小时长谈。游凯超本科、博士均毕业于清华，现在是 Inferact 的联合创始人兼首席科学家。Inferact 由伯克利的开源大模型推理引擎 vLLM 的核心维护者们创立，今年初拿到了 1.5 亿美元种子轮融资。整期节目大致分三块：他怎样从算法研究者转向系统工程；vLLM 如何从一篇论文长成开源社区、又长成一家公司；以及他对“模型—Infra—Harness 协同设计”和行业格局的判断。贯穿始终的是一种很朴素的价值观：做有意义、可验证、真正有人用的东西。

一、从算法到系统：为什么转向

游凯超自称典型的理科生，高中时没刷过算法竞赛，而是在“学堂在线”上自学大学物理和 Python。进清华时高考分数只比录取线高两三分，后来却拿了清华特奖。他对特奖看得很淡，认为这个奖曾经被媒体过度渲染，把一群二十岁出头的学生推到聚光灯下并不健康；“清华是舞台，别只当观众”说的是追求自身成长，不是和别人比。

他博士前期做迁移学习、数据稀缺场景下的高效学习和大模型微调，后来转向机器学习系统，给了三个理由。第一，AI 学术圈投稿量呈几何级增长，审稿质量崩坏，中稿近乎抽彩票，他用了“礼乐崩坏”来形容。第二，他反思“为什么成功的是何恺明”：很多想法组里也想过，差别在于恺明有大规模实验的能力，真正决定成败的是系统和数据，而不是在交叉熵损失上雕花。第三，2022 年他在 VALSE 会上和张祥雨聊了一个多小时，发现这位目标检测大牛关心的已经不是新 loss，而是复杂硬件给软件带来的挑战。再加上 Scaling Law 时代算法上的低垂果实已被摘光，而小规模算法改进往往会被下一代更大的预训练模型直接抹平，他认为系统方向更“确定”：加速了几倍是可以客观验证、可以累积正反馈的。用他的话说，别人可以说你的东西不新颖，但不能说它没用。

伯克利是他人生里两个关键的节点。2019 年他在 Michael Jordan 门下暑研，认识了当时即将入学、后来成为 vLLM 发起人之一的李卓翰，也接触到系统方向的 Ion Stoica。当他担心“无名小卒做的系统没人用”时，Stoica 告诉他：好软件总会有人用。四年后他向 Stoica 申请交流，提起了这段旧事，Stoica 很感动，于是 2024 年他去了 Sky Computing Lab，正赶上 vLLM 快速发展。他把两位导师做了对比：Jordan 偏理论洞见，Stoica 追求真实世界的影响力；在当下，后者更值得追求。他与本科同学翁家翌（现在 OpenAI 做 ChatGPT 训练）一起做过强化学习框架“天授”，两人也有相似的转向。

二、vLLM：从论文到社区

他特意区分了 vLLM 和 PagedAttention。PagedAttention 借鉴操作系统虚拟内存来管理 KV Cache，投 SOSP 2023 时被审稿人批评“太简单”，靠做得早、实验扎实才低分过线。vLLM 则早已不只是这个算法，它是一整套推理系统，作用是向用户屏蔽模型和硬件的复杂性：用户只是在下拉菜单里换一个模型，背后的适配却千差万别。他用电力系统打比方：硬件是风、水、光这样的自然资源，模型是发电机，推理引擎是电网。

他认为 vLLM 是伯克利开源传统的延续，从 BSD、RISC-V、RAID 到 Spark、Ray，都是学生在读期间发起、再由公司托举成为工业基础设施的。David Patterson 提出的“实验室只开五年”规律，恰好和产业需求周期发生了共振。说服博士生长期维护开源项目很难：低年级要发论文，高年级要找工作，只有中后期、论文已经够毕业的人才合适，他正是这样的人。核心四人是卓翰、论文一作 Woosuk、后来担任 CEO 的 Simon，以及他自己。他说大家走到一起是因为追求“意义”，并引用《送东阳马生序》里的意思：心中有足以快乐的事，就不会在意吃穿不如别人。

2024 年的主线是从原型到生产的 V0→V1 重构；2025 年的主线是大规模集群部署，同时开源模型的重心从欧美转到中国。他 2024 年底回国，正赶上 DeepSeek V3 和 R1，于是从零搭建了 vLLM 中文社区，走访 DeepSeek、Kimi 等用户。DeepSeek 内部本就基于 vLLM 做了深度优化，vLLM 团队反过来也在向他们学习。

社区治理采用“仁慈的独裁者”模式：几位最终拍板人之下是十来位核心维护者和几十位 committer。他做过一个强硬决定，把 Beam Search 从引擎里删掉，因为它已经不适合大模型的主流负载，继续维护只会增加复杂度。目前优先级放在大集群上的大模型，几百兆的小模型不再接性能优化需求。vLLM 曾被 GitHub 统计为贡献者最活跃的项目，但这也带来了“幸福的烦恼”：有培训机构批量提交垃圾 PR 来给学员包装简历，彻底打破了“社区用户都是善意的”这一假设。他判断，在 Coding Agent 时代代码变得廉价，维护者自己让 Agent 重写往往比审别人的 PR 更快，开源社区会演变为“维护者写代码、用户提反馈”。他也提到 OpenClaw 那种纯 AI 自治的社区，但认为 vLLM 必须提前为未来三个月的新模型、一年后的新硬件做设计，这种前瞻性的判断目前交不给 AI。

三、为什么一定要开公司

2024 年底 vLLM 被捐给 PyTorch 基金会，从法律上确保它永远开源、商标归社区。但 Stoica 一直坚持：没有公司托底，这个项目一定会“凉”，就像 Linux 离不开 Red Hat，Kubernetes 离不开 Google，Spark 离不开 Databricks。大厂做不了这件事，因为大厂之间互不服气；只有由创始团队组建的中立创业公司才有号召力。2025 年现实问题集中爆发：人员来来去去，撑不起长期的重要功能；新模型、新硬件发布前的支持需要签 NDA，而社区不是法人实体；集群级别的优化需要机器，只能四处“乞讨”算力，还随时可能被收回。

游凯超决定得最早。2024 年底，他判断创业失败的最坏结果不过是少拿几年工资，而不创业 vLLM 就无法长期发展。于是他接了 Sky Computing Lab 的博士后，“为创业等两年”，Jordan 也支持他这样选。最摇摆的是 Woosuk：xAI 和 Thinking Machines Lab 先后邀请他领导基础设施，机会多得惊人。最后大家问了他一个问题：如果你赚了很多钱，但十年后 vLLM 失败了，你会开心吗？他想了几天，答案和大家一样。注册公司前夕，某顶级大厂的一号位打电话开出每人年薪 2000 万美元，请他们别创业，四人当场一口回绝。李卓翰毕业较早，2024 年已经进入 OpenAI、后来又去了 Meta，没有加入。

融资比想象中顺利。a16z 在 2023 年、红杉和真格在 2024 年就以捐赠的形式资助过开源项目，“钱早就准备好了”。投资人看重的是生态位：每个开源模型发布背后都有 vLLM 的支持，每家芯片厂商都主动来靠拢。公司现在三十多人，Stoica 是联合创始人兼顾问。名字 Inferact 取自 “Bring Inference into Action”。商业模式是按 Token 产出和节省的成本来收费，而不是卖工程师的时间，形式包括 Endpoint 服务、客户自带机器的 BYOC，以及战略生态合作。他强调，眼下想合作的客户远多于能接的，与社区利益冲突的生意直接不接。

四、模型与 Infra 的协同设计

这是节目技术密度最高的部分。核心概念是“硬件彩票”：摩尔定律终结后，算力增长都是专用的，模型结构如果没对上硬件，就吃不到红利。Hinton 的胶囊网络对 GPU 不友好，所以没能普及；Transformer 抽中了矩阵乘法的彩票。模型结构决定了推理效率的上限，上限太低，系统工程师也无力回天。现实中通常是算法去迁就已经造好的硬件。他举了几个例子：RoPE 之所以胜出，是因为它可以在 Attention Kernel 之外独立实现，和 FlashAttention 互补，而需要改 Attention 内核的位置编码方案都被淘汰了；反过来，也有 Infra 过于强势、为了负载均衡采用 Expert Choice 路由而牺牲算法正确性的情况。

他把 DeepSeek 评为协同设计做得最好的团队，Infra 是全球顶级水平，而且算法同学也懂 Infra，比如 DeepSeek MoE 的高效实现就出自算法同学之手。他把这份功底追溯到幻方量化时期对性能的极致压榨和自建机房带来的全栈掌控，但也指出这很难复制：自建机房控制力强、成本低，却难以快速扩张。FP8 训练是一个典型案例：权重分块量化、激活逐通道量化，并利用矩阵单元和向量单元可以并行执行的特点来做累加，在不损失精度的前提下吃到了 Hopper 架构翻倍的算力。他也点评了 DeepSeek 新发布的投机解码方法 DSpark：它属于 DFlash 路线，一次猜很多 Token，再按置信度只验证前面靠谱的部分，算法上不算新颖，腾讯混元和上海交大都有类似工作，但 DeepSeek 把它扎实地做到了极致。他还隐晦地评价某位以“懂 Infra”著称的大佬，认为对方擅长的只是建集群这种“Infra 的 Infra”，本质上是资本和电力，并不懂 AI Infra。

关于 MoE，他总结了三大挑战：细粒度专家导致矩阵维度偏低，动态路由不适合 GPU 擅长的静态数据流，以及万亿参数规模下专家并行的通信难题。DeepSeek 用 DeepEP、DeepGEMM 等一整套方案引领了这一波。注意力机制是推理引擎面临的最大挑战，因为它决定了状态如何管理：完整注意力适合 PagedAttention，线性注意力的状态大而且会被修改，混合注意力就更难。他观察到，欧美模型更重效果，中国模型更重效率，根子在于算力供给不同。

他特别强调 Token 和电的区别：电可以调压、标准化，Token 却带着模型的烙印，无法互相转换，而且和 Harness 深度耦合，所以现在是百花齐放又相当混乱的局面。Test-time Scaling 的重心已经从“让模型想得更久”转向“让 Agent 和环境交互更多轮”，前缀缓存因此变得至关重要。他批评一些 Harness 设计“自作聪明”：频繁改动放在请求前部的工具列表、在 System Prompt 里塞精确到秒的时间戳、把定时任务都设在整点，结果前缀缓存全部失效，整点流量暴涨。月之暗面的同学把这形容为一群“小龙虾”整点集体出动攻打月球。他提到 Manus 的季逸超写过 Infra 友好的 Harness 设计，也期待正在扩招 Agent 框架岗位的 DeepSeek 拿出示范。

方法论上，他反复回到“第一性原理”：行业里每月都冒出大量新技术，团队需要有足够多的人真正理解 Continuous Batching、GPU 性能测试、Attention 的计算过程，才能分辨哪些是花拳绣腿。他举了自己的例子：从 GPU 编程模型推断应该存在某种调试工具，于是追着英伟达找出了早已存在却少有人知的 CUDA Core Dump，解决了大量非法内存访问之类的疑难问题。他也认同 Patterson 的判断：后摩尔时代，AI 的上限取决于系统。FlashAttention 让大量近似 Attention 的论文失去意义；Continuous Batching、PagedAttention 和投机解码让自回归解码变得便宜；分块并行算法让线性注意力变得可行。只有能被高效实现的算法才能留下来。

五、判断与下注

他给了一个 Hot Take：面向人的模型，上下文停在百万级就够了，长程任务和终身学习靠记忆、技能、子 Agent 等外部模块解决；如果这个判断成立，现有的模型结构和 Infra 范式还能延续很久。效率和规模并不矛盾，就像用电高峰时电厂只能更努力，供给侧要优化，需求侧也要学会节省 Token。他认为中美在 AI 基础设施上是各有掣肘：中国缺高端算力，但土地和电力充足；美国正好相反。他最大的下注是“开源模型终将胜出”。理由是模型不像核武器那样可以藏起来，它必须大规模民用，而用户在使用过程中就能收集到足够训练自己模型的数据，尤其是 Coding Agent 的数据，一个月左右就能让飞轮转起来，他举了智谱 GLM 的 Coding 能力为例。因此模型终将商品化，护城河只剩快速迭代，Inferact 选择专注在推理这一层。在他看来，vLLM 已经是“AI 推理领域的 Linux”，Red Hat 也已经把它打包进企业发行版。

结尾部分比较个人化。他把自己的开源情结归因于成长时代的风气，把写作看作技术分享和形式化思考；给年轻研究者的建议仍然是从第一性原理出发，想清楚自己要什么。谈到人类，他认为技术积累正处于指数曲线的临界点，AI 是把全人类经验浓缩后再加速；理想状态是硅基智能提供规模化的执行力，人类提供灵感和语境。快问快答里，他最喜欢的地方是伯克利；分享的冷知识是给模型输入一千个感叹号，可以借输出反推对方推理引擎开了几步投机采样；歌选了李宗盛的《山丘》，意思是想说的还有很多；对“语言即世界”，他联想到五次及以上方程没有根式解，人类或许只是低维生物。
