谁在害怕中国模型？Who’s Afraid of Chinese Models? ｜ Stratechery ｜ 文章 ｜ https://stratechery.com/2026/whos-afraid-of-chinese-models/

Ben Thompson 在 Stratechery 上回应中国开源权重模型 Kimi K3 引发的恐慌。他的核心判断是：从经济角度看，这种反应被严重夸大了；真正值得担心的只有网络安全。

他从自己在凯洛格商学院读 MBA 的经历讲起：当年他认为软件零边际成本让传统商业原理失效，并由此提出了“聚合理论”；而 AI 让那些老原理重新回到了中心——边际成本又回来了。开源权重模型常被误以为“免费”，但它省掉的只是研发这项与收入无关的固定成本；推理则是与收入同比增长的销货成本（COGS），开源模型同样不是免费提供的。Kimi K3 每百万输入/输出 token 收费 3/15 美元，低于 OpenAI 的 GPT-5.6 Sol（5/30 美元），但按 token 比价未必正确。英伟达 CEO 黄仁勋把 GPU 称为“token 工厂”，这套说法在 ChatGPT 时代成立，到了推理和智能体时代就失灵了：不同模型得出正确答案所需的 token 数差别很大，据报道 Kimi 用的 token 明显多于 Sol，价格优势可能被抵消。因此 token 不是大宗商品，真正可以互换的是用 token 构建出来的“智能”。智能的成本取决于模型体量、推理效率（如 MoE）、显存效率（KV 缓存）、服务效率（批处理、前缀缓存等）以及 token 效率。

他认为许多有经济价值的任务正在迅速变成智能的大宗商品市场。他用一个三家供应商的算例说明大宗商品市场的规律：价格由满足需求的最高成本供应商的边际成本决定，成本结构最好的赚得最多，最差的会破产，而固定成本和债务就在这时变得致命。但眼下这套分析还不适用：前沿模型供不应求，算力短缺让英伟达、转售算力的 SpaceXAI（以及 Meta）和 Anthropic 层层都有高利润，Anthropic 和 OpenAI 凭借能力、规模和 token 效率，单位前沿智能的成本可能本就最低。中国模型显得便宜，是因为算力短缺撑起了一把“价格保护伞”，他非常怀疑中国模型按边际成本算真的更便宜。

那前沿实验室为何惊慌？他给出四点：它们仍停留在训练成本主导财务的思维里，而推理市场的增长将远快于训练成本，完全可以以量补价；智能并非完美的商品，谁在跑推理谁就在收集数据，这也是微软热衷帮企业运行自有模型的原因，而中国模型让这条路更可行；实验室的差异化在于向上整合用户体验，Claude Code 和 Codex 黏性很强，这对包括微软在内的软件公司构成威胁；还有 Anthropic 的意识形态——它相信只有自己能被托付 AI，开源替代品是对这一信念的致命打击。

中国的动机很明确：把互补品商品化。阿里发布据称仅次于 Anthropic Fable 5 的 Qwen3.8 Max，并将重新开放权重；他推测这与习近平上周强调开源开放的 AI 讲话有关，讲话把开放与 AI“从数字世界走向物理世界”挂钩，而物理世界正是中国在机器人等领域占优的地方。关于蒸馏，他认为把中国的成功全归于蒸馏是错的，但否认它带来的巨大优势同样是错的，尤其是在强化学习后训练越来越关键的今天。他引用红杉的 Dean Meyer 和 Konstantine Buhler 的观点：美国开源模型厂商受服务条款约束，只能绕道中国模型“蒸馏蒸馏的结果”（Thinking Machines 就靠中国模型解决强化学习冷启动）。他反问蒸馏到底错在哪里——大模型本身就是对整个互联网知识的蒸馏。他的主张是立法明确训练数据采集属于合理使用，并禁止（至少美国公司）用服务条款禁止蒸馏。

唯一值得害怕的是网络安全。Hugging Face 遭自主 AI 智能体入侵后，美国前沿模型的护栏分不清应急响应者和攻击者，防守方只好在自家基础设施上运行智谱 Z.ai 的开源模型 GLM 5.2 分析 1.7 万多条日志。他痛批特朗普政府在 Fable 发布后的恐慌式应对强化了 Anthropic 认为只有自己可信的倾向，导致防守方实际上被禁止用 Fable 或 Sol 做网络安全，只能依赖一个多年来试图削弱美国网络防御的国家的模型，“简直疯了”。他的结论是：放宽 Fable 和 Sol 在网络安全上的限制，让美国开源模型厂商与中国公平竞争；让前沿实验室靠更好的产品取胜，而不是让它们定义安全，或抽走人类集体知识的梯子。
