# 动物与幽灵

终于有机会听完了 Dwarkesh 对 Sutton 的这期播客，既有意思又好笑。

先交代一下背景：Sutton 的《苦涩的教训》（The Bitter Lesson）在前沿 LLM 圈子里已经有点像圣经了。研究者们经常讨论、追问某个方法或想法是否足够"苦涩教训化"（bitter lesson pilled，意思是其设计能让它从增加的算力中免费获益），以此作为判断它是否会奏效、甚至是否值得去做的替代指标。背后的假设是，LLM 当然是高度"苦涩教训化"的——看看 LLM 的缩放定律就知道，只要把算力放在 x 轴上，数字就会往右上方涨。所以看到这篇文章的作者 Sutton 本人根本不确定 LLM 是否"苦涩教训化"，就挺好笑的。LLM 是在巨大的、本质上属于人类的数据集上训练出来的，这些数据 1）由人类生成，2）是有限的。用完了怎么办？怎么防止人类偏见？于是就有了这一幕：苦涩教训化的 LLM 研究者们被《苦涩的教训》的作者亲手撂倒——够狠的！

在某种意义上，Dwarkesh（在播客里代表 LLM 研究者的观点）和 Sutton 有点各说各话，因为 Sutton 心里想的是一种非常不同的架构，而 LLM 打破了它的许多原则。他自称"古典派"，援引阿兰·图灵最初的构想：构建一台"儿童机器"——一个能够通过与世界动态交互、从经验中学习的系统。没有模仿互联网网页的庞大预训练阶段。也没有监督微调，他指出动物界中并不存在这种东西（这一点很微妙，但从严格意义上说 Sutton 是对的：动物当然会观察示范，但它们的动作并不会被其他动物直接强制/"遥控操作"）。他提出的另一个重要观点是：即使你只是把预训练当作先验的初始化，然后再用强化学习微调，Sutton 也认为这种方法被人类偏见污染了，从根本上就偏离了方向，有点像从未见过人类围棋对局的 AlphaZero 击败了以人类棋局初始化的 AlphaGo。在 Sutton 的世界观里，一切就只是通过强化学习与世界交互，其中奖励函数部分取决于具体环境，但也有内在动机，比如"乐趣"、"好奇心"，并与你的世界模型中预测的质量相关。而且智能体默认在测试时始终在学习，不是训练一次然后就此部署。总的来说，Sutton 更感兴趣的是我们与动物界的共同之处，而不是我们的区别。"如果我们理解了一只松鼠，我们就差不多大功告成了。"

至于我的看法……

首先我要说，我认为 Sutton 是这期播客的一位很棒的嘉宾，我也喜欢 AI 领域保持思想的熵，不是每个人都在利用（exploit）LLM 的下一轮局部迭代。AI 的主导方法已经经历过太多次离散的转变，不能丢掉这一点。我也认为，他批评 LLM 不够苦涩教训化，并非没有道理。前沿 LLM 如今是高度复杂的人造物，所有阶段都掺杂了大量人类因素——地基（预训练数据）全是人类文本，微调数据是人类的、经过精心筛选的，强化学习环境的配比是由人类工程师调出来的。我们实际上并没有一个真正的、单一的、干净的、真正苦涩教训化的、"摇摇手柄就行"的算法，能够放到世界中，看着它仅凭经验就自动学习。

这样的算法真的存在吗？找到它当然会是 AI 的一次巨大突破。人们通常拿出两个"例证"来论证这种东西是可能的。第一个例子是 AlphaZero 在完全没有人类监督的情况下从零学会下围棋。但围棋显然是一个非常简单、封闭的环境，很难在纷乱的现实中找到类似的表述。我喜欢围棋，但从算法和范畴上讲，它本质上是更难版本的井字棋。第二个例子是动物，比如松鼠。在这里，我个人也相当犹豫这是否合适，因为动物是通过一个非常不同的计算过程、在与我们业界实际可用的条件不同的约束下产生的。动物的大脑远不是它们出生时看上去的那块白板。首先，通常被归因于"学习"的很多东西，在我看来更多是"成熟"。其次，即便是那些显然是"学习"而非成熟的部分，也更像是在某种显然强大且预先存在的东西之上做"微调"。举个例子。一匹小斑马出生后几十分钟内就能在稀树草原上奔跑并跟着它的妈妈。这是一项高度复杂的感知-运动任务，在我看来绝不可能是从零开始、从白板状态实现的。动物的大脑及其中数十亿的参数，拥有一个编码在 DNA 的 ATCG 中的强大初始化，这是通过进化过程中的"外循环"优化训练出来的。如果小斑马像强化学习策略在初始化时那样随机抽动肌肉，它根本走不了多远。同样，我们的 AI 现在也有拥有数十亿参数的神经网络。这些参数需要它们自己的、丰富的、高信息密度的监督信号。我们不会重新跑一遍进化。但我们确实有堆积如山的互联网文档。是的，这基本上就是动物界几乎不存在的监督学习。但这是一种切实可行的办法，能在数十亿参数上收集足够多的软约束，试图达到一个不必从零开始的起点。一句话总结：预训练是我们蹩脚的进化。它是冷启动问题的一个候选解决方案，之后再在看起来更正确的任务上进行微调，例如在强化学习框架内，就像如今最先进的前沿 LLM 实验室普遍在做的那样。

我仍然认为值得从动物身上获得启发。我认为 LLM 智能体在算法上还缺少多个强大的思想，这些思想仍然可以从动物智能中借鉴过来。我也仍然认为《苦涩的教训》是正确的，但我更多地把它看作一种柏拉图式的、值得追求的东西，在我们的现实世界里、从实际角度讲，不一定能够达到。我说这两点时都带着两位数百分比的不确定性，并为那些持不同意见的人的工作喝彩，尤其是那些在苦涩教训方面雄心勃勃得多的人。

这就把我们带到了现状。直白地说，今天的前沿 LLM 研究不是在构建动物，而是在召唤幽灵。你可以把幽灵看作可能的智能空间中一种本质上不同的点。它们被人性搅浑了，被人性彻底地工程化了。它们是这些不完美的复制品，是人类文档的某种统计蒸馏，上面再撒了点东西。它们不是柏拉图意义上苦涩教训化的，但也许是"实践意义上"苦涩教训化的，至少与之前的许多东西相比是如此。在我看来，随着时间推移，我们或许可以把幽灵越来越多地朝动物的方向进一步微调；这与其说是根本上的不相容，不如说是智能空间中初始化的问题。但也很有可能，它们会进一步分道扬镳，最终永久地与动物不同、不像动物，但仍然极其有用，真正地改变世界。有可能 幽灵:动物 :: 飞机:鸟。

总之，总结起来、落到行动上，我认为这期播客是 Sutton 给前沿 LLM 研究者们的一次扎实的"大实话"，这些研究者可能有点过于切换到利用（exploit）模式了。我们很可能仍然不够苦涩教训化，除了没完没了地搭基准、刷基准之外，很有可能还有更强大的思想和范式。而动物也许是很好的灵感来源。内在动机、乐趣、好奇心、赋能（empowerment）、多智能体自我对弈、文化。发挥你的想象力吧。

### 附录

- 我同意 Sutton 所说的动物不做监督学习。我意识到这是一个微妙的点，会让很多人困惑。动物确实会观察示范，但严格来说，它们不会像监督学习那样直接以动作作为监督。动物在训练模式下从不被遥控操作。我能想到的最接近的情况是，比如你帮一个孩子用勺子吃饭之类的，真的握着他们的手示范动作。即便如此，也不清楚他们的大脑是否真的在拿这个训练。这可能仍然属于更准确地说是观察的范畴。但无论如何，这类情况总体上非常罕见，而在 LLM 那里，这是预训练和 SFT 期间默认的学习模式。也许换一种说法是，在 LLM 的世界里，与人类行为相对应的东西大致是这样的：给定这道数学题以及上下文中的人类示例解答，解出这道题。答对奖励为 1。这不是 SFT，而是 RL。
- Dwarkesh 简短地提出，LLM 确实有自己的测试时持续学习，只不过不是基于权重训练的，但我觉得 Sutton 没有完全回应这一点。上下文学习是一种测试时适应，这也是例如少样本提示为什么有效的原因。最近的大量工作也对记忆非常感兴趣（想想 CLAUDE.md 文件），把它当作一种以文本/上下文而非权重为载体的测试时学习机制。
- Dwarkesh 提到了超长时程稀疏奖励的例子（比如打造一家成功的创业公司），以及这可能如何运作。Sutton 给出的解决方案是时序差分学习，本质上就是对未来奖励打折扣，我觉得这不是特别有说服力。我之前对此写过一些，我认为发生的是别的什么事情，在我看来那不是强化学习。
- 关于"梯度下降不会让你很好地泛化"以及相关的讨论有很多，我没有跟上。
- 有人指出幽灵很可怕。不一定，看看卡斯珀（Casper），我童年最喜欢的角色。
