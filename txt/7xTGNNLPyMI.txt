**开场**

这是一堂面向普通观众、讲解 ChatGPT 这类大语言模型的完整课程。讲者要回答的问题是：对话框里可以输入任何东西、按下回车，背后到底发生了什么，返回的文字是怎么来的，你究竟在和什么对话。他按构建 ChatGPT 的顺序，把整条流水线从头讲一遍：预训练、监督微调、强化学习三个阶段，中间穿插这些训练方式带来的“认知心理学”层面的特点，最后讲未来趋势和使用渠道。

**一、预训练第一步：下载并处理互联网**

讲者以 Hugging Face 整理的 FineWeb 数据集为例（OpenAI、Anthropic、谷歌等公司内部都有类似的数据集）。目标是从公开来源拿到海量文本，既要高质量，也要多样性，因为模型的知识就来自这里。成品 FineWeb 只有约 44TB，一块硬盘就能装下。

起点是 Common Crawl：这个机构自 2007 年起爬取互联网，到 2024 年已索引 27 亿个网页，做法是从少数种子页面出发，沿着链接不断抓取。这些原始数据要经过多道处理：
- URL 过滤：用黑名单排除恶意软件、垃圾、营销、种族主义、成人网站等域名。
- 文本提取：爬虫存下的是带标记、CSS 的原始 HTML，要去掉导航等内容，只留正文。
- 语言过滤：FineWeb 用语言分类器，只保留英文占比超过 65% 的页面。这是各公司可以自行取舍的设计决定，比如把西班牙语全滤掉，模型的西班牙语就会很差；FineWeb 偏重英文，训练出的模型英文强、其他语言一般。
- 去重等步骤，最后是个人身份信息（地址、社保号等）的识别和剔除。

他展示了 FineWeb 里的几篇样例（如 2012 年龙卷风的文章、一篇讲人体有两个“9 伏电池大小”肾上腺的医学文章），又把前 200 个网页拼在一起，说明得到的就是一大片原始互联网文本，接下来要让神经网络学会这些文本的规律。

**二、分词（Tokenization）**

神经网络需要一维的、符号集有限的序列。文本按 UTF-8 编码就是比特序列，只有 0 和 1 两种符号，序列极长；而序列长度是宝贵的资源，所以要拿更大的符号表换更短的序列。第一步把每 8 个比特合成一个字节，得到 256 种符号，序列缩短为原来的八分之一（他建议把这些数字当成唯一的 ID，甚至想成 256 个不同的表情符号）。实际的先进模型还要继续压缩：用字节对编码（BPE）算法，找出很常见的相邻符号对（例如 116 后面跟 32），合成一个新符号（ID 256），把所有出现的地方替换掉，反复迭代，每次都让序列变短、词表变大。实践中词表大小约 10 万比较合适，GPT-4 是 100,277 个符号。文本变成这些符号的过程就叫分词，符号叫 token。

他用 Tiktokenizer 网站（选 cl100k_base，即 GPT-4 基座模型的分词器）演示：“hello world”恰好是两个 token（hello 的 ID 15339，“ world”带前导空格，ID 1917）；去掉空格、在中间加两个空格、改变大小写，切法都会变（“Hello World”会变成三个 token），所以分词区分大小写。一行示例文本在 GPT-4 眼里是长度 62 的序列。FineWeb 整体约 15 万亿个 token，这些数字本身没有含义，只是唯一的标识符。分词在后面还会回头再讲。

**三、神经网络训练**

训练的目标是让网络学会 token 在序列中相互跟随的统计规律。做法是从数据里相当随机地截取 token 窗口，长度从 0 到某个最大值，实践中可能是 8000，也可以是 4000 或 16000，更长的窗口计算太贵。示例里取 4 个 token 作为“上下文”，输入网络，要预测下一个 token。网络对词表中每个 token（10 万多个）各输出一个概率。开始时网络是随机初始化的，输出也是随机的，比如正确答案（ID 3962）只有 3%；而我们知道真正的下一个 token，于是用数学方法微调网络，让正确 token 的概率升高、其他的降低，更新后可能变成 4%。这个过程在整个数据集的海量 token 上、以大批量并行的方式反复进行，直到网络的预测符合训练集里的统计规律。

网络内部：输入序列和模型的参数（权重）一起代入一个巨大的数学表达式。参数一开始随机设置，他把它们比作调音台上的旋钮，训练就是找到一组使预测与训练集统计规律一致的设置。现代网络有数十亿参数，表达式由乘法、加法、指数、除法等简单运算构成；神经网络架构研究的任务就是设计出表达力强、易于优化、便于并行的表达式。他展示了一个网站上的生产级 Transformer 可视化图：token 先被嵌入成向量，然后依次经过层归一化、矩阵乘法、softmax、注意力模块、多层感知机模块等，最后输出下一个 token 的概率。图中的中间数值可以粗略看成“合成神经元的放电率”，但他提醒这些神经元比生物神经元简单得多：这个表达式没有记忆、没有状态，输入到输出是固定函数。

**四、推理（Inference）**

推理是从模型中生成新数据。给定一个前缀（例如 token 91），把它输入网络，得到概率分布，然后按这个分布“掷一枚有偏的硬币”采样出下一个 token（例如 860），把它接到序列后面，再预测下一个，如此重复。演示中第四步采样得到 13659（“article”），而训练数据里原来是 3962，说明系统是随机的：有时恰好复现训练集里的片段，更多时候是训练数据的“重新混合”，统计特性相似但并不相同。

通常的流程是：下载互联网并分词只做一次，然后用不同设置、不同规模训练许多网络，选定满意的一组参数后再做推理。你在 ChatGPT 上聊天时，模型是 OpenAI 几个月前训练好的，参数固定，你得到的全是推理。

**五、GPT-2：训练是什么样子**

GPT 是 Generatively Pre-trained Transformer 的缩写。GPT-2 是 OpenAI 2019 年发表的第二代，当时第一次凑齐了今天看来可以辨认的现代技术栈，只是规模小得多：16 亿参数（现代模型接近万亿或数千亿）、最大上下文长度 1024 个 token（今天是几十万甚至上百万）、训练数据约 1000 亿个 token（FineWeb 是 15 万亿）。2019 年训练它估计要 4 万美元；讲者在 llm.c 项目里复现它，约一天、600 美元，他认为认真优化可以降到 100 美元左右。成本下降的原因：数据集质量更高、过滤方法更成熟，硬件快得多，运行模型的软件也优化了很多。

他展示了自己正在训练 GPT-2 的终端：每一行是一次参数更新，每次在 100 万个 token 上同时改进预测，每次约 7 秒，总共 32,000 步（约 330 亿个 token），演示时只跑到第 420 步左右，约 1%。研究者盯着的是“loss（损失）”这个数字，越低说明预测越好，就在一旁等着、喝着咖啡确认它在下降。每 20 步会做一次推理采样：第 1 步和第 20 步输出完全是随机文字，约 1% 时仍是胡言乱语，但已有一点局部连贯，跑完全程（还需一两天）才会输出相当连贯的英语。

算力方面，他在云上租了一台 8 块 H100 的服务器（租用平台他常用 Lambda），按需价格约每块 GPU 每小时 3 美元。GPU 适合这类训练，因为矩阵乘法可以大规模并行。一块 GPU 可以八块一组装成一个节点，多个节点再组成数据中心。大科技公司争抢 GPU 来训练模型，推动英伟达股价到 3.4 万亿美元；他还提到一个月前的报道，马斯克要在一个数据中心里装 10 万块 GPU。所有这些 GPU 都在协作做同一件事：在 FineWeb 这样的数据集上预测下一个 token。

**六、基座模型**

预训练的产物叫基座模型（base model），本质是“互联网文本的 token 模拟器”，它还不是助手，只会生成互联网文本的变体，也就是“梦出”网页。很多公司训练这类模型，但公开发布基座模型的不多，因为它只是后续步骤的第一步。发布一个模型需要两样东西：描述网络结构的 Python 代码（前向传播，通常几百行）和参数（GPT-2 约 15 亿个数字）。GPT-2 当年就是这样发布的。

接着是 Meta 的 Llama 3：4050 亿参数，在 15 万亿 token 上训练，做法与 GPT-2 相同，只是大得多。Meta 发布了 Llama 3.1 405B 的基座模型，也发布了 instruct 版本（即助手）。他在 Hyperbolic 网站上演示这个基座模型（必须选 Llama 3.1 405B base，最大 token 设为 128）：
- 问“What is 2+2?”，它不会回答“4”，而是被当作前缀继续写，往哲学方向发散；重复几次，每次的续写都不同，因为系统是随机的。结论：它不是助手，而是一个昂贵的自动补全，并且是随机的。
- 这个模型在预测下一个 token 的过程中学到了大量世界知识，存在参数里。他把 4050 亿参数比作互联网的“zip 文件”，但是有损压缩，保留的是互联网的大致印象。他用“Here is my top 10 list of the top landmarks to see in Paris”这样的提示引出巴黎景点列表：信息大体可能对，但只是模糊的、概率性的回忆，常出现的内容更容易被记住。
- 把斑马的维基百科开头一句贴进去，模型几乎逐字背出整页内容（直到后来才偏离），这叫“复述/反刍”（regurgitation）。原因是维基百科这类高质量来源在训练时被优先采样，模型大概看过约 10 次，就像人读一百遍就能背出来，只是模型每次呈现的学习效率更高。这通常不是想要的结果。
- 该模型的知识截止到 2023 年底，没见过 2024 年美国大选。他用“共和党提名特朗普……”做前缀让它续写：一次采样出彭斯做竞选搭档、对手是希拉里和蒂姆·凯恩，另一次是德桑蒂斯、对手是拜登和哈里斯，是不同的“平行宇宙”，这些都是幻觉，即模型按概率做的最佳猜测。
- 巧妙设计提示，基座模型也能用：给出 10 组英文单词与韩语翻译（few-shot 提示），它靠上下文学习（in-context learning）识别模式，把 teacher 翻成对的韩语。
- 还可以只靠提示做出助手：他让 ChatGPT 帮忙写了一个提示，内容是“一个乐于助人的 AI 助手和人类之间的对话”，再配上几轮示范对话，最后接上真正的问题“Why is the sky blue?”。基座模型会以助手的身份回答（瑞利散射），只是答完后会继续替人类编出下一个问题；如果不加这套提示直接问，得到的只是更多的问题。

他在这里小结第一阶段：把互联网文档切成 token，用神经网络预测 token 序列，产物是基座模型，也就是 token 层面的互联网文档模拟器；接下来要做后训练，计算量小得多，大数据中心、数百万美元的开销主要都在预训练。

**七、后训练：监督微调（SFT）与对话**

要让模型回答问题，需要处理“对话”，可以是多轮的，最简单的是人和助手之间的对话。他举了三个例子：问“2+2 等于几”，助手答“2+2 等于 4”；追问“如果换成 * 呢”，助手作答；还有人提出不该帮忙的请求，助手就拒绝。因为是神经网络，不能用代码写规则，而是通过构造对话数据集来“按示例编程”，实际的数据集可能有几十万条多轮、很长、主题多样的对话。对话由人工标注员（labeler）写：给他们对话情境，请他们写出该情境下理想的助手回答。训练时把原来的互联网文档数据集扔掉，换成对话数据集，用完全相同的算法继续训练；模型会很快学到助手如何回应人类。预训练可能要在数千台电脑上训练约三个月，后训练通常只需约 3 小时，因为对话数据集比互联网文本小得多。

对话如何变成 token：需要一种编码协议（类似互联网上的 TCP/IP 数据包规则）。他在 Tiktokenizer 里展示：GPT-4o 的做法是用特殊 token im_start（他说是 imaginary monologue start 的缩写，自己也不清楚为何这样叫）后接说话人（如 user），然后是分隔符，再是问题的 token，最后用 im_end 结束；助手的回合同样处理。这些特殊 token 是后训练阶段新加入的，之前从未训练过。一个两轮的对话总共是 49 个 token 的一维序列，各家格式略有不同，目前有点“狂野西部”。推理时，你在 ChatGPT 里发出消息后，OpenAI 的服务器把上下文拼好，在末尾放上“助手回合开始”的 token，然后从模型采样，由模型接着写出回复；回复未必与训练集里的一模一样，但风格相近。

数据从哪来：他翻开 OpenAI 2022 年的 InstructGPT 论文，第 3.4 节写到公司通过 Upwork 或 Scale AI 雇用承包商，让他们自己想出提示（例如“列出五个重拾职业热情的想法”“接下来该读哪十本科幻小说”“把这句话翻成西班牙语”），再写出理想回答。公司给标注员的标注指南要求回答有帮助（helpful）、真实（truthful）、无害（harmless），实际的指南通常有几百页，标注员要专门学习。InstructGPT 的数据集没有公开，但有开源的复现，比如 Open Assistant：网上的人受邀创建类似的对话，例如请人写一段经济学术语“垄断”的简短介绍，再写回答，对话可以接着“现在解释给一只狗听”。训练不可能覆盖所有未来的提问，但有十万量级这样的示例，模型就会捕捉统计规律并采纳这种有帮助、真实、无害的助手人格；遇到相同的问题时可能原样背出，更多时候是给出风格类似的回答。

最近两三年，更多是由语言模型生成回答，人再编辑；UltraChat 就是一个很大程度上合成的数据集，几百万条对话，可能有少量人工参与，覆盖面很广。这类 SFT 数据集常常是多种来源的混合体，部分合成、部分人工。

他想说的是：当你在 ChatGPT 里提问，得到的回答是“统计上模拟 OpenAI 雇用的标注员”，而不是什么神奇的 AI；这些标注员通常是受过教育的专业人员（比如写代码相关的对话时），所以你得到的是对这样一个人的即时模拟。举例：问“推荐巴黎五大景点”，如果这道题恰好在后训练数据里，你多半会看到标注员做约 20 分钟网上调研后写下的列表；如果不在，就是模型的预训练知识（互联网上关于巴黎景点有大量讨论）与这种答题风格结合而涌现出的回答。

**八、大模型“心理学”之一：幻觉**

幻觉就是模型编造信息。训练集里可能有这样的对话：“Tom Cruise 是谁”“John Baraso 是谁（美国参议员）”“成吉思汗是谁”，答案都由知道或查过的标注员以自信的语气写出。所以当你问一个他随口编的名字“Orson Kovacs”，模型不会说不知道，而是按“谁是某某”的回答风格给出统计上最可能的猜测。他用 Hugging Face 的推理试验场，故意选老模型 Falcon 7B instruct：第一次说他是美国作家兼科幻小说家，重新生成变成 1950 年代电视剧里的虚构人物，再来一次是前小联盟棒球手；模型并不知道，只是在抽样，并模仿答案的格式。相比之下，他用 ChatGPT 问同一个问题（并让它不要搜索），它回答说不知道有这样一位知名人物，说明幻觉已经改善。

缓解办法一：让模型在不知道时说“不知道”。以 Meta 的 Llama 3 论文（称之为 factuality）中的流程为例：从训练文档里取一段，让语言模型针对这段生成事实性问题和答案（他拿当天的维基百科特色条目 Dominik Hašek 做演示，ChatGPT 生成了“他效力于哪支球队”“拿过几次斯坦利杯”等问题）；然后拿这些问题多次询问被测模型（他用 Mistral 7B 为例），再用另一个语言模型来判断回答是否与标准答案一致，全程不需要人参与。球队这个问题，三次都答对布法罗军刀队，说明模型知道；斯坦利杯正确答案是两次，而模型三次的回答（四次、没赢过等）都不对，说明模型不知道。对于它不知道的问题，就在训练集里新增一条对话，答案是“抱歉，我不知道”或“我不记得”。这样做之所以有效，是因为网络内部很可能有一个表示“不确定”的神经元，但它没有和“说出我不知道”这一行为连起来；有了这些示例，模型就能学到这种关联。这是 ChatGPT 等如今能拒答的原因。

缓解办法二：给模型使用工具。参数里的知识像一个月前读过的东西的模糊回忆，常见的记得牢，罕见的记得差；而人遇到不知道的事会去查，相当于刷新工作记忆。做法是引入新的特殊 token，例如“搜索开始”和“搜索结束”，让模型可以输出查询语句。当运行推理的程序看到“搜索结束”，就暂停采样，用查询去 Bing 之类的搜索引擎检索，把得到的网页文本复制进上下文窗口，之后模型再继续采样，可以直接引用这些文本。上下文窗口里的 token 就是模型的工作记忆，能直接被网络访问，不再是模糊的回忆。教模型使用工具同样靠训练集：几千条展示如何发起搜索的对话就够了，因为预训练已经让它知道什么是网络搜索、什么算好的查询。他在 ChatGPT 里问“Orson Kovacs 是谁”，屏幕上闪过“正在搜索网页”，几秒后回答并附上引用来源；加上“不要用工具”就会只凭记忆回答。问“Dominik Hašek 拿过几次斯坦利杯”，ChatGPT 有把握，直接凭记忆答“两次”；也可以要求它搜索来核实，它就会去搜并引用维基百科。

由此引出对使用的建议：让 ChatGPT 总结《傲慢与偏见》第一章，凭记忆也能得到合理的结果，因为这本名著有大量相关讨论；但更好的做法是把第一章原文贴在提示里（他从网站复制粘贴，用分隔符隔开），因为这样模型可以直接读取而不必回忆，总结质量会更高，就像人在总结前重读一遍章节。

**九、大模型“心理学”之二：自我认知**

网上常有人问大模型“你是什么模型、谁造了你”，他认为这个问题本身没有多少意义：模型不是一个人，没有持续的存在，每次对话都是启动、处理 token、关闭，对话内容构成上下文窗口，结束后就全部清除，每次对话都从头开始，没有持久的自我。默认情况下得到的是随机的答案：他用 Falcon 测试，它说自己是 OpenAI 基于 GPT-3 开发的。他认为这未必说明它用了 OpenAI 的数据，更可能是因为预训练的互联网文档里有大量关于 ChatGPT 和 OpenAI 的内容，微调时模型又没被告知该如何称呼自己，于是就“幻觉”出了这个标签。

开发者可以覆盖这个设定，有两种办法。一是在训练数据里写进去：他以 Allen AI 的完全开源模型 OLMo 为例，其 SFT 数据混合体共约 100 万条对话，其中有一份“硬编码”的 240 条对话，例如“介绍一下你自己”“你叫什么名字”，回答是“我是 Allen 人工智能研究所开发的开放语言模型 OLMo……”，用这些微调后模型就会照着说，不加的话它多半会说自己是 OpenAI 的 ChatGPT。二是用系统消息（system message）：对话开头有一条用户看不到的消息，写明“你是 OpenAI 开发的模型，名字是 ChatGPT-4o，训练于某日期，知识截止于某日期”，这些 token 在上下文窗口里提醒模型它的身份。这些都是后来“拧上去”的，不像人类的自我认知那样深。

**十、大模型“心理学”之三：模型需要 token 来思考**

这一节讲模型在解题时的计算能力。例题：Emily 买了 3 个苹果和 2 个橙子，每个橙子 2 美元，总共 13 美元，苹果多少钱？有两个答案，都得出 3 美元，但一个先写“答案是 3 美元”再解释，另一个先一步步算出中间结果再得出 3。讲者说其中一个会让模型的数学变得很差，请听众暂停想想。

原因是：模型生成是从左到右一个 token 接一个 token，每个 token 都是把前面所有 token 输入网络、经过有限层（这里的演示网络只有几层，先进模型大约一百层）的计算得到概率分布，所以每个 token 的计算量是有限且基本固定的，不可能在一个 token 里做任意复杂的计算，推理和计算必须分摊到许多 token 上。先写答案的版本，等于要求模型在“答案是 $”之后的那一个 token 里把整道题的计算全部塞进去，后面写的解释只是对已经产生的答案的事后辩解；而分步的版本先得出“橙子总共 4 美元”“13−4=9”“9÷3=3”等中间结果，每一步都很简单，到末尾时前面的结果已经在工作记忆里，答案就容易得出。所以对话数据里的标注必须把计算摊开；普通用户一般不用操心，因为 OpenAI 的标注员会注意这一点，他问 ChatGPT 这道题，它就会一步一步“定义变量、列方程”，这些中间结果是写给模型自己的，不是给用户看的。

他还“刁难”了模型一下：要求用单个 token 立刻回答，对于这道简单的题它居然能一次答对（实际是两个 token，因为美元符号单独算一个）；他把数字改成 23 个苹果、177 个橙子，模型回答了 5，是错的，因为一次前向计算装不下；然后让它不管 token 限制、按常规解，它就写出所有中间步骤，得出正确答案 7。

他在实际使用中不完全信任模型的“心算”，数字大时尤其如此，中间任何一步都可能出错，所以他会说“用代码”：模型写出 Python 程序，交给另一部分计算机运行，把结果带回来，他可以检查代码，而且 Python 比语言模型的心算更有正确性保证。他用这一节总结：模型需要 token 来思考，要把计算分摊到许多 token 上，让它产出中间结果，能用工具就用工具。

数数是同样的问题：他让 ChatGPT 数一串点有多少个，让它一个 token 回答，会出错。这串点在模型眼里被切成几个 token（他在分词器里看到，大约 20 个点是一个 token），模型要靠这些 token ID 去数，答案其实是 177，而它说 161。让它“用代码”就对了：模型很擅长复制粘贴，把输入原样复制成 Python 里的字符串，再调用 count，由 Python 解释器来数，得到正确的 177。

**十一、大模型“心理学”之四：拼写与参差不齐的智能**

模型也不擅长拼写类任务，因为它们看不到字符，只看到 token。例子：给出 “ubiquitous”，要求从第一个字母开始每隔三个字母打印一个，模型答错了；这个词在分词器里是三个 token，人可以直接在视觉上索引每个字母，模型却不行，它必须从训练中自己摸索每个 token 里装了哪些字母。使用 token 主要是为了效率，不少人希望取消分词、改用字符级或字节级模型，但那会让序列过长，目前还不知道怎么处理。同样可以让模型用代码来做：把词复制进 Python，由解释器按位置取字符，结果是 u、q、s，正确。著名的例子是“strawberry 里有几个 r”：它在网上火过很多次，很长一段时间里所有顶尖模型都坚持说只有两个 r，原因是模型既看不到字符又不擅长数数，两个弱点叠加；现在已经答对了，他说可能是 OpenAI 做了硬编码。

他还举了一个至今让人摸不着头脑的例子：问“9.11 和 9.9 哪个大”，模型有时说 9.11 更大并给出理由，有时在最后又改口，有时始终答错，也有时答对，可结果并不稳定。而同一个模型能做奥赛级的数学题，能答博士水平的物理、化学、生物题。他听说有团队研究过网络内部的激活，发现这时许多通常与《圣经》经文有关的神经元被点亮；在经文的编号里，9.11 排在 9.9 之后，所以模型似乎被这种联想干扰了，即使它在试图用数学论证，也会得出错误答案。这件事至今没有被完全理解。他的结论是：要把它当作一个神奇但不能完全信任的随机系统，把它当工具，而不是放手让它去做、再把结果直接复制粘贴。

**十二、小结：两个阶段**

他回顾前两个阶段：预训练在互联网文档上训练，得到基座模型，需要数千台电脑训练数月，是互联网的有损压缩，但直接用处有限；后训练中的监督微调算法上与预训练相同，只是把数据集换成人与助手的百万级、主题多样的对话，对话由人（借助语言模型）按标注指南创建，得到助手。助手若不加缓解措施会产生幻觉，可以借助网络搜索、代码解释器等工具改善。接下来讲第三阶段，强化学习，它仍然属于后训练，但是第三个主要阶段。在 OpenAI 这样的公司里，预训练的数据、预训练的训练、对话生成与监督微调、强化学习分别是不同的团队，模型像接力一样依次交接。

**十三、强化学习：用上学来类比**

他用上学做类比。教科书里有三类内容：大量讲解（exposition），读这些相当于预训练，建立知识库；带详解的例题，专家给出完整的解法，读它们相当于监督微调，模型学着模仿专家；每章末尾的练习题，只给题目描述和书后答案里的最终答案，不给解法，要自己尝试各种做法、看哪种能得到答案，这就是强化学习。人类做这类练习时用到预训练的背景知识，还有一点对专家的模仿。

回到苹果和橙子的题。同一道题可以有四种写法，都得到 3：列方程组，用英文一步步讲，或者直接跳到结果。一个解法有两个目的：一是得到正确答案，二是向人清晰呈现。如果只关心得出正确答案，标注员并不知道哪种写法对模型最好：例如“30−4÷3 =”那一步要求在单个 token 上完成很多计算，可能对模型太难；而另一些步骤可能对模型是小菜一碟，写出来就是浪费 token。人觉得容易或困难的，与模型不同，模型的认知方式不同。模型的知识也与我们的不同：它有大量博士级数学、物理、化学知识，我们的解法可能没有利用到；反过来，我们可能在解法里放入了模型参数里没有的知识，让它觉得突然跳了一大步。所以人类不适合为模型写这些 token 序列，示例只能通过模仿用来初始化模型，真正有效的序列要让模型自己在强化学习的试错过程中发现。

具体做法：他在 Hugging Face 推理试验场里选了一个 20 亿参数的 Gemma 小模型，对同一个提示反复运行，每次生成的解法略有不同（因为每个 token 都在采样），这道题太简单，几次都得出了正确的 3 美元。实践中，对一个提示可能采样上千甚至上百万个独立解法，有的对有的错，要鼓励那些得出正确答案的。他用示意图说明：生成了 15 个解法，只有 4 个答案正确（绿色），其余是红色；然后在这些正确的解法上训练，这些训练序列不是人写的，而是模型自己产生的，相当于学生检查自己的解法，发现某种做法有效，就以后多这样做。可以只选其中最好的一个（比如最短、看起来最好的），更新参数后，模型在类似情形下走这条路径的概率就会稍高。这件事在数以万计的提示（数学、物理等各种题目）上、每个提示上千个解法的规模同时进行，模型在迭代中自己发现哪些 token 序列能可靠地得到正确答案，这些序列没有思维跳跃，并充分利用了模型自己的知识。这就是“猜测并检验”。

在这个流程里，SFT 模型仍然有用，它把模型初始化到正确解法的附近（比如会列方程或者会一步步讲），而强化学习才是把一切调准的环节。他总结：训练大模型很像教孩子，只是孩子是在每一章里依次接受这几种训练，而 AI 是分阶段进行——先在所有教科书的讲解上预训练；再在所有教科书的例题详解上做监督微调，得到只会盲目模仿专家的模型；最后在所有教科书的练习题上做强化学习。

他指出，预训练和监督微调已有多年历史，是业界标准，而强化学习阶段还很早期，没有标准化。核心思想很简单（试错学习），但细节很多：怎样选最好的解法、训练多少、提示的分布如何、怎样设置训练使其真正起作用。OpenAI 等公司内部实验了一段时间，却没有公开。所以 DeepSeek 刚发布的论文影响很大：这家中国公司公开讲了大语言模型的强化学习微调，以及它对大模型多么重要、如何催生推理能力，并给出了复现所需的诸多细节，重新点燃了公众对 RL 的兴趣。

**十四、DeepSeek-R1：思维的涌现**

论文的图 2 显示了模型在数学题（AIME 题目）上的准确率，随着数千步更新持续上升，模型在大量题目上经过试错学会了怎么解题。更值得注意的是定性的变化：训练后期，每个回答的平均长度上升，模型用更多 token 来获得更高准确率。论文里的例子是，模型自己出现了类似“等等，这是个值得标出的顿悟时刻（aha moment）。让我们一步步重新评估……”的话，也就是重新检查步骤、从不同角度尝试、回溯、重新组织。他强调这是优化中涌现出来的特性，没有人能把它写进理想的助手回答里，因为人不知道该写什么，这是我们在脑子里做、却没有写在解题过程里的东西；这就是思维链，也是回答变长的原因，同时也提高了解题准确率。模型学到的是他称之为“认知策略”的东西：如何从不同角度处理问题、引入类比、反复尝试和验证。而人只给了正确答案。

他把同一道苹果题放给推理（思考）模型。DeepSeek-R1 可以在 chat.deepseek.com 上用，要打开“DeepThink”按钮。输出里它说“让我想想看……”，算出 3 美元，然后说“等一下，我再验算一遍”，换个角度再算，说“对，都对得上”，再想“有没有别的方法，比如设方程，设苹果价格为 8 ……”，得到同样的答案，确信后才为人类写出一份整洁的解答，并把答案框起来。这就是正确性（思考过程）和呈现（整理后的答案）的分离。他此前在 GPT-4o 上得到的则是模仿专家解法的 SFT 式回答。

对担心把敏感数据发给中国公司的人，他指出 DeepSeek-R1 是开源权重的模型，可以下载，但完整精度的大模型无法在笔记本上跑；许多公司托管完整的大模型，他常用的是 together.ai，在它的 playground 里选 DeepSeek R1 即可，因为模型相同，能力相同，只是采样随机性导致结果略有差异，而它来自美国公司。

ChatGPT 的模型下拉菜单中，o1、o3-mini、o3-mini-high 等标有“使用高级推理”，据 OpenAI 员工的公开说法，它们是用与 DeepSeek-R1 非常相似的技术经强化学习训练的思考模型，可能要付费订阅（每月 20 美元或 200 美元的档位）才能用；而 GPT-4o、4o mini 等免费版本应当看作主要是 SFT 模型，不会像 RL 模型那样思考，虽然也涉及一点强化学习。他演示 o3-mini-high：界面上显示“推理中”，但 OpenAI 不展示完整的思维链，只展示摘要，他认为部分原因是担心“蒸馏风险”，即别人模仿这些推理链来恢复推理能力。他的看法是，这些模型与 DeepSeek 目前性能相当，评测难以分辨，付 200 美元订阅的最高档模型看起来仍略好，但 DeepSeek-R1 仍是可靠的思考模型选择。

使用上，对简单问题、基于知识的问题，思考模型可能是杀鸡用牛刀，没必要为事实性问题想 30 秒，所以他 80% 到 90% 的使用是 GPT-4o，遇到数学、代码等很难的问题才用思考模型，等得久一点。他还提到谷歌 AI Studio（aistudio.google.com）里的 Gemini 2.0 Flash Thinking Experimental 01-21 也是谷歌的早期实验性思考模型，同一道题也答对了；Anthropic 当时还没有思考模型。他说 RL 是令人兴奋的新阶段，但细节很难，因此这些模型在 2025 年初都还处于实验阶段。

**十五、AlphaGo 与“第 37 手”**

强化学习的强大并非 AI 领域的新发现，围棋里已经证明过：DeepMind 的 AlphaGo（有同名纪录片）。在 AlphaGo 的论文里有一张图，比较了监督学习模型和强化学习模型的 Elo 等级分，以及李世石（Lee Sedol，强大的人类棋手）。监督学习模型模仿专家棋谱，能进步但会触顶，永远赶不上顶级棋手，因为只模仿人就不可能超越人；而强化学习中，AlphaGo 通过自我对弈，做大量尝试，赢棋的对局被强化，学到的是经验上、统计上能赢的行动序列，不受人类水平限制，可以超过李世石（论文里只是因为花钱才在某个点截止）。图的结构与 LLM 的情形一样，只是围棋没有提示，是固定的游戏。他认为在大语言模型的推理问题上我们才刚刚看到这种图的苗头，光靠模仿专家走不远，需要建立类似小游戏的环境，让系统发现独特而有效的解题轨迹。

强化学习没有什么会阻止系统偏离人类下棋的分布。论文中提到的“第 37 手”，是 AlphaGo 走的一步没有人类专家会走的棋，人类下这一步的概率被评估为约万分之一，但事后看是妙手。他推荐 YouTube 视频“李世石对 AlphaGo 第 37 手的反应与分析”，里面棋手说“这是一步很让人惊讶的棋，我以为那是个错误”。同理，如果继续扩大这一范式，大模型会是什么样不得而知：也许是发现人类想不到的类比，也许是新的思考策略，甚至可能发明一种不是英语的语言，因为模型不被限制必须使用英语，行为不那么确定，可以随便什么管用，也可以慢慢偏离训练数据的英语分布。前提是要有非常大而多样的题目集，让这些策略得以打磨；这正是前沿大模型研究在做的事情，创建大而多样的提示分布，也就是让模型练习思考的各种“游戏环境”，相当于为所有知识领域编写练习题。

**十六、不可验证领域：RLHF**

前面的问题都属于“可验证领域”：每个候选解可以很容易地和具体答案对比，要么要求模型把答案框起来，直接检验框里的内容是否相等，要么用“LLM 评委”，让一个语言模型对照答案判断解法是否一致，目前的模型足够可靠，全程无需人工。而创意写作（写一个关于鹈鹕的笑话、写诗、总结一段话）是不可验证的，难以给不同解法打分。他让 ChatGPT 写了鹈鹕笑话（一个是鹈鹕嘴里装了太多东西，因为它们不会背背包；一个是鹈鹕为什么从不付酒钱，因为总是把账单记到别人头上），评论说模型不擅长幽默，他觉得幽默其实很难。

原则上可以让人评分，但强化学习要做成千上万次更新，每次更新有成千个提示，每个提示又有成百上千个生成，规模太大，不可扩展。OpenAI 当时的一篇论文（其中不少作者后来成为 Anthropic 联合创始人）提出了基于人类反馈的强化学习（RLHF）：核心技巧是“间接”，只让人参与一点点，另训练一个独立的神经网络，称为奖励模型（reward model），去模仿人的打分，成为人类偏好的模拟器，然后针对这个模拟器做 RL，可以无限次地查询，全自动。按他给的示意数字，如果完全由人评：1000 次更新 × 每次 1000 个提示 × 每个提示 1000 个生成，需要人评 10 亿次笑话。

奖励模型怎么训练：对“写一个关于鹈鹕的笑话”这个提示，取五个生成的笑话，请人从最好到最差排序（让人排序而不是直接打分，因为排序容易得多）。奖励模型是完全独立的神经网络（大概也是 Transformer，但不是生成语言的模型，只是打分模型），输入是提示和一个候选笑话，输出一个 0 到 1 之间的分数。将它的打分与人的排序比较（有精确的损失函数），再更新：例如人认为最好笑的第二个笑话，模型给了 0.8，已经较高，更新后会再升高一点；人排第二、模型却只给了 0.1 的那个，更新后会大幅升高；人认为最差、模型却给了较高分的，更新后会降下来。这样奖励模型越来越接近人的偏好。人只需要看大约 1000 个提示、每个五个笑话，共约 5000 个笑话。

RLHF 的好处：能在任意领域做强化学习，包括摘要、写诗、写笑话等创意写作和其他数学代码之外的领域；经验上做对了模型会好一点。为什么有效，他说没有很确定的说法，只给出自己的最佳猜测：“判别者—生成者差距”，对人而言判别往往比生成容易得多。SFT 要求标注员写出理想回答，摘要、写诗、写笑话这类任务需要创造性写作，很难；RLHF 只要求人从模型给的五首诗中排序，这是容易得多的任务，能得到更高准确度的数据，让人不做生成而只做区分，然后系统自己去发现什么样的回答会被人评高分。

缺点：一是强化学习针对的不是真实的人的判断，而是人的有损模拟，可能产生误导。二是更隐蔽的问题：RL 极其擅长钻奖励模型的空子。奖励模型是有数十亿参数的大型神经网络，存在训练集之外的输入能得到莫名其妙的高分。如果运行很多更新（例如 1000 次），前几百步鹈鹕笑话会变好，然后断崖式崩坏，开始出现荒谬的结果，比如最佳笑话变成“the the the the”，奖励模型却给它 1 分的满分。这类样本叫对抗样本。你可以把“the the the”加进数据集并给它最低分，模型会学会给它零分，但模型里永远存在无穷多的荒谬对抗样本，这样反复补永远赢不了，RL 跑得足够久总会找到办法欺骗它。所以实践中 RLHF 只跑几百次更新，模型变好后就截止、发布，也可以改进奖励模型，但总会再遇到这种情形。

他的说法是“RLHF 不是 RL”：它当然是 RL，但不是那种神奇的、可以无限运行的 RL。在可验证领域（如框出的答案是否正确），评分函数很难被钻空子，可以跑几万、几十万步，发现我们可能根本想不到的奇异策略；围棋也一样，有完美的模拟器，输赢无法作弊，所以可以无限跑，最终击败李世石；而奖励模型可被欺骗，所以 RLHF 更像一种小幅的微调，而不是只要投入更多算力、跑更久就能得到神奇结果的东西。GPT-4o 就经过了 RLHF，因为它有效，但本质是对模型的一点微调。

**十七、三个阶段回顾**

这是他计划讲的技术内容的结尾。他回顾了预训练、监督微调、强化学习三个阶段，与教孩子的过程大致对应：预训练是读讲解、获取基础知识；监督微调是看大量例题详解、模仿专家；强化学习是做练习题。不同的是，现在要为 LLM 和 AI 编写覆盖人类所有知识学科的“教科书”，还有数学、代码等我们希望它们能用上的情形，并改进他讲过的各种算法，再把这些大规模、高效地训练好。他没有深入的一点是，这些训练是极其庞大复杂的分布式任务，要在几万甚至几十万块 GPU 上运行，其背后的工程处于计算机在这种规模上能做到的最前沿。

**十八、未来趋势**

- 多模态：前面讲的都是文本，很快会出现可以原生处理音频（能听会说）和图像（能看会画）的模型，会带来自然对话。做法没有本质区别，只要对音频、图像做分词，再用同样的方法训练：音频可以取频谱图的切片来分词，图像可以切成小块（patch）分别分词，图像就是一串 token，这些 token 与文本交织在同一个模型里处理，已经有不少早期工作。
- 智能体（agent）：目前大多是我们把单个任务“用银盘端给”模型，由人来组织连贯执行；模型还不能在长时间内连贯地纠错、把任务串成较长的工作，但在进步。接下来会看到长时间运行的智能体，任务不是几秒，而是几十秒、几分钟甚至几小时，人会定期查看进展；因为模型并非无错，仍需监督。他以工厂里谈论“人与机器人比例”为例，说数字领域会谈论“人与智能体的比例”，人更多地成为智能体任务的监督者。
- 更普及、更隐形：AI 会融入各种工具，无处不在；还有“使用电脑”：现在模型还不能代你操作，但 ChatGPT 刚推出的 Operator 是早期例子，可以把键盘鼠标的控制权交给模型。
- 研究空白：例如测试时训练（test time training）。目前模型有训练阶段和推理阶段两个阶段，参数训练好后固定、部署，模型在使用中不再学习，唯一的测试时学习是上下文里的 token 带来的上下文学习，而人是真正会在做事时学习的，睡觉时大脑也在更新“参数”，模型和工具里还没有对应物。他认为这会是必要的，因为上下文窗口是有限而珍贵的资源，当开始处理很长的多模态任务（比如放入视频）时，token 窗口要增长到远超几十万的规模，目前唯一的办法就是把上下文窗口做长，但这样本身扩展不到真正长时间的多模态任务，需要新的想法。

**十九、如何跟进最新进展**

他常用三个渠道。第一是 LM Arena：LLM 排行榜，基于人类对比：用户向匿名的模型提问，判断哪个回答更好，据此计算排名。他展示时谷歌 Gemini 排第一，OpenAI 紧随其后，DeepSeek 排第三，而最后一列的许可证显示 DeepSeek 是 MIT 许可、开放权重，任何人都可以下载、自己托管、随意使用，这样强的模型以开放权重发布是前所未有的。再往下是更多谷歌和 OpenAI 的模型，然后是 xAI、Anthropic 的 Sonnet（第 14 位）、Meta 的 Llama（同样开放权重，排名靠后）。他说这个榜单很长时间都很好，但最近几个月有点被“刷榜”，不像以前那么信任，因为经验上很多人都在用 Anthropic 的 Sonnet，觉得它是很好的模型，却排在第 14，而用的人不那么多的 Gemini 却排得很高；所以只当作初筛，仍要针对自己的任务试用几个模型。第二是 swyx 等人维护的 AI News 通讯，几乎隔天一期，内容全面，部分由人撰写和整理，大量由语言模型自动生成，顶部的摘要质量不错，有人工把关。第三是 X（推特），很多 AI 动态在上面，关注自己喜欢和信任的人。

**二十、在哪里使用模型**

- 大型闭源模型：去各家官网，OpenAI 是 chatgpt.com，谷歌是 gemini.google.com 或 AI Studio（他不明白为何有两个）。
- DeepSeek、Llama 等开放权重模型：用推理平台，他最喜欢 together.ai，playground 里可以选各种开放模型对话。
- 基座模型：即使在这些推理平台上也不常见，因为它们都面向助手和聊天；他用 Hyperbolic，因为它托管 Llama 3.1 基座模型，他希望有更多人托管基座模型。
- 本地运行：最大的 DeepSeek 无法在 MacBook 上运行，但有蒸馏过的小版本，还可以用更低的精度（不是 DeepSeek 原生的 FP8，或 Llama 的 BF16，而是低得多）来运行，这样能放进电脑，在笔记本上跑出还不错的模型。他常用的是应用 LM Studio，他觉得界面难看、易用性差，面向专业人士，列出五百种让人眼花缭乱的模型，要选择不同的蒸馏版本和精度，理解后才好用（这需要单独一个视频讲）。他演示加载了 Llama 3.2 instruct 1B，让它讲鹈鹕笑话，全在本机 MacBook Pro 的 GPU 上运行，不连别人的服务器，用完可以“弹出”模型来释放内存。

**二十一、回到那个输入框**

最后他回到开头的问题。用户的问题先被切成 token，放进对话协议格式里的用户位置，整个变成一维的 token 序列；点下回车后，ChatGPT 像自动补全一样继续往序列后追加 token，这就是它给出的回答。

预训练阶段本质上是把互联网上的知识获取到神经网络的参数里；而“人格”来自监督微调：OpenAI 这样的公司整理出约一百万条主题多样的人与助手对话（虽然过程中大量使用合成数据和语言模型帮助，本质上仍是由人参与的数据整理工作），由受雇的标注员按学习过的标注指南，为任意提示写出理想的助手回答，用示例教会神经网络如何回应。所以他认为，回答可以理解为对 OpenAI 一位标注员的神经网络模拟：好像把问题交给这位标注员，他先读完标注指南，再花两个小时写出理想的回答，只是我们并没有等两个小时，得到的是一个模拟；而且神经网络不像人脑，什么容易、什么困难与人不同，每个 token 的计算量有限，所以这是一种受限的、有损的模拟，也因此会出现幻觉和“瑞士奶酪”式的能力：整体非常强，却处处有孔，有时会莫名犯傻：没给足够的 token 思考、心算出错而编造答案、数不清字母、说不对 9.11 和 9.9 谁小。

使用思考模型（如 o3-mini）时情形有些不同。GPT-4o 基本没有做强化学习，只做了 RLHF，而 RLHF 不是真正的 RL，只是小幅微调；思考模型则做了 RL，经过第三个阶段，练习思维过程，发现新的思考策略和解题方法，看起来有点像头脑里的内心独白，在公司创建和整理的大量练习题上练习。这时得到的不再只是对人类标注员的模仿，而是涌现出来的思考，是新的、有趣的东西；OpenAI 没有展示底层的思维链，我们看到的只是摘要。至于在可验证领域（数学、代码）发展出的思考策略能否迁移、推广到创意写作之类不可验证的领域，业内还不清楚。强化学习目前还很新、很原始，但在推理问题上已经看到了苗头，原则上可以做到类似“第 37 手”那样的事，只不过是在开放领域的思考和解题上，做出人类没有想到的东西、人类没有过的类比；目前它们主要在数学、代码这类可验证的领域发挥所长。

他最后说，这是进入这个领域非常激动人心的时刻。他自己每天要用这些模型几十次到上百次，工作因此大大加快，他认为这些模型会带来大量财富创造。他提醒要了解它们的缺点，即使是 RL 模型也会有这些问题：要把它们当作工具箱里的工具，不要完全信任，因为它们会随机地犯傻、产生幻觉、跳过心算而算错、数不清数。用它们找灵感、写初稿、提问，但一定要检查和核实，并对自己工作的成果负责。
