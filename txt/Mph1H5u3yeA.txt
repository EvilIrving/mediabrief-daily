这是 Better Stack 的一期技术短片，主持人 Andris 介绍 Docker 开源的 Docker Agent。他的核心观点是：搭建 AI 智能体不必再写大量 Python 样板代码，几个 YAML 文件加一条命令就够了。

Docker 的说法是，Docker Agent 之于智能体，就像 docker run 之于容器。在 YAML 里写明模型、指令和可用工具，“调用模型、执行工具、回传结果、循环到完成”这套流程就由它代管。模型可以接 OpenAI、Anthropic、Gemini、OpenRouter，也可以接本地模型；工具既有文件读写、Shell 等内置能力，也能挂任意 MCP 服务器，还支持协调者把任务分给子智能体。主持人最看重三点：智能体成了配置，能做版本管理、走代码审查，换模型只改一行；能像容器镜像一样推到 Docker Hub 等仓库分发；一条命令就能把智能体变成 HTTP API、MCP 服务器或 A2A 服务器，供别的智能体调用。

演示部分围绕 A2A 展开。第一个是值班排障：日志分析智能体只有日志目录的只读权限，值班助手没有任何文件权限，只知道分析员的地址。问它结账服务为何报 500，问题会转给分析员，分析员查完日志和部署记录回传结论，再由助手整理成事故摘要。这就是“别的团队可以提问，但碰不到日志”的权限隔离思路。第二个是海战棋：GPT-6 Luna 和 Claude Haiku 5.5 各自作为独立服务对战，裁判用中立的 Kimi K3。双方一路打到各剩最后一艘船，最后 Haiku 以 34 发、50% 命中率险胜。主持人强调这不算基准测试。

他的结论是：用 YAML 写、一条命令跑、靠镜像仓库分享、凭一个 URL 互联，Docker Agent 把智能体开发大大简化了，他今后会常用。
