从 GPT-2 到 2026 年的前沿大模型，大语言模型的核心基础架构依然建立在因果解码器自回归 Transformer 骨架之上。七年间位置编码从绝对位置嵌入演变为旋转位置编码（RoPE），多头注意力（MHA）全面转向分组查询注意力（GQA）与潜在压缩注意力，激活函数从 GELU 收敛至 SwiGLU，密集模型普遍分化为稀疏专家混合架构（MoE）。整体架构演进的核心推动力并非破坏性范式重构，而是围绕显存开销削减、长上下文计算复杂度下降、推理并行吞吐优化与训练稳定性展开的深度工程微调。

一、DeepSeek V3 与 R1：现代高能效架构的基准标杆
DeepSeek V3 及其推理衍生版本 R1 奠定了当代前沿开源架构的基础模板，其技术核心由两项关键设计驱动：
1. 多头潜在注意力（MLA）：不同于 GQA 依赖多个查询头共用同一组 Key/Value 头的物理共享方案，MLA 将 Key 与 Value 联合投影压缩为低维潜在向量（Latent Vector）并进行缓存，自回归解码时仅需常驻低维潜在向量，计算注意力时通过解耦投影矩阵动态还原，并在外部补充独立的解耦 RoPE 向量保留相对位置信息。消融实验证明，调优后的 MLA 不仅将自回归推理阶段的 KV 缓存显存占用压缩至传统 MHA 的极小比例，其跨任务表征性能甚至超越全量 MHA 基线。
2. 细粒度专家混合架构（DeepSeekMoE）：V3 拥有 6710 亿总参数，每层配置 256 个极小专家与 1 个固定激活的共享专家，每次推理仅动态路由激活 8 个专家，使单 Token 激活参数量严格控制在 370 亿。共享专家始终激活以捕获跨领域的通用语言特征，路由专家专注于特化分支，配合无辅助损失的负载均衡路由策略，从根本上消除了辅助损失对主语言建模目标的干扰。此外，模型引入多 Token 预测（MTP）训练目标，通过级联辅助预测头并行预测后续多个 Token，不仅增强了前向表示的规划能力，更可直接用于推理阶段的推测解码（Speculative Decoding）以成倍拉升文本生成吞吐。

二、归一化拓扑与注意力窗口重构（OLMo、Gemma、Mistral、Llama）
1. OLMo 2 与 OLMo 3 的归一化重构：OLMo 2 全面转向 RMSNorm，并将归一化层置于注意力和前馈模块之后、残差连接内部（构建了一种非传统的 Post-Norm 变体），同时引入 QK-Norm（在施加 RoPE 之前分别对 Query 和 Key 实施 RMSNorm），从根源上平抑了深层网络内部注意力激活值的异常极大值，避免训练损失震荡。OLMo 3 进一步演进，7B 规格采用 MHA 配合 3:1 滑动窗口，32B 规格全面转向 GQA，并在全局注意力层集成 YaRN 频域插值算法，将有效上下文无损扩展至 64k。
2. Gemma 3、Gemma 3n 与 Gemma 4 的局部稀疏化：Gemma 3 采用极激进的滑动窗口注意力（SWA），将局部层与全局层的交替比例从 Gemma 2 的 1:1 扩大至 5:1，并将局部窗口压缩至 1024 Token；在归一化拓扑上采用“三明治”布局，在注意力模块前后均配置 RMSNorm 兼取 Pre-Norm 与 Post-Norm 之长。端侧特化模型 Gemma 3n 则引入逐层嵌入（PLE），将高显存占用的词表嵌入参数卸载至外部介质按需流式加载，并融合 MatFormer 嵌套结构，实现单个母模型按需切分出轻量级独立子模型。最新的 Gemma 4 则在全局层引入激进的 Values = Keys 投影复用机制（直接省去独立的 Value 投影矩阵参数与显存开销），并采用仅对 25% 频率分量施加旋转的 p-RoPE，以极简的结构调优在综合基准上追平大参数量竞争对手；其 MoE 版本（26B-A4B）仅需激活 4B 参数即逼近 31B 稠密模型的性能上限，展现出极高的参数转化效率。
3. Mistral Small 3.1 24B 的工程取舍：该模型在相同计算量下超越 Gemma 3 27B，其关键工程决策在于彻底摒弃滑动窗口注意力，采用原生统一的 GQA 架构。尽管滑动窗口能节约理论显存，但统一注意力能无缝兼容硬件底层的 FlashAttention 融合算子，换取更低的端到端执行延迟。
4. Llama 4 Maverick 的交替稀疏：Llama 4 采用与 DeepSeek 截然相反的专家策略，采用少而大的专家配置（单层仅激活 2 个大专家，隐藏层维度达 8192），并采用 MoE 层与稠密前馈层隔层交替拓扑，在 4000 亿总参数下将激活参数压至 170 亿。

三、参数形态与专家粒度分化（Qwen3、SmolLM3、Kimi K2、gpt-oss、Grok、GLM）
1. Qwen3 的双轨演进：Qwen3 体系同步推出了从 0.6B 到 32B 的稠密模型，以及 30B-A3B、235B-A22B 的 MoE 模型。其 MoE 版本移除了 DeepSeek 风格的共享专家，以规避共享专家在分布式推理部署中引发的通信开销与推理调度瓶颈。超小规格 0.6B 采用“深而窄”结构，兼顾端侧低内存占用与高知识密度。
2. SmolLM3 与周期性无位置编码（NoPE）：SmolLM3 3B 引入了无位置编码机制，完全不显式注入 RoPE 或绝对位置嵌入，仅依赖自回归因果掩码的天然下三角结构隐式提供时序信息。为兼顾长文本外推与局部精度，模型每 4 层中有 1 层采用 NoPE。
3. Kimi K2 的超大规模 MoE：Kimi K2 达到万亿级总参数，在架构上作为放大的 DeepSeek V3 变体，其最大工程亮点在于全面采用 Muon 矩阵优化器替代传统的 AdamW，在大规模分布式预训练中展现出更陡峭的损失下降曲线；后续推出的 Thinking 版本更将原生上下文直接拉伸至 256k。
4. OpenAI gpt-oss 的宽浅与硬件单卡化：gpt-oss（20b 与 120b）逆潮流采用了“宽而浅”设计（20b 仅设 24 层，隐藏层维度扩展至 2880），在并行硬件上具备更高的吞吐上限。专家层采用大粒度配置（32 个专家激活 4 个），重新引入注意力线性层偏置，并以头独立学习标量实现注意力汇元（Attention Sinks）。更关键的是其专家权重原生采用微缩浮点 MXFP4 格式量化，使 120B 旗舰模型能够直接跑在单张 80GB H100 显卡上，彻底摆脱多卡张量并行的通信开销。
5. Grok 2.5 与 GLM-4.5 的工程设计：Grok 2.5 揭示了工业级线上系统的架构形态，采用大颗粒度专家搭配单一 SwiGLU 共享专家；GLM-4.5 则在底层前置 3 个连续的稠密 Transformer 层，使模型在底层先收敛形成稳定的语义表征，再输入后续 MoE 路由器进行分支决策。

四、线性状态空间与混合架构的演进波折（Qwen3-Next、MiniMax、Kimi Linear、Nemotron）
自回归注意力机制随序列长度呈二次方增长（O(N^2)）的计算瓶颈，推动了线性注意力与混合架构的密集实验：
1. Qwen3-Next 与 Gated DeltaNet：Qwen3-Next（80B-A3B）采用 3:1 的混合架构，将 3 层 Gated DeltaNet 与 1 层门控注意力（Gated Attention）交替排列。Gated DeltaNet 引入快速权重记忆矩阵（Fast Weight Memory）与输入/遗忘双门控，依据 Delta 规则进行线性复杂度状态更新；保留的门控注意力层则通过输出门、零中心 QK-Norm 与部分 RoPE 保障全局高精度信息检索，原生支持 262k 超长上下文，并配合多 Token 预测（MTP）加速推测解码。
2. MiniMax 的架构往返：MiniMax 在 M1 采用基于线性注意力的 Lightning Attention，但在随后的 M2 旗舰模型中彻底回退至标准全注意力机制，其团队明确指出纯线性注意力在严密多步推理与多轮长会话上下文保持上存在无法忽视的精度缺陷。M2 转向为每个注意力头配置独立参数的 QK-Norm、无共享专家的超低激活率 MoE（激活率仅 4.37%），并引入仅旋转半数维度的 Partial RoPE 以防止未见序列极值外推失真。
3. Kimi Linear 的通道级增强：Kimi Linear 重新押注 3:1 混合架构，提出 Kimi Delta Attention（KDA），将 Gated DeltaNet 中的标量门控细化为逐通道门控（Per-channel Gating），并在全局层采用不带 RoPE 的 MLA。在保持线性级推理延迟的同时，KDA 显著提升了长程联想记忆检索的保真度。
4. NVIDIA Nemotron-3 的 Mamba-2 混合：Nemotron-3 Nano 构建了 52 层以 Mamba-2 为主干、穿插极少数全局注意力层的混合拓扑；Super 120B 则引入了在 1024 维潜在表征空间内计算的超紧凑 MoE 专家，大幅压低分布式通信开销。

五、2026 旗舰模型的最新收敛（Trinity Large、GLM-5、DeepSeek V3.2）
1. Arcee Trinity Large：融合各家工程优势，采用 3:1 局部与全局注意力交替，在全局层采用 NoPE 架构与逐元素门控，并引入增益随深度按 1/sqrt(L) 缩放的双重 RMSNorm 三明治归一化。
2. DeepSeek V3.2 与动态稀疏注意力（DSA）：在 MLA 潜在压缩缓存的基础上引入 DSA 机制。DSA 摒弃了静态固定的滑动窗口限制，通过内置的轻量级“闪电索引器”（Lightning Indexer）对历史 Token 进行重要性打分，动态筛选 Top-k 关键 Token 计算精确注意力，兼具次二次方计算复杂度与长程注意力敏锐度。
3. GLM-5 的高效长文本落地：在 744B 总参数规模下全面采纳 MLA 潜在压缩与 DeepSeek 动态稀疏注意力（DSA），将层数压缩至 78 层以减少前向流水线延迟，在保持长文本极端推理精度的同时大幅削减首字延迟。

纵观主流前沿架构，各大实验室的技术选型最终高度收敛于四个核心工程旋钮：KV 缓存压缩路径（GQA、MLA、滑动窗口还是混合线性状态空间）、MoE 专家粒度与路由共享机制、归一化拓扑与数值防溢出设计，以及位置编码的稀疏化注入。随着硬件协同与系统工程的深化，架构微调带来的纸面红利正逐步让位于高质量数据配比、训练中期的退火策略以及后训练阶段基于可验证奖励的推理算力扩展。
