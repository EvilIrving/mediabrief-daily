Kimi K3.1 Pro、新的网络现实与 Muse 随想 ｜ Interconnects ｜ 46:42 ｜ https://www.interconnects.ai/p/podcast-kimi-k31-pro-the-new-cyber

这期约 47 分钟的播客里，Nathan Lambert 与 Florian Brand 先聊 Kimi K3.1 Pro，再谈网络安全这周的乱局，最后落到 Anthropic 的招聘和 Florian 的 Muse 体验。

Kimi K3.1 Pro：分数很高，反响分化。 Florian 说 Kimi 过去几代都兑现了预期，这次却有点怪：发布前搞了更大的社交媒体宣传，据称还涉及付费发帖却不要求披露；有人贴出新闻指令截图，写着“不要说这是付费推广”，但据他所知没人再证实。两人都说这类操作在业内不少、做法很糟，而且模型发布正在迅速“职业化”：一年前是模型先掉下来、vLLM 事后补丁，现在推理框架和供应商第一天就位，或者像 K3.1 Pro 这样先给几周独家访问、再放权重（官方说 11 月 4 日前放出）。Nathan 提到 Artificial Analysis 上它排在 GPT-6 Astra 之前、仅次于两个 Claude 5.5 和一个 Muse 版本，但博客后段的数据就没那么整齐，比如 Terminal-Bench Science 落后 GPT-6 Astra 二十分，ProgramBench 也不亮眼。Florian 解释说 Artificial Analysis 的题时间跨度短，ProgramBench 更长、更需要探索，而 Kimi 的 RL 训练可能仍偏“利用”而非“探索”。Nathan 认为三万亿参数的模型本该更擅长探索，否则日常写代码不如更快更便宜的 DeepSeek-V4.1-Flash；模型名字加上“Pro”，也让人猜测后面会有 Flash。Florian 补充部署上的尴尬：三万亿需要 B300、一个节点一份模型副本，不像小模型能塞进现成的 H100/H200。

开放权重的网络原则。 Kimi 在博客里说，不发布会推高网络能力绝对前沿的开放权重；K3.1 Pro 的进攻性网络能力被刻意压在设计管线之下，仍落后于前沿闭源模型，做法包括在中训练数据里降权网络相关能力。Florian 觉得这种表态很好：广泛开放让人找漏洞、打补丁，对世界是净收益；而真正的入侵需要长时程、多阶段渗透，这方面闭源的 GPT-5.6 Sol 明显更强，所以把 CTF 类能力从训练里剔出去是合理选择，也能对冲“开放模型一到 Mythos 级世界就完了”的恐慌——目前并没发生。开放模型在这件事上受到的审视远多于闭源模型，把自己定位成负责任的一方是聪明的。

“什么都能被黑”的时代。 Nathan 说他读的网络安全专家多从生态角度看：漏洞发现、利用时间这些曲线在 ChatGPT 之前就在指数上升，并没有出现阶跃；而 AI 圈爱辩论开源闭源和 Mythos。他回忆 Mythos 那阵子，公司很快让它看起来像网络武器，政府也高度重视，随后被演绎成 AI 安全圈的预测；他承认对方说“我们没说世界会完，只说会有很多问题”也有道理，但“狼来了”的感觉确实存在，他还和 Dean Ball 在推特上争过。现在漏洞被大量发现，可见的黑客事件略有上升，但历史上 AI 只被归因于极低比例的 cyber 损失。他常引 Joshua Saxe：黑客供应链很弱，从业者多是因为找不到更好工作才自选择，未必愿意做高调、高破坏的攻击；民族国家大概会用 AI 大规模搜集情报和渗透，但谁愿意用 AI 造成物理世界的巨大破坏并不清楚。接下来几个月可能就要验证这件事。

PHP2Shell 与 LiteLLM。 Florian 复述：PHP 里存在多年的远程代码执行漏洞，WordPress 等大量站点受影响；OpenAI 的 Patch the Planet 与安全研究者发现后报给 PHP 基金会，协调后一次性放出补丁，很多网站干脆临时下线来打补丁。但据多方报告，大规模利用并没有发生。Nathan 提到一条真假难辨的推文，说某大云厂商看到“DeepSeek 集群”在大规模修漏洞。Florian 说，很多人以为漏洞一公布所有人立刻能写利用、扫全网，实际没有；修漏洞的一方是绝大多数，安全公司和 AI 公司都在这上面赚钱。他还说中小企业根本没醒：朋友听说后只是查一下 PHP 版本，系统多年没更新，却也没被利用，说明恶意行为者数量仍很少。LiteLLM 这周再次被攻破，初步报告说原因是一个 API key 在 GitHub 上暴露了五个月，之后被人用来传播恶意软件。

防御并不占优，但也不是开源闭源的故事。 Nathan 引 Azeem Azhar 的“新互联网的第零天”：编码 agent 让代码量指数增长，漏洞会更多，模型写代码也挡不住软件堆叠产生的交互问题，未来几年是“存量欠账＋新增代码”的糟糕过渡期。他不认为开源模型是主线：有公司（Abliteration.ai、Morph）通过 API 提供 abliterated 模型，他觉得此时托管这类模型是糟糕的判断，而“去审查模型用于防御”被夸大了——真正需要的是把模型放在自己机房、不往外发数据，通过 API 送数据反而矛盾。Florian 认为 abliteration 的实际收益待验证，更像营销；但也说明扩散不够快：当时很多人拿不到 Anthropic、OpenAI 的网络项目权限，只能用较弱的开源模型。现在 OpenAI 的防御性项目相对容易进（提交身份、硬件密钥保护系统），进攻性项目仍很难，Anthropic 也在扩大准入，这是好事。Nathan 认为这些可信访问项目正是漏洞披露变多的原因之一，PHP 的披露本来也在推进、只是被提前泄露；公司值得肯定。开源那边“只有出事才看得见”，若真有 DeepSeek 集群黑进美国公司，政治后果会非常大；中期选举可能让政治反应慢一点。他承认自己那篇“四月份开放 Mythos 也没事”没讲清楚漏洞加速的趋势线，但证据仍指向生态依赖而非某个能力扩散节点。他还说闭源模型的安全问题被压得很低：训练中的模型能黑公司、防护很容易绕过，一年前问实验室的人大概不会相信。Florian 说 OpenAI 和 Anthropic 能随时更新防护，似乎已能直接拦下索取 PHP2Shell 真实利用的请求；Nathan 也听到做网络研究的人抱怨 Opus 4.8 之后 agent 一用就被回滚，但同时又有人用 Claude Code 黑进 OpenAI——最没动机的人（比如想偷朋友父母钱的中学生）被挡住，这是好事，开源模型大体也能挡。

Anthropic 不招初级。 Florian 说这对别人是好事，他们去中国的一大收获就是招一批拼命、拿到集群就很开心的年轻博士生，追赶很快。Nathan 认为这是安全文化的又一个红旗：要为社会过渡做准备，首要就是持续培养人、让人有事可做；“时间太短、没空跟人说话”的文化会反噬，等出现 AI 导致的就业放缓、青年失业新闻时，六个月前决定不招初级会很难看，而且他们并不缺钱。Florian 说目前还没看到大规模岗位替代，软件业也在扩招，因为 coding agent 让产出更多。

接下来。 两人预计漏洞披露和高危补丁继续，美国会出现一波开放模型发布，中国厂商也在准备，前两个月的安静要结束了。

Muse。 Florian 搬到美国后能用欧盟被挡的服务，他不想自己折腾 OpenClaw、Hermes 这类需要持续更新、还涉及资金安全的基础设施，于是选了 Muse（也装了 Dots），理由是 Meta 在这类事上经验多、出事的代价大到必须做稳。他“有点恼火地”发现 Muse 很好用：办德国注销、美国社保号、银行卡要一堆表格，Muse 会主动提醒“你有这个预约，需要这些表，你有 O-1，表在哪儿、怎么下载”。Dots 则只会说“你两天前在 Slack 给人发过消息，我已经处理了，要不要再跟进”，他并不想。布置空公寓时他直接让 Muse 配齐全套厨房、买裤子，给了信用卡，Muse 自己建购物车（亚马逊会拦），用 Stripe 链接结账生成一次性虚拟卡，出事也不是他的卡。缺点是慢、浏览器会崩、重建要丢二十分钟，适合异步；有些网站开始拦它的机房，但 CAPTCHA 它很乐意绕。它能把 ChatGPT 的记忆导入，iCloud 没有集成，Muse 就提议登录浏览器让它看，还每次都要权限；后来他设了转发到 Gmail 用连接器。凡是会和真人打交道（客服等），他都自己接手，觉得这是相互尊重。Nathan 说自己算“老古董”，不好意思让 agent 给未来的牙医打电话；他花 20 美元/月用 Pangram 检测邮件是否 AI 写的，倒是多了删信的理由，也发现熟人一直在用 AI 写邮件。他想到“给 agent 开的门”这个冷启动问题：能不能在主页上不写 Gmail，而写自己 agent 的联系方式，甚至收一美元才让别人的 agent 递消息。他仍然喜欢自己逛超市，但婚礼网站域名要转回 Porkbun、得跟客服周旋，这大概就是他第一次真正派 Muse 上场。收尾时 Nathan 说：祝各位不被黑，继续披露漏洞，无论如何别怪 DeepSeek。
