斯坦福机器学习课：大语言模型与深度学习基础（课堂录像） ｜ Komal Prajapati（X） ｜ 约 2:34:00 ｜ https://x.com/KomalPr17116591/status/2108245975882166472

这是斯坦福一门机器学习课的课堂录像，讲者是一位斯坦福教授（课上提到另一位授课老师 Chris 讲过线性模型）。内容大致由两节课拼成：前半讲自回归大语言模型如何从文本一步步变成概率模型，后半回到深度学习的基本功，讲神经网络、梯度下降和残差网络。讲法偏板书推导，节奏不快，常停下来答学生的问题，也时常坦白"细节不重要""原因我们其实并不完全理解"。

课从 GPT-3 开创的自回归范式讲起：逐个生成 token，每个 token 都条件依赖于前面的所有 token。第一步是分词。按字符切分，序列太长；按整词切分，罕见词和新词学不到。所以现在都用子词词表，像字节对编码（BPE）那样，让"internationalization"这类长词拆成常见片段，模型只要分别懂各片段就能理解组合。词表通常在 25 万量级，空格常和后面的词合成一个 token；每家模型的分词器不同，他还提到据报道 Claude 最近换了更细的分词器，同样的文本会多花 token。之后，一段文本就只是一串 token 的 ID。

建模上，用链式法则把整段序列的联合概率拆成一连串条件概率：每个 token 的 ID 查表得到一个可训练的嵌入向量，开头加一个特殊的起始 token，送进 Transformer 后在每个位置输出 logits，经过 softmax 就是"下一个 token"的分布。生成时按这个分布采样，可以用温度调节随机性，或用 top-k 截掉低概率的选项；训练时最小化每个位置正确 token 的负对数似然之和，用梯度下降优化。

接着他拆开 Transformer 看：每层是注意力加 MLP。MLP 对每个位置独立处理，位置之间唯一的交流渠道是注意力。每个位置算出查询、键、值三个向量，用查询和各位置键的内积（除以缩放因子）做 softmax 得到注意力权重，再对值向量加权求和，直觉上就是"决定该关注过去的哪些位置"。为了不偷看未来，要用因果掩码把矩阵上三角设为负无穷，softmax 后归零。多头注意力就是多套独立的权重，各自关注不同的信息（比如一个找实体、一个看情绪），拼接后再投影成一个向量。每层还配有归一化（常用 RMSNorm）和残差连接，有前置和后置两种排列。他特别指出代价问题：注意力要算 T×T 的矩阵，时间和显存都随上下文长度平方增长，这正是 ChatGPT、Claude Code 要"压缩上下文"的原因。FlashAttention 通过分块计算省了显存；一些线性化的变体能降低对长度的依赖，但表达力会下降，要做权衡。他说学生问的"为什么不只用 MLP"答案很简单：参数量会随序列长度爆炸，而且根本学不到位置之间的关系。

后半段回到基础。回归可以看作高斯噪声下的极大似然，分类用 softmax 和交叉熵。随机梯度下降之所以必要，是因为面对万亿级 token，连算一次全量梯度都不可能；单个样本的梯度虽然有噪声，期望却等于全量梯度，轨迹大体跟着走。神经网络是线性变换和非线性激活（ReLU）的层层复合，他用房价的例子讲"中间变量"的直觉：步行便利度、社区质量等，并示范怎样把繁琐的下标记号压成矩阵形式。最后讲 2015 年的残差网络：让网络只去学"输入与目标的差"，再把输入加回来，这样可以堆很多层；至于每个残差块用两三层效果最好，他坦言"原因我们并不真正理解"。
