CSS :has 无可否认的实用性（The Undeniable Utility Of CSS :has） ｜ Josh W. Comeau ｜ 文章 ｜ https://www.joshwcomeau.com/css/has/

Josh W. Comeau 坦言起初并不看好 CSS 的 :has 伪类，但用现代 CSS 重建博客后发现自己完全错了，即使在 React 和 CSS-in-JS 的项目里也极其好用。:has 让选择器可以"自下而上"，根据子元素给父元素设样式；当时支持率约 92%，他的用法多是锦上添花，必要时可用 @supports 检测并提供后备方案。

他举了博客里的真实例子：便当盒卡片里的按钮获得键盘焦点时，用 :has 把焦点框画到整张卡片上，而不是把卡片做成按钮带来无障碍问题；拖动控件时让容器变色。他认为最酷的用法是把 :has 当全局事件监听器：模态框设置一个 data 属性，html:has(...) 就能禁止页面滚动，省掉一段 useEffect。它还能朝两个方向选兄弟元素，甚至跨越不相干的容器，比如悬停分类按钮时高亮所有同类的书。

最后他强调选复杂度最低的工具：那个分类高亮例子做完整后选择器会很冗长，真做他会用 JS 状态；日常像焦点框、禁止滚动这类场合，:has 才是最顺手的。
