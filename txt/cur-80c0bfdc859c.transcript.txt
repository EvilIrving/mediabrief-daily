Agent Harness 的演进

大约在 2025 年圣诞节前后，AI 工程师注意到 agent 变了：它们开始管用了。很难精确说清为什么。也许我们终于有假期空闲去试最新模型和最新 agent；也许模型跨过了某个能力阈值；也许模型外面的包装成熟了。

本文将论证：是后两者的合流。模型与 harness 一起改进，两条改进曲线在正确时刻交叉。这一动态也有助于解释接下来会发生什么：模型不断把 harness 吸进权重，工程师不断删除已被吸收的部分，剩下的是面向人类注意力、而不是面向模型的 harness。

发明 Transformer 的人之一 Lukasz Kaiser 在 6 月的 Unsupervised Learning 节目里说：去年冬天、去年圣诞的变化有点难钉死——harness 变了，后训练也变了一点，然后新的预训练模型来了……但感觉像一次不那么容易说清是什么造成的巨大跃迁。

「发生了什么？」的答案并不只在模型权重里。它在权重周围生长起来的系统里。答案在 agent harness。

回想 2022 年 11 月，ChatGPT 还是最先进的 AI 工具时：它可支配的唯一能力是下一 token 预测，外加一些让它表现得像有用助手的 RLHF。没有工具，没有搜索，没有推理。原始 ChatGPT 被困在训练数据和你发送的提示里。它是缸中之脑。

agent harness 是让 LLM 挣脱那一禁锢、与真实数字信息空间交互的方式。

harness 实际是什么

agent harness 是权重之外让 agent 工作的一切：环绕模型的环境、工具、上下文与护栏。没有 harness，模型是缸中之脑。它可以采取认知行动，但需要 harness 才能把决定落实到真实数字空间。harness 像是给模型的心智一具身体：有了它，模型可以感知（上下文）、行动（工具）、持久化信息（记忆与压缩）、并强制边界（权限与护栏）。

Harness 1.0：过去，「外挂时代」

模型与 harness 演化路径上有两条曲线：harness 向模型要求什么，以及模型实际能交付什么。两条曲线之间的落差等于 agent 的效能；落差的闭合，正是本文将论证的、Kaiser 所指那次可感知改进的原因。落差如何分阶段闭合：

1. ReAct，「纸上的 harness」（2022 年 10 月）：提示技术，把 agent 循环写在权重之外——推理、行动、观察、重复。当时提示是唯一推理方法，没人叫它 harness。同年冬 Meta 的 Toolformer 暗示工具使用可以训练进去而不是提示出来。两条曲线此时都接近零。

2. AutoGPT/BabyAGI，「过早的自主」（2023 春）：harness 曲线冲到模型能力曲线前面，把模型当成「自主员工」，而模型仍是脆弱的下一 token 预测器。循环不会给模型增加能力，只会放大已有能力；低于某阈值时放大的是错误。逐步 95% 可靠、20 步任务平均成功率约 36%。这是落差最宽处，接下来 18 个月是反应与试图闭合落差。

3. Cursor/Copilot，「退回人在环中」（2023–2024）：第一批 AI IDE 认清给模型过多自主的失败模式，把 harness 曲线拉到模型曲线之下——把循环给人，让模型加速人。第一版 Devin 试图把自主交回模型；Answer.AI 团队测试成功率仍约 15%。与此同时模型继续改进；2024 年末 o1 出现，落差首次反转，出现模型能力悬垂的迹象。

4. Claude Code，「曲线交叉」（2025 年 2 月）：若模型已超前 harness，仍故意踩刹车就浪费能力。Claude Code 是第一个抓住机会的编程 agent：放弃 IDE 改用终端，给 bash 与文件读写，用权限规则代替逐步审批。Boris Cherny 团队按下一档模型能力来建，而不是当前档。它火不是因为第一个给自主，而是第一个在正确时机给——模型已足够可靠。约六个月 ARR 约 10 亿美元。

接下来曲线不只相遇，开始编织在一起。

Harness 2.0：现在，「共训时代」

今天 harness 重要，而且可度量。Harness-Bench 同一模型、相同 106 题、不同 harness，得分从 52.4 到 76.2，差 23.8 分。agent 有一半是 harness。OpenAI 在 ARC-AGI-3 上仅加保留推理与压缩，就把 GPT-5.6 Sol 从 13.3% 提到 38.3%。

底层是：强化学习进了 harness 内部。OpenAI 2025 年 5 月 codex-1 发布称在多种环境的真实编程任务上用 RL 训练。Toolformer 的梦想成为现实：工具调用从外部提示变成在模型环境内训练。模型开始把 harness 能力吸进权重，例如学会考虑自身上下文窗口的自动压缩。GPT-5.1-Codex-Max：第一个原生训练为通过压缩跨多个上下文窗口运作的模型。

一旦吸收，harness 就可以脱掉脚手架。Anthropic 的 Thariq Shihipar 说团队最近删了 Claude Code 系统提示的 80%。衡量 harness 演化速度的尺度是：在保持同等能力的前提下你能删掉多少 harness。这就是循环：训练、吸收、剥离、重复。Kaiser 说的跃迁难钉死，正因为它不是离散事件，而发生在模型与 harness 协同的空隙里。

Harness 3.0：未来，「注意力时代」

继续删除模型能吸收的一切。多 agent 编排、工具选择、记忆……自改进 harness 也可像模型一样被训练。删除与吸收结束时剩下的是以人为中心的能力：权限、身份、信任与可辨识性。模型把权限吸进自身等于消解了权限。吸收并不终结 harness，而是翻转它。

harness 成为 agent 面向操作它的人的接口。它出生时是人连模型的界面：从聊天空到 IDE 再到终端。若模型吸收面向计算机的能力，下一阶段抽象上移一层：harness 成为模型连向我们人类注意力的界面——注意力接口（attention-interface）。

Ryan Lopopolo 在 Latent Space《为 token 亿万富翁做极限 harness 工程》一集说：唯一根本稀缺的，是我团队同步的人类注意力。token 已充裕可靠，瓶颈仍是稀缺的人类注意力。Anthropic 的长时 agent 进度文件与审批队列已是火花。

模型与 harness 曲线的落差在吸收后并不消失，而是迁过人类边界，形成新的一对曲线与新落差：agent 向人要求什么，与人能够应答什么之间的空隙。

注意力接口

我预测一年内，每家做 agentic AI 的公司都会像普及 AGENTS.md 一样推出人类注意力策略面。AGENTS.md 告诉 agent 如何与代码库协作；注意力接口将告诉 agent 如何与你协作：何时可打断、何时应继续工作、哪些决定可独断、哪些需要批准。像系统其他部分一样，它会成为可学习组件。每次纠正都是有用数据。

模型始于缸中之脑。harness 给了身体，身体又开始溶回脑。留给我们建造的，是未来模型永远不会吸收的那一层：连向真正稀缺资源——人类注意力——的接口。
