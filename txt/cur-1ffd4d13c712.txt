理解布局算法 Understanding Layout Algorithms ｜ Josh W. Comeau ｜ 文章 ｜ https://www.joshwcomeau.com/css/understanding-layout-algorithms/

Josh W. Comeau 讲他学 CSS 的一次顿悟：CSS 不是一堆属性，而是一组布局算法，属性只是传给算法的参数。很多人觉得 CSS 不可靠，是因为不知道属性处在哪套算法里。

他举了两个例子。z-index 在 Flow 布局里无效，并不是"必须配合 position"，而是 Flow 根本没实现它，Flex 子元素不设 position 照样生效。width: 2000px 在 Flow 里是硬性规则，在 Flexbox 里只是可收缩的"假设尺寸"。元素用哪种算法，有的由自身声明决定，如 position: fixed；有的由父元素决定，如 display: flex 让子元素改用 Flexbox；冲突时定位布局通常胜出。

文章主体解释了图片下方多出几像素的"行内魔法空白"：图片默认是行内元素，Flow 按基线对齐，给下伸字母留了空间。解决办法是设 display: block，或让父元素用 Flex，line-height: 0 也行但只作演示。他的结论是，只研究单个属性看不到层叠上下文、包含块这些冰山下的概念；CSS 没有报错和调试器，直觉是最好的工具。他也批评网上很多 CSS 教学只分享代码片段而不讲原理，自己多年靠深挖 MDN 和 CSSWG 规范来补全心智模型，很值得但极耗时。常见的算法包括 Flow、Flexbox、Positioned、Grid 和 Table，其中 Flow 是诞生于文档时代的默认算法，像文字处理软件那样排版，不允许元素重叠。文末推广了他的课程。
