921: AI Coding Roadmap for Newbies (And Skeptics) ｜ Syntax ｜ 49分钟 ｜ https://syntax.fm/921

这一期 Syntax 是 Wes Bos 和 Scott Tolinski 给 AI 编程新手和怀疑者准备的路线图：先讲用 AI 写代码的几种方式，再讲自己动手做一个 AI 应用，借此弄懂上下文、提示词、流式输出、嵌入、RAG、MCP 等概念。

写代码的方式按"吓人程度"从低到高排列：编辑器里的幽灵文本自动补全；IDE 侧边栏的 agent 模式聊天，改动先暂存，可逐条接受或回滚，Scott 主要用这种；终端里的 CLI agent，Claude Code 领先，另有 Gemini CLI、Codex、OpenCode 和 Warp，适合并行派任务。两人承认 Claude Code 质量更高，但仍偏爱 IDE 的图形界面看 diff。补上下文推荐 Context7，能注入 Tailwind 4、Svelte 5 等库的最新文档；AI 只熟悉特定时期的工具，Svelte 把 on:click 改成 onclick 它就不认识。Wes 的原则是：觉得 AI 蠢时，多半该通过 MCP 给它补个工具。v0、Lovable、Bolt.new、Replit 适合主要做 UI、不想碰代码的人，别小看它们；在 ChatGPT 里复制粘贴最原始，Scott 现在改用能引用多个标签页的 Dia 浏览器。

做应用部分：系统提示词设定角色；借助 AI SDK，结构化输出已不成问题，模型最擅长 JSON 和 Markdown；响应慢就要流式解析，JSONL 每行一个对象最安全。RAG 是把问题和近千期文字稿片段转成嵌入向量，取最接近的几段交给模型。MCP 让 AI 操作 Figma、Godot、DaVinci Resolve 等程序。Wes 做过的玩具：拍照后让 OpenAI 用《拖车公园男孩》Ricky 的口吻描述，再用 ElevenLabs 的声音念出来，借此体会各模型在速度、价格、质量上的取舍。

工具库推荐 OpenAI SDK、Vercel AI SDK（统一对接各家模型并提供流式 UI）、Cloudflare Agents SDK（状态持久化、长任务）；LangChain 他们很久没用了；Transformers.js 可本地跑 Hugging Face 小模型，Wes 用它从六千张截图里挑出笑得最开心的一张。

最后建议多探索，把 AI 当作有趣的机器学习来玩，Scott 专门有个自动清空的 temp 文件夹放试验。两人承认 AI 在版权、能耗上有问题，但它确实在改变行业；尽量用自己熟悉的技术，才能判断生成的代码值不值得留。本期没有 Sick Picks。
