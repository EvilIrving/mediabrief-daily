智能体 Harness 的演进

2025 年圣诞节前后，AI 工程师们注意到智能体发生了变化。它们开始能用了！很难确切说清原因。也许是我们终于有了假期的空闲时间，去用最新的模型试用最新的智能体。也许是模型跨过了某个**能力阈值**。也许是模型外面的**那层包装**成熟了。

我在这篇文章中要论证的是，原因在于后两者的汇合。**模型和 harness 一起进步**，然后它们的进步曲线在恰当的时刻交叉。而这种动态也有助于解释接下来会发生什么：模型不断把 harness 吸收进自己的权重，工程师不断删掉被吸收的部分，**最终剩下的是一个服务于人类注意力、而非服务于模型的 harness。**

Transformer 的发明者之一 Lukasz Kaiser 6 月在 “Unsupervised Learning” 节目上说：

“去年冬天、去年圣诞节的那次变化——有点难以说清。我是说，harness 变了，后训练也有些变化，然后又来了新的预训练模型……但感觉是一次**很大的跳跃**，而到底是什么促成的，并不那么容易说清。”

“**到底发生了什么？**”的答案并不仅仅在模型权重里。它在围绕权重成长起来的那个系统里。

**答案在智能体 harness 里。**

回想一下 2022 年 11 月，当时 ChatGPT 是最先进的 AI 工具。它唯一可用的能力就是下一个 token 预测，外加一些基于人类反馈的强化学习（RLHF），让它能够表现得像一个乐于助人的助手。没有工具，没有搜索，也没有推理。

最初的 ChatGPT 被局限在它的训练数据和你发给它的提示词里。不多也不少。**它是一个缸中之脑。**

智能体 harness 是让 LLM **挣脱这种禁锢**、与真实的数字信息空间交互的一种方式。

## Harness 究竟是什么

**智能体 harness 是除模型权重之外、让智能体得以运转的一切。** 即围绕模型的环境、工具、上下文和护栏。没有 harness，模型就是缸中之脑。它可以做出认知层面的行动，但需要 harness 在真实的数字空间中把这个决定付诸执行。

**harness 就像是给模型的心智装上了一副身体。** 有了 harness，模型就能感知（上下文）、行动（工具）、持久保存信息（记忆和压缩），并守住自己的边界（权限和护栏）。

## Harness 1.0：过去，“外挂时代”

模型 / harness 的演进路径中贯穿着两条曲线。**harness 对模型提出的要求，以及模型在实践中能够交付的东西。**

这两条曲线之间的差距，就等于智能体的有效性；而我要论证的是，正是这一差距的缩小，带来了 Lukasz Kaiser 所说的智能体切实可感的进步。

这个差距是这样分阶段缩小的：

1. **ReAct，“纸面上的 harness”**（2022 年 10 月）：ReAct 是一种提示技术，通过提示让模型进行推理。它是写在纸面上的智能体循环，位于模型权重之外。它定义了“智能体循环”的概念：模型推理 -> 行动 -> 观察 -> 重复。再强调一遍，**ReAct 循环只作为一种提示方法而存在。** 提示是当时唯一存在的推理方法，也没有人把它叫作“harness”。同一个冬天，Toolformer（Meta，2023 年 2 月）暗示了工具使用可以通过训练习得，而不是通过提示。这有点像艾伦·图灵在计算机被实现为物理实体之前提出的计算机构想。一个强大的想法，直到后来才得以实现。（ReAct 比 ChatGPT 早一个月——2022 年 10 月对 2022 年 11 月。）此时两条曲线都接近于零。差距很小，因为我们才刚刚起步。
2. **AutoGPT/BabyAGI，“过早的自主”**（2023 年春）：随着 AutoGPT/BabyAGI 的出现，harness 曲线冲到了模型能力曲线的前面。两者都把完全的自主权交给模型，要求模型扮演“自主员工”，但此时的模型仍然不过是脆弱的下一个 token 预测器。**循环并不能给模型增加能力。** 循环放大的是模型已有的能力，而在某个阈值以下，循环放大的是错误，而不是可靠性。想想负向复利的威力：每一步 95% 的可靠性，在一个 20 步的任务上，平均成功率约为 36%。harness 交给模型的是一项它根本没有现实可能完成的任务。**这是差距最大的时候**，而接下来的 18 个月都是对此的反应，以及缩小这一差距的尝试。
3. **Cursor/Copilot，“退回到人在回路中”**（2023 - 2024 年）：最早的 AI 驱动 IDE 认识到了给模型过多自主权这一失败模式。它们通过把 harness 曲线拉低到模型曲线之下来缩小差距。**不要把循环直接交给模型；把循环交给人**，让人有能力编排循环，而模型为人提速。第一版 Devin 试图把自主权交还给模型。Answer.AI 团队的一项测试表明这仍然为时过早，成功率约为 15%。这证明了 IDE 从完全自主后撤的做法并不是怯懦，而是正确之举。然而，尽管主流策略是把 harness 压到模型之下，**模型仍在持续进步**。临近 2024 年底，随着第一个推理模型 o1 的推出，差距第一次***发生反转***，我们开始看到模型能力过剩（capability overhang）的最初迹象。
4. **Claude Code，“曲线交叉”**（2025 年 2 月）：2024 年底的反转创造了一个需要有人抓住的机会：如果模型现在领先于 harness，那么一个刻意给模型踩刹车的 harness 就是在白白浪费能力。**Claude Code 是第一个为抓住这个机会而打造的编程智能体。** 它放弃 IDE、转向终端，给模型 bash 和文件读写权限，并用**权限规则**取代了每次修改都需要人工批准的做法。循环再一次交到了模型手中，而这一次它领会了任务。**Boris Cherny 和团队在构建 Claude Code 时，着眼的是下一代模型的能力，而不是当前模型。** 它之所以如此成功，并不是因为它是第一个给模型自主权的产品，而是因为它是第一个在正确的***时机***这么做的产品。那个时机就是**模型已经可靠到足以在自主状态下取得成功的交叉点**。Claude Code 在六个月内年化收入（ARR）增长到大约 10 亿美元，这一切都是因为 Anthropic 抓住了两条曲线开始交汇时出现的机会。

接下来发生的是，两条曲线不只是交汇，它们开始***编织***在一起。

## Harness 2.0：现在，“共同训练时代”

**如今 harness 很重要，而且是以一种我们可以测量的方式。** Harness-Bench 让同一个模型在不同的 harness 中完成同样的 106 项任务，得分从 52.4 到 76.2 不等：在模型零改动的情况下，相差 23.8 分。**智能体有一半是 harness。**

OpenAI 通过修改 harness，在 ARC-AGI-3 上取得了类似的结果。仅仅增加了保留推理和压缩，GPT-5.6 Sol 的 ARC-AGI-3 得分就翻了三倍，从 13.3% 提升到 38.3%。

在幕后发生的是，强化学习（RL）已经移到了 harness ***内部***。OpenAI 在 2025 年 5 月发布 codex-1 的公告中写道：“codex-1 是在多种环境中，针对真实世界的编程任务，用强化学习训练出来的。”

**两条曲线汇合，并开始编织成一个统一的系统。**

这正是 Toolformer 的梦想在现实中成真。工具调用不再是从外部通过提示来驱动，而是在模型的***环境***内部训练出来的。

然后，随着模型在 harness 的环境中接受训练，**它们开始把 harness 的能力吸收进模型权重**，例如，学会在了解自身上下文窗口的情况下自动压缩。

GPT-5.1-Codex-Max 发布时的介绍：

“第一个原生训练为通过压缩跨多个上下文窗口运行的模型。”

**一旦模型吸收了 harness 的能力，harness 就可以拆掉脚手架。** 这是一种做减法式的生产。Anthropic 的 Thariq Shihipar 说，团队最近删掉了 Claude Code 系统提示词的 80%。

衡量智能体 harness 演进速度的标准，是在保持同等能力水平的前提下，**你能删掉多少 harness**。这就是我们作为 AI 工程师需要努力构建的未来。

于是，这就是模型 / harness 演进的循环：**训练** -> **吸收** -> **剥离** -> **重复**。模型攀向下一件它还做不到的事情。

Kaiser 指出的那次跳跃之所以难以说清，是因为它不是一个离散的事件。预训练上的飞跃很明显，因为你可以在模型卡里把它讲清楚。而模型 / harness 共同演进带来的跳跃就没那么明显了，因为演进过程没有文档记录。这就是去年冬天那次跳跃的答案：**它发生在模型与 harness 协同工作的那片空间里。**

我们需要问：如果每一项 harness 能力最终都会被模型吸收，那最后留给我们的是什么？

## Harness 3.0：未来，“注意力时代”

不断删掉模型能吸收的一切。想象一下这个过程结束时你的智能体是什么样子。当你删掉一切之后，你手里还剩下什么？

模型权重接下来会吸收什么？多智能体编排、工具选择、记忆……这只是几种可能。研究人员正在构建能够自我改进的 harness，它们本身可以用类似训练模型的方式来训练。

在这个删除与吸收的过程结束时，剩下的是**以人为中心的智能体能力**。比如**权限、身份、信任和可读性**。一个把权限吸收进自身的模型，等于消解了权限。吸收并不会终结 harness。吸收会把 harness 翻转过来。

**harness 变成了智能体面向操作它的人类的接口。**

harness 诞生时是人类面向模型的接口。我们从聊天框发展到 IDE，再到终端。如果模型吸收了面向计算机的能力，下一阶段的演进就会上升一个抽象层级。harness 变成模型面向我们人类注意力的接口。

它变成了**注意力接口**（attention-interface）。

Ryan Lopopolo 在 Latent Space 的 “Extreme Harness Engineering for Token Billionaires” 这一期节目中说：

“唯一从根本上稀缺的东西，是我团队成员的同步人类注意力。”

token 变得充足而可靠，但**我们仍然受制于稀缺的人类注意力这一瓶颈。**

我们已经看到了这方面的苗头，比如 Anthropic 用于长时间运行智能体的进度文件，以及智能体审批队列。

当模型吸收了 harness 时，模型曲线与 harness 曲线之间的差距并不会消失。它会迁移跨过人类这条边界，形成一对新的曲线和一个新的差距。**新的差距**存在于智能体对*人类*提出的要求，与**人类能够回应的程度**之间。

## 注意力接口

我预测，一年之内，**每一家构建智能体 AI 的公司都会推出一个人类注意力策略界面**，就像每一家智能体 AI 公司都推出了 AGENTS.md 一样。

AGENTS.md 告诉智能体如何与你的代码库协作。**注意力接口将告诉智能体如何与你协作。** 它将规定智能体何时可以打断你，何时应该继续工作，哪些决定可以独自做出，哪些决定需要你的批准。而且就像智能体系统中的其他一切一样，**它将成为系统中一个可学习的组件，能够随着更多数据不断学习。** 每一次纠正都会成为有用的数据。

模型起初是一个缸中之脑。harness 给了大脑一副身体，然后这副身体开始溶解回大脑之中。留给我们去构建的，是任何未来模型都永远不会吸收的东西。通往那唯一真正稀缺的资源的接口：**人类注意力。**
