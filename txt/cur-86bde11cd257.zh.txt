OpenAI 和 Anthropic 在几个月内将 LLM 价格下调了最高 80%。为什么？

让我们快速梳理过去几个月里 OpenAI 和 Anthropic 主要 LLM 模型发布的时间线。所有价格数字均为 `输入 MTok / 输出 MTok / 缓存读取 MTok`。

### 2026 年 6 月 26 日

OpenAI 发布了 GPT-5.6 Sol 和 Luna。Sol 是 GPT 5.5 的直接继任者，价格保持不变，为 `$5 / $30 / $0.50`；Luna 则是专为更便宜的使用场景设计的小型模型，价格为 `$1 / $6 / $0.10`。他们还发布了一款介于两者之间的 Terra 模型，但很少有人关注它。

### 2026 年 6 月 30 日

Anthropic 发布了 Claude Sonnet 5，并声称它更接近自家的 Opus 系列模型，但反馈褒贬不一。值得注意的是，其发布价为 `$2 / $10 / $0.20`，这一价格原本只是临时性的，之后会上涨。

### 2026 年 7 月 24 日

Anthropic 发布了 Claude Opus 5。鉴于 Opus 4.5 对智能体编程（agentic coding）兴起所产生的巨大影响，这是一次备受期待的大版本更新，价格为 `$5 / $25 / $0.50`（与 GPT-5.6 Sol 相近）。尽管其公布的部分基准测试结果出人意料地超过了规模大得多的 Fable 5，但真实世界的反馈却更为分化。

### 2026 年 7 月 30 日

OpenAI 宣布将 GPT-5.6 Luna 的价格下调 **80%**（？？？），降至 `$0.20 / $1.20 / $0.02`。

### 2026 年 8 月 10 日

Anthropic 宣布，Sonnet 5 发布时的临时降价现已成为永久价格。

### 2026 年 8 月 21 日

OpenAI 宣布在未来三个月内将 GPT-5.6 Sol 的价格下调约 20%（`$4 / $20 / $0.40`）。

### 2026 年 9 月 1 日

Anthropic 发布了 Fable 5.1，价格为 `$10 / $50 / $0.25`。与 6 月发布、价格为 `$10 / $50 / $1` 的 Fable 5 相比，它不仅在所有领域的基准测试表现上都严格更优，还将缓存读取成本降低了 75%。

在使用智能体进行编程时，缓存读取成本占总 token 支出的绝大部分（96% - 99%），因为缓存中包含的是每一轮对话的完整历史。此外，缓存命中率通常在 90% - 100% 之间（具体取决于 LLM 推理提供商的基础设施）。综合来看，缓存读取成本降低 75%，对应的是使用该模型的成本降低 70-75%——这显然值得注意，即便缓存成本通常只是脚注里的一项！

### 2026 年 9 月 3 日

OpenAI 发布了 GPT-6 Astra，其规模与 Fable 5.1 相近，定价也相似，为 `$10 / $50 / $1`，但没有更低的缓存读取成本。Astra 的模型表现确实与 Fable 相当。

### 2026 年 9 月 22 日

OpenAI 公布了 GPT-6 Sol，价格低得惊人，为 `$2 / $10 / $0.20`，相比临时降价的 GPT-5.6 Sol，输入和输出价格都减半！他们同时发布了 GPT-6 Luna，输入和输出价格同样是上一版本的一半（`$0.10 / $0.50 / $0.01`）。

就*在同一天*，Anthropic 发布了 Claude Opus 5.5，并明确表示“Opus 5.5 的服务所需算力少于 Opus 5，其定价也反映了这一点”。其 `$4 / $20 / $0.20` 的价格在总体上远低于 Opus 5，原因是输入/输出成本降低了 20%，缓存读取成本降幅更大，使得这款甚至比 Fable 5.1 更强的模型总成本降低了 **40-60%**（关于 Opus 5.5 我有很多话想说，但那是另一篇文章的事了）。

### 2026 年 9 月 29 日

结果证明 GPT-6 Sol 在性能上是个失败品，因此一周后 OpenAI 发布了 GPT-6.1 Sol。出人意料的是，它的性能与 Astra 相当（个人使用后可以确认），但 OpenAI 还顺手把缓存价格砍了一半（`$2 / $10 / $0.10`），与 Anthropic 相当于输入价格 5% 的缓存读取成本持平，使这一模型系列的累计降价幅度达到 **75%**。

总体而言，从 6 月 GPT-5.6 系列模型发布至今，使用这些热门 LLM 的成本已经大幅崩塌，这在一年前是我意想不到的。这些降价同样适用于 Codex 和 Claude Code 等订阅制智能体运行框架中的模型使用。更重要的是，这些模型似乎并没有为了降价而在输出质量上偷工减料。

从上面的时间线可以看出，Anthropic 与 OpenAI 之间存在明显的针锋相对，因此有理由认为 OpenAI 和 Anthropic 的这些具体降价是针对彼此的回应。然而，除非存在某种外部因素，否则没有人会一口气降价 **80%**。那么，原因究竟何在？

## LLM 的行为经济学与竞争对手的定价压力

如果你一直在新 LLM 发布时就用智能体去测试它们，就会发现除了主观感受之外，很难将它们区分开来。自去年 11 月智能体 LLM 迎来超高速增长以来，模型已经越来越商品化：只需在 OpenCode 和 Zed Agent 这类运行框架里切换一个开关，或者通过 OpenRouter 换一个 API 端点字符串，就能在自己的代码库上试用新模型，因此护城河很小。此外，还有*众多*竞争者——不只是 Google 和 Meta 这样的大公司——它们能提供足以替代的模型，从而形成价格压力。

就开放权重模型而言，让我们再看看 DeepSeek Flash V4.1，它最近也发布了更新的 1017 变体。

最初的 DeepSeek V4 Flash 0420 于 2026 年 4 月发布，价格为 `$0.14 / $0.28 / $0.0028`，因此迅速病毒式传播，尤其是在当时 OpenAI 还没有面向简单任务的小型模型的情况下。那个 `$0.0028` 被证明是关键：2% 的缓存读取占比远低于上述 OpenAI 和 Anthropic 模型的 5%-10%，这使得实际有效成本*甚至*比宣传的还要低。我怀疑 7 月 GPT-5.6 Luna 降价 80%，正是为了专门与这些更小的开放权重模型竞争。如今，新的 DeepSeek Flash V4.1 1017 模型在基准测试上的表现*显著*优于 DeepSeek Flash V4（在 Artificial Analysis 指数上为 45 对 24），而 DeepSeek 给出的成本仍大致相同，为 `$0.15 / $0.60 / $0.003`。请注意关键限定词是“来自 DeepSeek”。

在 OpenRouter 上，任何推理提供商都可以上架自己所托管的模型；当用户调用 OpenRouter API 时，请求会被路由到其中之一——默认情况下会为负载均衡而路由到任意可用模型，但开发者可以在 API 请求中指定“最低价格”之类的偏好。早在 5 月，我就注意到 OpenRouter 上有 13 家不同的提供商托管 DeepSeek V4 Flash。而对于更新后的 1017 变体，现在已有 *29* 家不同的提供商。

不过，如果看有效输入成本（即把缓存读取成本与缓存命中率之间的相互作用计算在内），许多不同提供商在成本上相差无几。

OpenAI 和 Anthropic 将不得不用更高质量的模型来与这些开放权重模型形成差异化——他们目前在这方面做得不错，尤其是 Opus 5.5——但他们需要*持续*这样做，这也是为什么有数十亿美元被投入研发。开放权重模型正在快速追赶：就在几天前，Moonshot AI 发布了 Kimi K3.1 Pro，其性能与 Opus 5.5 相当（Kimi 为 55，Opus 5.5 为 58），输入/输出价格只有一半，缓存读取成本相同（`$2 / $10 / $0.20`）。它与 Kimi K3 规模和架构相同，而 Kimi K3 目前由 20 多家不同的推理提供商托管：因此，一旦权重在 11 月 4 日开放，你可以预期其中大多数提供商会以大致相当的价格支持新的 Kimi K3.1 Pro 模型。值得注意的是，Moonshot AI 自己也加入了降价大军，将 Kimi K3.1 Pro 定价为低于原版 Kimi K3（`$3 / $15 / $0.30`）。

在那些高调批评 AI 的人士中，有一个反复出现的论调：token 价格被人为压低，目的是把人们钩进 LLM 生态，但之后价格会上涨到“token 的真实成本”，一旦免费搭车结束，AI 吹捧者们就要倒霉了。这套理论认为，OpenAI 和 Anthropic 正在像 2010 年代 Uber 和 Lyft 对网约车行业所做的那样进行亏损换增长；但与那时不同的是，OpenAI 和 Anthropic 并不是拥有生态内唯一定价权的双寡头，而且推理行业的进入门槛也没有那么高。只要这众多推理提供商能够继续以与 OpenAI 和 Anthropic 相近的价格和相近的质量提供模型，并且切换成本可以忽略不计，那么价格可能会继续*进一步*下降。两家公司都在努力构建护城河以抵御这一趋势，例如重视企业承诺（enterprise commitments）以及 OpenAI Dots 和 Claude Duet 这样的个人智能体助手，这并不令人意外。

所谓 token 价格会突然上涨的说法，更像是一种幻想，既得不到行为经济学的支持，也与过去几个月 LLM 价格的实际趋势不符——更好的模型价格*大幅*下降，而且不只是 OpenAI 和 Anthropic 在降。只要算力提供商能把每 token 成本定得低于每 token 收入，这些推理提供商就会为相互竞争而降低 token 成本，直到 OpenAI/Anthropic 也不得不降价竞争。OpenRouter 上的 29 家不同提供商几乎没有动机去提供不盈利的模型（他们大可直接停止提供，并把算力容量转用于盈利的模型），而“token 的真实成本”最终可能就落在价格等于边际成本之处。

说到这个，OpenAI 和 Anthropic 确实都接近 IPO，这让降价一事引出了更多疑问。

## IPO 造势

这些降价的时机值得注意，因为有传言称 OpenAI 和 Anthropic 都将很快 IPO——OpenAI 在 2027 年，Anthropic 则在几个月内。到目前为止，从 OpenAI 和 Anthropic 泄露的财务数据看，不出所料，两家公司都因研发/规模化而亏损数十亿美元，尽管这两份报告都没有把过去几个月智能体 LLM 使用的超高速扩张计算在内。投资者会仔细审视巨额负利润，并要求它们拿出扭亏为盈的计划。

那么，他们为什么要把自己的主要收入来源降价高达 80%？这与你想要在 S-1 招股书上好看些的做法*恰恰相反*！推理本身的利润率很可能讲述了另一个故事，一些报告称每 token 利润率高可达 80%，但附有保留条件。在这些大幅降价之后，他们还剩多少利润率？

就我个人而言，降价确实影响了我花在 LLM 智能体上的钱，但并不是以我预期 OpenAI/Anthropic 希望普通客户表现出的方式。当 GPT-5.6 Sol 还是顶级模型时，我订阅了每月 $100 的 Codex（5x Pro 套餐），尽管对随机的用量重置感到恼火，我还是设法把订阅包含的额度全部用完了。当 GPT-6.1 Sol 发布、我注意到使用它的成本实际上降低了 75% 之后，你猜我做了什么？

我把最高用量额度削减到了原来的五分之一，因为同一个模型的使用效率提高了 4 倍，所以最终大致持平，这是显而易见的选择。

平心而论，Claude Code 和 Codex 这类订阅的利润率并不确定，因为相对于 API 用量，它们提供的价值巨大；如果出现资金紧张，我猜订阅价值会先于模型的基础价格被削减。例如，在 GPT-6.1 Sol 发布的同时，OpenAI 将 Codex 每月 $200 档位的用量额度削减了 50%，理由是“以反映我们日益高效的模型”——这*在技术上*没错，但写出来就很好笑。

一旦 Anthropic 的 IPO 招股书很快公开，我将*非常*好奇地去看其中的推理利润率。

我也怀疑，如果 OpenAI/Anthropic 有意让自家更贵的模型过时，这对它们是否有利。Opus 5.5 在一个月前发布之后，关于 Fable 5.1 或 GPT-6 Astra 的讨论就*完全*消失了，因为 Opus 5.5 就是那么好。

我完全预计 Fable 5.2/GPT-6.1 Astra 会在几周内发布并证明我错了，而我将*非常*好奇它会怎么定价。

另一个不那么愤世嫉俗、可以解释降价的因素是：LLM 基础设施在过去几个月*确实*改善了——当 Anthropic 说“Opus 5.5 的服务所需算力少于 Opus 5，其定价也反映了这一点”时，我相信它。一个真正具有讽刺意味的结果是：如果这些模型在算力上更高效，就会减少对这些大规模数据中心建设的需求，从而可能引发连锁性的经济崩溃。不过，这大概率不会发生，因为推理只是算力组合中的一部分，而那些数据中心在流水线的其他环节仍然需要。

总的来说，这轮降价很奇怪，但作为用户，我当然不会抱怨！开放权重模型和二级推理提供商将继续充当一种经济制衡，约束 LLM 的价格以及大型实验室可能炮制的其他商业把戏。即便 Anthropic 和 OpenAI 的 IPO 灾难性地失败并导致两家公司倒闭，也不会突然让 LLM 和智能体作为一个产业走向死亡。
