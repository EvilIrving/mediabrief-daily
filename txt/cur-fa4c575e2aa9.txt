Josh W. Comeau 这篇交互式教程（2023 年发表，2026 年 6 月更新）把自己学 CSS Grid 时最关键的几个"顿悟点"串起来讲。CSS Grid 已被约 96% 的用户的浏览器支持，只比 Flexbox 少 0.5% 左右。

核心心智模型是：Grid 的行列结构完全由 CSS 定义，一个 DOM 节点被切成看不见的隔间，而 Table 布局必须靠 <tr>、<td> 等额外节点才能做到。display: grid 默认是单列的隐式网格，每个子元素自动占一行；父元素高度仍按 Flow 布局由内容撑开，给定固定高度时则均分成等高的行。

grid-template-columns 可以用百分比、像素等任何长度，也可以用新单位 fr。fr 分配的是"多余空间"：先按内容算出列宽，剩下的再按比例分，类似 flex-grow，所以列不会缩到比内容还窄；百分比是硬约束，内容会溢出。加上 gap 时差别更明显：百分比列占满 100% 后再加间距就会撑出容器，fr 列则自动扣除间距。grid-gap 已弃用，成为 gap 的别名。子元素多于列数时网格会自动加行；同时写上 grid-template-rows 就成了显式网格，适合"圣杯"式页面布局。repeat(7, 1fr) 免去了手写七遍 1fr，作者用日历举例，并提醒正式的日期选择器应使用 React Aria 这类无障碍库。

放置子元素时默认像铺瓷砖一样依次填空格，也可以用 grid-row、grid-column 指定位置。grid-column: 1 / 4 里的斜杠是分隔符而非除法，数字指的是网格线而不是列序号，4 列网格有 5 条线；负数从右往左数，1 / -1 无论多少列都能横跨全宽。想让部分元素自然流动、又让"特色"元素占两列，用 span 2 即可；若宽元素落在末列放不下会换行留洞，顺序无所谓时可用 grid-auto-flow: row dense 让后面的小元素回填。

作者最喜欢的是 grid-template-areas：像画 ASCII 图一样用字符串画出布局，再用 grid-area 按名字分配，重复名字即可跨行跨列，语义清楚，适合行列固定的显式布局；隐式网格则更适合用行列编号。一个大坑是 Tab 键顺序仍按 DOM 顺序而非视觉位置，焦点会乱跳，所以应让源码顺序与视觉顺序一致；新属性 reading-flow 和 reading-order 可以解决这个问题，但截至 2026 年 5 月只有 Chrome 和 Edge 支持（约 67%）。

对齐部分，justify-content 和 align-content 分布的是整列整行（网格结构本身），justify-items 和 align-items 对齐的是格子里的元素，justify-self 和 align-self 只针对单个元素；记法是 justify 管列、align 管行、content 管结构、items 管节点。最后的小技巧是 display: grid 加 place-content: center，两行代码就能让子元素水平垂直居中。文末是作者课程 CSS for JavaScript Developers 的推广。
