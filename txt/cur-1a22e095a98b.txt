多模态大语言模型（Multimodal LLMs, MLLMs）的核心技术演进聚焦于视觉与语言两种异构模态的特征表征对齐与自回归生成集成。构建多模态大模型在底层架构上收敛为两大范式：统一嵌入解码器架构（统一序列拼接）与跨模态交叉注意力架构。

一、两大核心基础架构与训练流派：
1. 统一嵌入解码器架构（Unified Embedding Decoder / Method A）：
该范式将图像视为连续的视觉词元直接融入语言模型的输入流中。在实现流程上，输入图像首先被切分为若干固定大小的图像块（Patches，例如 16x16 像素，一张 224x224 的图像切分为 196 个图像块）；随后送入预训练的视觉 Transformer（ViT，常用 CLIP 或 OpenCLIP）提取高维视觉特征，亦有如 Fuyu 采用直接线性投影或等价步长的卷积层将原始像素块直接映射为嵌入向量；接着通过轻量级投影层（Projection Adapter，如单层线性投影或带激活函数的两层 MLP）将视觉特征投影至与文本 Token 相同的隐藏层空间维度；最后将视觉 Token 与文本 Token 拼接为一个连续序列，直接输入未经结构修改的标准因果解码器 LLM 中。该方案的工程优势在于能够无缝复用现有高度优化的纯文本大模型推理调度栈与算子库；其缺陷在于自注意力机制的计算复杂度随序列长度呈二次方增长（O((T_text + T_img)^2)），高分辨率图像产生的大量视觉 Token 会剧烈挤占文本上下文窗口，显著增加推断阶段的 KV 缓存与显存开销。
2. 跨模态注意力架构（Cross-Modality Attention / Method B）：
视觉 Token 不直接占用主干语言模型的输入序列位置，而是通过独立的交叉注意力层（Cross-Attention）注入网络。主干文本 Token 作为查询向量（Query），图像编码器输出的视觉表征作为键（Key）和值（Value），通常在主干网络中每隔固定层数（如每 4 层）插入一个交叉注意力块。其核心工程优势在于计算复杂度解耦为文本长度与图像 Token 数量的乘积（O(T_text × T_img)），对超高分辨率图像具有显著的计算吞吐与显存效率优势，且在微调时冻结底层文本 LLM 权重能够有效保留纯语言模型的原生推理能力；其缺陷在于打破了标准因果解码器的规整拓扑，需要为分布式部署开发专门的跨注意力并行算子。
3. 模态对齐与两阶段训练流程：
主流多模态模型通常以成熟的指令微调纯文本大模型为起点。第一阶段为预训练模态对齐（Pre-training），冻结视觉编码器与文本 LLM，仅对海量图像-文本对语料训练投影适配器；第二阶段为多模态指令微调（Instruction Fine-tuning），解冻文本 LLM 和/或视觉编码器，利用高质量视觉对话语料进行全量或参数高效微调。

二、2024 年秋季前沿多模态模型横向解构：
业界前沿开源模型在两类架构基座上展现出丰富的工程创新：
1. Meta Llama 3.2（11B 与 90B）：采纳跨模态注意力架构（Method B）。为实现与纯文本 Llama 3.1 的即插即用替换，Meta 团队选择冻结文本 LLM 核心参数，从零预训练了专用的 ViT-H/14 视觉编码器，并在主干中每 4 个 Transformer 块插入一个交叉注意力层。
2. 艾伦人工智能研究所 Molmo：坚持极简工程路线，公开全部清洗数据集（PixMo）与训练代码，采用端到端全量参数联合更新，在单一训练阶段中直接对齐多模态表征。
3. 英伟达 NVLM：在严格受控变量下对比了解码器架构（NVLM-D）、交叉注意力架构（NVLM-X）与混合架构（NVLM-H）。严谨的消融实验揭示：NVLM-X 在处理极端高分辨率图像时展现出显著的吞吐与显存效率优势；NVLM-D 在 OCR 密集识别与文档图表结构化解析上准确率更高；而混合架构 NVLM-H 融合动态瓦片（Tiles）与局部交叉注意力，兼具高分辨率效率与精细 OCR 识别能力。
4. 阿里 Qwen2-VL：引入朴素动态分辨率（Naive Dynamic Resolution）机制，能够原生处理任意长宽比图像而无需强制下采样或填充黑边，避免因拉伸形变导致小文本模糊；并引入多模态二维旋转位置编码（Multimodal 2D-RoPE），将空间高度与宽度坐标统一映射至自回归时序位置中。
5. Mistral Pixtral 12B：独立从零训练了 4 亿参数的原生视觉编码器，支持可变输入分辨率与多图混合输入序列。
6. 苹果 MM1.5：提供从 1B 到 30B 的稠密与 MoE 模型，其核心特性在于引入专用的文本空间坐标 Token（Bounding-box Coordinates），在统一文本输出空间内实现高精度的视觉定位（Grounding）与目标检测。
7. Rhymes AI Aria：构建了首个采用跨模态交叉注意力与 MoE 深度融合的开源多模态模型，单 Token 在 24.9B 总参数中仅激活 3.9B 参数。
8. 百川 Baichuan-Omni：设计了严密的三阶段渐进式解冻策略，依次训练投影适配器、视觉编码器与全量网络参数，平抑模态迁移带来的表征震荡。
9. Emu3 与 DeepSeek Janus：探索跨模态统一生成范式。Emu3 证实自回归因果解码器在不借助扩散模型的前提下可直接用于高画质图像生成与多模态理解；DeepSeek Janus 则通过解耦视觉理解与视觉生成的独立编码通路，有效解决了单一编码器在双向任务中的表征冲突问题。

在评估层面，公开基准集普遍面临数据污染与评测协议不一致的挑战。多模态模型的最终选型需综合考虑分辨率动态支持能力、OCR 精确度、纯文本能力保真度以及生产部署时的推理显存与吞吐瓶颈。
