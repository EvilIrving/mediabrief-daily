Latent Space 创办者 swyx 发表的《AI 工程师的崛起》（The Rise of the AI Engineer）确立了新一代软件工程职业坐标，指出大模型基座与 API 生态推动应用 AI 发生历史性“右移”，正在催生软件工程自 DevOps 与 SRE 之后需求最为旺盛的新兴专业分工。

这一范式转移的核心驱动力在于基础模型能力涌现与云端 API 的普及。在传统机器学习时代，将一项 AI 能力落地应用往往需要由数名博士组成的算法团队历经数年研发，深度沉淀于数据标注、特征工程、PyTorch/TensorFlow 训练流水线、分布式多机训练以及 GPU 集群运维等底层硬核领域。而今天，随着具备通用推理能力的基座模型成熟，以往耗资巨大的研发任务被抽象为几行标准的云端 API 调用，数千名没有深度学习博士背景的普通全栈工程师能够在短短几个工作日内独立交付服务数百万用户的复杂 AI 原生应用。

文章精准勾勒了传统机器学习工程师（MLE）与新型 AI 工程师（AIE）在技术栈与工程目标上的本质分野。MLE 的核心工作聚焦于模型损失函数收敛、权重参数调优、算子级优化与 GPU 训练开销；而 AIE 则致力于利用现有先进模型构筑端到端高可用系统，其核心日常涵盖提示词与上下文工程、检索增强生成（RAG）、向量数据库检索拓扑、系统延迟与 Token 经济学调优、自动化评估（Evals）以及 Agent 外围 Harness 架构治理。诸如 Simon Willison、Pieter Levels 以及 Riley Goodside 等先行者的实践表明，产品交付能力而非论文发表数量已成为该领域的核心评价尺度。顶尖实验室提供的高达数十万美元年薪以及黑客松社区的繁荣，进一步印证了市场对该角色的迫切需求。

在产业与组织形态上，随着各大初创与巨头内部临时建立的 #discuss-ai 讨论组演化为正式编制的工程团队（如 Notion AI、Figma 等），AI 工程师呈现出强烈的两极化哑铃分布特征。哑铃的一端是极少数投入数十亿美元算力训练基础前沿模型的顶尖研究实验室；哑铃的另一端则是基数极其庞大、专注于将模型能力无缝缝合进真实人类业务世界的 AI 工程师。未能及时完成这一组织范式转型的传统软件团队，将在敏捷构建与落地迭代速度上全面落后于 AI 原生型工程组织。
