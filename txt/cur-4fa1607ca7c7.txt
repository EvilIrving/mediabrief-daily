EP95 对话字节 Trae 团队：探秘 AI IDE演进之路 ｜ 硬地骇客 ｜ 76分钟 ｜ https://www.xiaoyuzhoufm.com/episode/67c5744abf52a16cd1357d2d?utm_source=rss

本期硬地骇客与迪魔王串台，主持人邀请字节跳动 Trae 团队的架构师天猪和负责开发者运营的五花肉，从 Cursor 的爆发谈起，聊 AI Coding 的演进、Trae 的技术实现与市场策略。主持人开场就用数字说明市场潜力：Cursor 的营收从 2023 年约 100 万美金涨到 2024 年 11 月突破 6500 万美金。

天猪出身字节 DevInfra，曾在蚂蚁和字节做 Node Infra，近两年负责 Cloud IDE。他解释字节进入这个市场的原因：部门本来就在服务内部成千上万的工程师，大模型出现后看到了提升开发效率的可能，于是把内部的 Cloud IDE 和代码助手推向更大的市场。他观察到，别的大厂的 Cloud IDE 多是外包在用，字节却有大量正式员工在用，甚至反过来催团队优化性能，他猜测与算法同学联调需要在线环境、本地机器规格不够以及合规有关。他强调 Cloud IDE 不等于 Web IDE，UI 层和背后的容器都可以在本地、浏览器或远端 K8s 之间组合，所以 MarsCode 和 Trae 由同一团队负责。五花肉补充，和通义灵码等偏 to B 的插件产品相比，他们更偏个人开发者，强调激发创意。

谈到 Cursor 为何爆火，天猪认为 Claude 3.5 Sonnet 的突破放大了 Cursor 长期积累的工程能力，是厚积薄发。他借自动驾驶把 AI Coding 分成四级：L1 人工编程，L2 AI 辅助编程，L3 AI 结对编程，L4 AI 主动编程。补全一路从下拉提示演进到 Copilot 的 Ghost Text，再到 Cursor 和 Codeium 预测下一个编辑位置的超级补全，这背后依赖大量 commit 数据的专项训练。侧栏对话的原理是把当前文件、光标位置、最近访问的文件、目录结构拼成一段大 prompt，难点在于理解项目、裁剪上下文，以及用 Fast Apply 小模型把生成片段合并回文件、节省 token。主持人由此意识到，自己在 ChatGPT 里随手写 prompt，效果不如 IDE，就是因为缺了这些上下文。L3 的代表是 Composer、Windsurf 和 Trae Builder：它们能拆需求、做计划、执行 npm 命令、打开浏览器、读报错再修复，像一个需要人确认关键步骤的高潜实习生。Devin 则瞄准 L4，想一步到位，但天猪试用后觉得又慢又贵，就停了订阅。主持人认为，信任取决于能力，程序员目前只放心 L2，并不是天生想掌控。天猪还把 Bolt.new、v0 这类从 Chat 出发的产品，和 Trae 这类从本地 IDE 出发的产品，比作从南北两坡攀登同一座山。前者深受产品经理欢迎，因为跟 AI 描述需求不用排期，也不会被扯皮。

技术实现方面，天猪解释了为什么要 fork VS Code：插件体系受限，而且 VS Code 对 AI 的理解跟不上每月都在刷新的认知。Trae 把前端组件 React 化，把 IDE 的 server 层用 Rust 重写，云端启动时间从业界的 30 秒到分钟级压到 2 到 5 秒。fork 的长期成本在于持续跟进上游合并，他们已经用自动化工具，甚至让 Trae 自己去合版。主持人抱怨 Trae 还不能连续 Tab，天猪说下个版本就会上线。被问到 Cursor 是否影响了发布节奏，天猪说团队从 2023 年 11 月就切入这个方向，Cursor 只让他们调整了优先级。他认为本地 IDE 免去了代码上云的合规顾虑，而 DeepSeek 已成为 AI 时代的 K8s，让私有化部署变得容易。

市场策略方面，五花肉介绍，Trae 选在 Product Hunt 首发，和海外用户一起打榜，以体现团队激发创造的风格，目前还没有付费计划。主持人提醒，免费不是长久竞争力，各家功能趋同。天猪回应说，Trae 的差异在 UI 和醒目的 Preview 面板：前端代码靠预览来低成本 review，他自己做小工具时可以全程不看一行代码，只靠截图标注来改。他认为这个领域还没跨越鸿沟，差距最终取决于生成效果、效率、规模和成本。他强调，在模型相同的情况下，核心竞争力是以合适的大小和速度拼出合适的上下文；成本上则要在智能、成本和延迟这个“不可能三角”里权衡，靠混合模型、裁剪上下文、缓存 prompt 等工程手段打磨。至于怎么用好这类工具，他建议把 AI 当实习生，管理好期望值，把需求说清楚，并善用 @ 引用文件、终端日志和截图等多模态输入。

最后，主持人担心 AI 只会让所有人更卷，天猪持中立而乐观的态度：这是汽车取代马车式的趋势，AI 带来了跨界的可能，他的团队就借助 AI 把 Builder 先后用 Node.js、Go、Rust 重写。工程提效本是永恒命题，AI 只是添砖加瓦，也能帮助程序员提升表达和思考能力。节目以 Trae 国内版上线和团队招聘前端与 AI 方向工程师的信息收尾。
