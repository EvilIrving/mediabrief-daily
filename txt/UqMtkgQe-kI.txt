这期节目录于 2025 年 12 月 1 日，嘉宾是 Manus 联合创始人兼首席科学家季逸超（Peak）。节目上线前几个小时，Meta 宣布全资收购 Manus，这次三个半小时的长谈于是成了 Manus 被收购前的最后一次访谈。录制时双方都不知道收购的事，收购也没有被谈及。季逸超从自己少年时期的创业讲起，一路讲到 Manus 怎么诞生、怎么做 Agent、怎么和模型厂商相处、怎么看待发布时的争议。他说话直率、爱自嘲，反复回到几个信念：别做垂直整合，相信通用方法（The Bitter Lesson），保持克制，以及“与其悬而未决，不如赶紧试试”。

**一、前两次创业：早十步就是先烈**

季逸超的父亲是北大物理系教授，母亲是中关村的老一辈连续创业者。2009 年他还在北大附中读高中，赶上 App Store 刚出现，做了一款付费的第三方 iOS 浏览器“猛犸浏览器”，靠一份一份卖拷贝赚了三十多万美元。他说这让他第一次能向父母和老师证明“瞎捣鼓”也有价值。那时国内用户付不了款，他就自己破解软件发到国内论坛“赚吆喝”，因此被真格基金的徐小平注意到。他拿了 term sheet，放弃上大学去创业，真格承诺“不管他干什么”，这个承诺一直兑现到今天。

为了让浏览器预测用户的下一次点击并提前加载，他进入了自然语言处理领域。2013 年 Word2Vec 让他觉得“新世界的大门打开了”，加上当时盛传苹果要做手表，他判断“十条蓝色链接”式的搜索会过时，于是第二次创业做语义搜索和自动构建知识图谱。团队研究开放式信息抽取，从零预训练模型，2018 年就在解决长上下文问题（从 512 个 token 做到 16K），项目叫 Maggie（取自动画里的超级计算机），从爬虫、索引到模型全部自研。他说那是自己智力和编程能力的巅峰，也是“这辈子想试的技术都试完了”，从此再无“要证明自己”的执念。2019 年拿到 GPT-3 的早期测试权限后，他随手写个提示词，效果就和自己训练的专用模型五五开，“觉得天要塌了”，第一反应是赶紧把公司卖掉。他总结了三条教训：垂直整合太痛苦，每天醒来都像海水在上涨；做得太早，“早一步是先驱，早十步就是先烈”；他自己不适合当 CEO，既不喜欢商业化，也讨厌管人。

之后他在一家准备上市的 to B 独角兽公司工作了一年半，从零搭起大模型业务。公司内部用榜单激励，赢得越多就能分到越多显卡，他一直霸榜第一。接着他在真格当驻场创业者，几乎和国内外所有大模型公司都聊过，最欣赏千问、DeepSeek 和 Kimi，但决定不去做模型。

**二、为什么跟肖弘做 Monica，又为什么放弃 AI 浏览器**

他想找的不是一号位的位置，而是一块“空的画布”。肖弘（Red）的 Monica 是一个 Chrome 插件：不改变用户习惯，可以无偏地观察用户怎样用 AI；功能按上下文出现，看 YouTube 时才出视频功能，避免“每加一个东西都稀释所有价值”；而且约有 1200 万美元 ARR、自身盈利。有正向现金流的产品，能让团队做第二曲线时“既大胆又理智”。他最看重肖弘的一点是“很正常”：身心健康、没有不良嗜好、思想不极端。他调侃行业里不少人“没有乔布斯的命，却得了乔布斯的病”，认为移动互联网时代成本低，可以容纳“艺术家型”创始人；AI 更像制造业，成本随用户线性增长，更考验稳健经营。Manus 有六位合伙人，CEO 肖弘负责产品最终拍板，CPO 张涛常年在外对接合作。他们的决策分三层：定目标时专断，排优先级时一人拍板但充分讨论，提方案时充分民主，因为方案的数量比质量更重要。

2024 年 3 月加入后，肖弘用一句话说服了他：“想不想在一个产品里把浏览器、搜索引擎和语言模型重新做一遍？”团队从 4 月到 9 月做了一款 AI 原生浏览器，形态已经很像后来的 ChatGPT Atlas，但越做越觉得不对：AI 和人共用一台电脑会互相打断；真正有价值的是长任务，可电脑一合上就停了；最关键的是回答不了“它能做到什么 Chrome 加 Monica 做不到的事”。历史上浏览器只迁移过两次，靠的都是分发渠道。恰好 Arc 的创始人宣布放弃 Arc，说自己连亲戚朋友都劝不动换浏览器，团队便在 9 月底自然地放下了这个项目。他的原则是：做完自己都觉得不酷的产品，就别发。

**三、Manus 的诞生**

无所事事的两周半里，他们注意到公司里的运营、数据分析同事都在用 Cursor 写博客、做可视化，根本不看左边的代码，只和右边的 AI 对话。这让他们意识到编程不是一种垂直能力，而是完成通用任务的媒介。于是团队做了三处改造：让 Agent 在云端异步运行，解放用户注意力并支持多任务并发；把代码藏起来当工具；面向非程序员的脑力工作者（prosumer）。项目代号是“Browser in Browser in the Air”，浏览器阶段积累的技术几乎都派上了用场。名字来自 MIT 校训“Mens et Manus”（心与手），别人都在做“心智”，他们要做触达真实世界的“手”。张涛跑的一个找办公室的例子，Manus 自己查资料、看地图、写程序，最后做出一个交互网站，让大家确信“一定能成”。产品 2025 年 1 月中旬基本完成，但季逸超坚持再打磨一个多月，让发布与 Claude 的下一代模型对齐，吃到最大的代际提升。

这期间他们做了三个判断：不自己训模型，因为模型迭代追不上产品经理的想法，应该等产品找到 PMF 之后再为降本或提高天花板去做；押注后来所说的“上下文工程”；不做“中国版 Cursor”。他用“壳”打比方：Monica 是生鱼片，好坏全看原料；Agent 多了“环境”这个第三要素，壳像地壳一样厚，像一锅水煮鱼。

**四、通用 Agent 的产品哲学**

坚持做通用 Agent，他给的理由有几层。技术上，通用模型加上一台虚拟机（相当于图灵机），两样底层供给本来就是通用的，做垂直等于自加约束。产品上，他用“达尔文式”的心态观察用户，再给 PPT、网站、批量文件处理这些头部场景做最后一公里优化；同时靠长尾取胜，就像 Google 赢在长尾搜索。一位分子生物学家上传了一种冷门的仪器数据格式，Manus 自己去 GitHub 下载解析工具完成分析，这种长尾对那个人来说是每天的工作。统一的 Agent 框架也让上下文可以在任务间流转，所以 Manus 总能比垂直产品“多做一步”，比如先做研究，再做带数据库的网站，再分析流量、做幻灯片、发邮件给投资人。新增的能力还会互相组合：加入“看图”能力后，Manus 自己学会了检查生成的网页能不能用。

环境方面，每个会话背后都是一个隔离的一次性沙盒。他们选了 Firecracker 全虚拟化，所以也能跑 Windows，还维护了一个专门给 Agent 用的 Linux 发行版。“广域研究”能一次启动上百个沙盒并行完成任务。他自称“纯血派”：任务过程应由智能决定，而不是靠工作流和规则打补丁。与其给数据可视化写一堆注意事项，不如加一个看图能力，让模型自己发现字体乱码、元素重叠。他反对把人类分工硬套给模型，让 Agent 分别扮演设计师、产品经理，认为“把 Agent 人格化是人的自恋”，并强调做 Agent 是同时做两个产品，一个给人用，一个给模型用。他不愿称 Manus 为 Agent OS，认为现有操作系统都会长出 Agent 能力，Manus 已经和微软合作，进入了 Windows 右键菜单和 Agent 365。

**五、与模型厂商：把训练“外包”出去**

Agent 的输入输出比在 100:1 到 1000:1 之间，聊天机器人大约是 3:1，所以 Manus 在各家模型厂商都是全球前二到前五的 token 消耗大户。发布时公司是亏损的，现在已接近打平。他用这份影响力“外包”模型训练：帮厂商搭评测，Gemini 可控并行函数调用的接口定义就是他写的。他认为多数模型仍是按聊天场景后训练的，到了长任务后段会感到“上下文压力”，急着收尾、狂写要点。他对模型厂商提了几条建议：与其无限扩展上下文，不如让模型具备“压缩意识”，把信息存到文件系统、需要时再取回，200K 以上的上下文已经不重要；推理应该是拿到观察后短暂思考的交错式推理，而不是“缸中之脑”式的长思维链，否则指令遵循变差、工具调用幻觉增加；支持用户在任务进行中随时插话；以及错误恢复能力，永远能找到另一条路。他们对 MCP 非常保守，因为动态加载工具会污染动作空间、拉低缓存命中率、推高成本。

各家厂商的长处已经分化：Anthropic 的工程化编程最强，他认为 Opus 4.5 被低估了；Gemini 在多模态理解上断层领先，还能用到 Google 的索引和 YouTube；OpenAI 在推理上投入最大。应用公司可以挑每个场景最好的模型，迭代也比垂直整合的模型公司快，“他们成了分化的，我们成了综合的”。他还预言，半年内头部应用公司都会凭借自己的数据飞轮训练模型，Cursor 的 Composer 就是例子。他承认自己的一个误判是早期太迷信小模型，后来发现参数量依然重要。

**六、邀请码、营销争议与商业模式**

对外界最大的两个质疑，他第一次正式回应。邀请码是因为发布前问遍云厂商和推理供应商，发现世界上能立刻到位的算力远比想象少，有厂商直说“千万别放开，放开我们会挂”。上线当天他们要求临时扩容，对方问“下个月还是下下个月”，他们答“今天下午”。最后是 Google Cloud 等伙伴从别的可用区调资源、在物理层面插卡上架，才撑过第一个月，当时一天要烧几十万美元。他承认没料到邀请码会被炒卖，定向邀请会更好；不到一个月邀请码就取消了。关于营销，他说得极重：“如果我们在 3 月发布时做过任何付费宣传，我死全家。”Manus 只做海外，北京时间晚上十点发布是为了对上北美的早上。国内一夜爆火是多年“广结善缘”，朋友和自媒体主动写的；美国是三天后从 Karpathy、Patrick Collison、Jack Dorsey 这些人开始自上而下传开的，两条链路几乎不重叠。国内很多骂声来自山寨应用，他郑重声明国内 App Store 里搜到的“Manus”都是假的。

商业上，ARR 已超过 1 亿美元。他强调只认“MRR 乘以 12”这一个口径，反对一切注水的 ARR。最初定价 20 和 40 美元，是照着 ChatGPT 的 20 美元“拍脑袋”定的，现在默认 40 美元一个月，本质上按用量计费。用户问的不是能不能便宜，而是付 200 美元效果能好多少，有人每月要付几千美元。所以公司看的是营收，不是 DAU。Agent 用户和聊天机器人用户是两个层级，ChatGPT Agent 推出后效果明显不如 Manus。a16z 的数据显示，装了 ChatGPT、Claude 的用户，最可能额外安装的就是 Manus。Manus 1.5 在平均体感上快了三到五倍，用户反馈它跨过了“生产力工具”的门槛。他也发现，用版本号打包更新，用户才能感受到变化。

**七、组织、行业判断与隐忧**

团队约百人，有两个特别的组：沙盒组负责“教一个不会用电脑的人用电脑”；Agent 组由 Agent 工程师、评测和小型研究团队组成，用“弱到强”的方法迭代框架，也就是锁定框架、比较同一模型家族的弱版和强版，调整框架让两者差距最大，这样下一代模型出来时收益最大。评测高度依赖用户的反馈和主观打分，因为用户在意的是幻灯片比例对不对、网站好不好用，这些很难自动验证。在 Scale AI 的“远程劳动力指数”上，Manus 排名第一，但完成率只有 2.5%，他把这看成还有巨大空间。他们每个月都在想能删掉什么，放弃了语音输出等功能，更愿意和 Notion、微软等伙伴联合发布，“价值往往不在节点，而在网络的边上”。团队搬到新加坡，是为了集中办公和满足全球合规要求，他不认为这是“跑路”。

对行业，他认为现在像 2018 年：Transformer 和 BERT 之后的狂热，大家在等下一个“GPT-3 时刻”。狭义的 Scaling Law 还在起作用，Agent 已经爆发，但每个场景都还“差一口气”。AI 泡沫客观存在，但在可接受范围内。他点评了海外各家：OpenAI 自下而上的研究文化依然最可能诞生新范式；Anthropic 盯着高经济价值；Gemini 3 证明预训练还能继续；xAI 押注“像素进、像素出”；田渊栋的隐式推理方向很有意思。他认同姚顺雨的观点，但不同意杨植麟“不训模型做 Agent 是逆向工程”的说法。他接下来最看重的是主动性，比如 Manus 每天在他醒来前读完 Notion 里的面试记录，替他填好招聘系统的评价，只问他接不接受。“通用 Agent”这个词其实是个意外：宣传片里一位保洁阿姨入镜，只好剪成黑屏配一句定义，词就这么来了。

他最大的隐忧，对外是失去特色，对内是变得复杂，保持克制又不能牺牲增长。最好的预期是让每个高价值白领都有一个 7×24 小时推理的 AI 伙伴，最坏的预期是“下个月死掉”，因为创业公司“没有活着的权利，只能靠一直跑去争取”。问他如果 Manus 死了做什么，他说“歇一会儿，太累了”。他形容这一年像“从 CBA 打进了 NBA”。最后问到他当下最关键的一个判断，他的回答是：AI 接下来的进步需要用户的参与。
