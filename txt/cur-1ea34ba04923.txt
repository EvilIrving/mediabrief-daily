现代大语言模型注意力机制的演进历程，展现了在上下文长度、内存占用与推理吞吐之间的工程权衡。主流开源权重模型中采用的核心注意力变体涵盖传统多头注意力、轻量化缓存机制、稀疏窗口以及新兴的线性混合架构：

一、多头注意力（MHA）：起源于突破传统循环神经网络（RNN）编码器固定隐藏状态的性能瓶颈。Transformer 架构通过因果掩码自注意力矩阵、Q/K/V 线性投影与 Softmax 归一化，支持多个注意力头并行捕捉序列中不同子空间的依赖关系。代表模型为 GPT-2 与早期开源基准模型。由于自回归推理阶段每个头均需独立保存 Key 与 Value 矩阵，随着并发请求增加与上下文延伸，其显存占用成为系统扩展的主要瓶颈。

二、分组查询注意力（GQA）：由 Ainslie 等于 2023 年提出，处于多查询注意力（MQA，单组 KV）与标准 MHA（每个 Query 头独立 KV）之间。通过让多个 Query 头共享同一组 Key 和 Value 投影，成倍削减自回归推理时的 KV 缓存显存占用。因训练稳定、易于适配硬件算子，GQA 成为现代主流大模型的基础标配配置（如 Llama 3、Qwen3、Gemma 3 等）。

三、多头潜在注意力（MLA）：由 DeepSeek-V2 首创，其核心逻辑并非共享注意力头，而是将 Key 与 Value 联合压缩至低维潜在向量（Latent Vector），推理时仅缓存该紧凑表示并在计算前临时解压，配合解耦的 RoPE 位置编码机制。消融实验表明调优后的 MLA 性能可比肩或超越全量 MHA，已被 GLM-5、Kimi K2、Ling 2.5 与 Mistral Large 3 等广泛采纳，成为大参数量模型削减显存的核心路径。

四、滑动窗口注意力（SWA）：限制每个 Token 仅与局部固定窗口内的历史 Token 计算注意力，并周期性穿插全量全局注意力层。Gemma 2 采用 1:1 交替与 4096 窗口，Gemma 3 激进扩展至 5:1 局部与全局比率及 1024 窗口，小米 MiMo 更将局部窗口收敛至 128，常与 GQA 组合以同时压缩计算复杂度与每 Token 缓存开销。

五、DeepSeek 稀疏注意力（DSA）：引入动态自适应机制替代固定静态窗口。DSA 依托 MLA 压缩表征，通过轻量级“闪电索引器”（Lightning Indexer）为历史 Token 评分，动态保留 Top-k 相关位置，实现模型自主学习回看跨度，在大幅降低长上下文二次方计算复杂度的同时保留远距离长程检索精度。

六、门控注意力（Gated Attention）：在注意力模块输出端增加门控激活机制，并引入零中心 QK-Norm 与局部 RoPE 调整，主要用于抑制长序列推演中的数值不稳定，广泛应用于混合架构模型中的保留全注意力层（如 Qwen3-Next 与 Qwen3.5）。

七、混合注意力（Hybrid Attention）：在保留 Transformer 骨架的同时，将多数昂贵的全注意力层替换为线性注意力或状态空间模型（SSM）。例如 Qwen3.5 融合 Gated DeltaNet 与门控注意力，Kimi Linear 采用通道门控 Delta Attention 搭配门控 MLA，Ling 2.5 整合 Lightning Attention，Nemotron-3 采用以 Mamba-2 为主干的稀疏注意力结构。此类架构专注长上下文线性计算效率，但在现有推理软件栈成熟度与通用短文本吞吐上，传统 GQA 仍具备极强的工程落地优势。工程选型需综合考虑显存带宽、硬件算子生态与长短文本比例。
