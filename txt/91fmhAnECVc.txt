这是张小珺时隔一年再次对话月之暗面创始人兼 CEO 杨植麟，录于 2025 年 7 月 Kimi K2 发布后不久。上一次访谈的标题是“向绵延而未知的雪山前进”，这一次杨植麟换了一个更乐观的比喻：他反复读了物理学家戴维·多伊奇的《无穷的开始》（The Beginning of Infinity），书里有两句要“刻在石头上”的话：问题不可避免，问题可以解决。他希望 AI 这座雪山没有尽头。整期节目大半在谈技术，从推理和 Agent 两种范式、K2 的研发，到开源、商业化，最后落到他如何用强化学习的眼光看管理、看自己。

**一、一座无限的山**

他说过去一年模型进步很大：两年前写一篇文章都写不明白，现在能连续工作几个小时完成复杂的编程任务。强化学习怎么做已经更清楚，但新的问题随之出现，比如强化学习最终依赖好的评估和验证，数学题、带测试用例的编程好办，复杂的端到端任务却很难衡量。在他看来这正是《无穷的开始》描述的过程：启蒙运动之前社会是静态的，之后知识不断被创造，每解决一个问题又带出新问题。他追求的就是一直往上爬，而且爬到后来可能是用 AI 来爬，团队已经在用 K2 做数据处理和模型训练相关的工作。他不再把 AGI 当成某一级台阶，而是一个方向：AGI 不像登月，没有“登上月球那一刻”可以宣布达成；技术对社会的影响也像蒸汽机一样，需要几十年去消化，最终每个人都会成为“超人”。

**二、两种 test-time scaling 与“一方产品”**

他认为过去一年最重要的变化有三点。一是以 o1 为代表的长思考强化学习：模型在推理中不断提出猜想、隐式地自我验证，相当于把 pass@k 变成 pass@1；但它仍是“缸中之脑”，像一个泡在鱼缸里的大脑，不和外界交互。二是多轮 Agent 强化学习：模型边想边调用搜索、浏览器、写代码，根据外界反馈决定下一步。两者本质上都是 test-time scaling，即在推理时用更多 token 或更多轮次完成更复杂的任务，比如把一个代码仓库克隆下来、翻译成另一种语言、调试到能跑通。三是模型公司开始做自己的“一方”Agent 产品，如 Claude Code、ChatGPT Agent。基于别人模型搭脚手架的产品（如 Manus）本质上是在逆向工程模型的训练环境；一方产品则先设计好工具和上下文工程，再在这个环境里训练模型，上限可能更高。月之暗面目前在一方产品上投入不多，主线仍是模型。

对于 OpenAI 的 L1 到 L5 分级，他认为并非线性。Claude 就是把技术押在 Agent 上而没有在推理上做太多，但要做最好的 Agent，终究需要很强的推理。“创新者”阶段的关键是模型能否参与自身研发，比如让 K2 参与 K3 的开发，这离不开 Agent 能力；“组织者”则可能是从一个 Agent 分叉出多个分工协作的多智能体系统。反过来，今天 Agent 泛化不够好，可能恰恰要靠 L4 的“用 AI 训练 AI”去解决 L3 的问题。

**三、K2：token efficiency 与 Agent 泛化**

他说 2024 到 2025 年最关键的决策，是把研发重心从“预训练加 SFT”转向“预训练加强化学习”，产品形态从对话转向 Agent。K1.5 主要验证了强化学习路线，发现不太需要过程奖励或价值函数，直接用端到端奖励就能训好。K2 有两个目标。第一是做一个非常好的基座模型：高质量数据增长很慢，几乎是常数，多模态数据又提升不了文本的“智商”，所以要追求 token efficiency，即吃同样多的数据，“脑子长得更多”，而不只是训得更快。核心手段是 Muon 优化器：Adam 已经用了十年，把参数元素独立看待，Muon 基于矩阵正交化考虑参数间的依赖，早期实验里约有两倍提升，30T 高质量数据相当于 60T。Muon 由 Keller Jordan 提出，团队先在 Moonlight 上验证，扩大规模时又遇到小实验预测不到的 max logit 爆炸，用 clipping 解决了；这也是整个训练里唯一没提前预测到的问题。此外，他们用模型改写高质量数据来改善泛化，用更大的稀疏度增加参数量。第二是 Agent 能力，最大的挑战是泛化：今天的强化学习任务和指标多是单点的，benchmark 少而且快饱和，刷高了分数不代表模型真的更好用。他们训练时选中等难度的任务，让强化学习形成隐式的课程学习；也希望模型不仅会写代码，而是成为通用 Agent，能用上公司内部数据库、定制 API 这类没见过的长尾工具。若做到这一点，很多垂直 Agent 就未必需要了。他说编程是 Agent 最重要的子集，相当于人类的手，代表数字世界的自动化。长上下文也很重要，难点是上下文变长的同时“智商”不能降，纯线性注意力就会伤智商。

关于 K2 本身：它取名与世界第二高峰、公认最难攀登的乔戈里峰重合，意思是很难但不是终点。相关技术积累了一年多，决定训练是在最近几个月；研究和训练是同一个团队。他强调预测能力比惊喜更重要，所以训练结果基本在意料之中。他认为 K2 更接近一个 base model，加更多后训练算力后上限还会高很多；下一代模型会继续提升基座，多模态是确定要做的，但要“聪明的多模态”，不能另开一个傻脑子。对于张祥雨所说“next token prediction 的本质缺陷”，他认为大模型不做强化学习确实难以聪明，但更大的基座强化学习上限更高。

**四、开源、产品与商业**

一年前他说过开源会落后于闭源，如今 K2 开源了。他的解释是：社区能在推理部署和后训练上贡献很多，创业公司可以基于 K2 训练法律等垂直领域的专用 Agent，但让基座本身变好仍只能靠原厂。开源既是技术信仰也是市场博弈，他会长期分享技术，但未必全部开放。他判断全球大模型最终会收敛到几家。他依旧相信“模型即产品”：训练 Agent 模型时必须把工具和上下文搭好，模型训完产品也就差不多了，交互方式会随模型能力演变，就像编程工具从 Copilot 到 Cursor 再到 Claude Code。为什么 AI 产品还没有数据飞轮？因为基于算力的 scaling 太有效，尤其强化学习是带负梯度的 on-policy 训练，效率高；而用户反馈噪声大，大模型又对噪声敏感。不过用户量仍有价值，能告诉你需求分布、该往哪里优化，Agent 类专业用户本身就能产生商业价值。被问是否要做“中国的 OpenAI”或“中国的 Anthropic”，他说应站在全球视角，简单说就是继续爬山、做时间的朋友。商业上 API 和一方产品都会尝试，头部公司的 AI 收入每一两个季度就能翻两三倍；能不能赚钱，取决于模型效果，如果能做到 Opus 的水平，空间会更大。他认为一方产品有垂直整合优势，但 Agent 空间太大，掌握独特工具或线下服务入口的公司仍有机会；与 Manus 这类公司短期内合作大于竞争。技术快速发展期很难靠投流赢，最大的变量依然是智能。

**五、用强化学习看管理和自己**

他认为科研、知识创造和管理都像强化学习：知识不是从经验直接来的，人类在地球上生活了很久，却直到几百年前才提出地球是圆的，靠的是提出猜想再验证。联合创始人周昕宇（Tim）常对他说，团队要用 RL 的方式管而不是 SFT：适量的 SFT 像先验，防止“飞得太远”；SFT 太多，大家就失去主观能动性。RL 式管理最大的风险是奖励被 hack，所有人不择手段把指标做上去，模型却没有变好，所以要建立更多观测指标。他说这就是自己对 CEO 角色的最新理解。

面对外界的起伏，他说要“不以物喜，不以己悲”，避免情绪化决策；过去一年的成长是接受“问题不可避免”。他认为 Kimi 成功的概率比一年前更大，因为每往上爬一步，就有人不再爬了；恐惧当然有，但更多关注眼下这一步。弯路肯定走过，就像牛顿的理论在当时最好、后来也被修正，任何中间状态都会被批评，要在人才和技术积累上坚持不变的东西，同时根据反馈不断调整。为什么做 AI？他说 Kimi 告诉他，AI 是人类文明的放大器：从启蒙运动以来，人类一直在突破知识边界，下一次突破要靠 AI 这个巨大的杠杆，它可能成为一门“元科学”。风险存在，但因噎废食就等于放弃了文明的上限；人生的意义在于创造、体验和爱，创造可能部分交给 AI，体验和爱仍以人为中心，社会机制需要一二十年去调整。快问快答里，他最喜欢的食物是拉面，推荐的书仍是《无穷的开始》，心目中最重要的论文包括反向传播、Transformer、GPT-3、ResNet 和 Adam；当下最关键的赌注是 Agent 的泛化，用 L4 的方法去做 L3。最后他笑说一年的话都讲完了，这是“碳基生物的局限性”。
