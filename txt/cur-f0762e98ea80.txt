这一期 ShopTalk Show 由 Dave Rupert 和 Chris Coyier 主持，请来 Jake Archibald 讨论一个看似简单的问题：CSS 能用 @import 引入别的 CSS，JavaScript 能用 import 引入别的 JavaScript，为什么 HTML 不能引入 HTML？Chris 此前写过一篇文章问这件事，最典型的场景是 Web 开发课第二周：三个页面共用同一套页头和页脚，结果要么复制粘贴，要么引入构建工具。三人干脆在节目里把一个原生 HTML include 当场设计了一遍。

先排除的是 iframe 和 object：它们的内容像被一堵墙隔开，CSS 进不去，尺寸也不会随内容变化。Chrome 近期提出的"响应式 iframe"需要嵌入方和被嵌入方都声明同意，但只在内部文档触发 load 事件时调整一次高度，Disqus 式的"加载更多评论"照样解决不了。Jake 在 blink-dev 上的反馈是：既然这么麻烦，还不如自己用 postMessage。

接下来是设计本身。Jake 认为它应当是一个标签，并且默认阻塞解析，就像不带 async 或 defer 的传统 script。传统 script 之所以阻塞，是因为里面可能调用 document.write 往解析器里插内容，而 include 做的正是同一件事，只是不需要脚本。如果默认异步，内容到达后页面就会跳动，在本地开发时又因为加载太快看不出来，这正是 Jake 最想避免的那类"隐藏陷阱"。他举了 view-transition-name: auto 作为反面例子。异步可以作为显式开启的选项。引入的内容必须是一棵完整的树，没闭合的标签按浏览器现有的纠错规则补齐，所以 WordPress 那种 header.php 开 div、footer.php 关 div 的做法行不通。如果需要包裹结构，可以考虑类似 slot 或 Remix outlet 的插槽。Dave 拿 JavaScript 类比：你也不能在一个文件里写 if 的左花括号、在另一个文件里写右花括号。被引入的文件可以继续引入别的文件，但禁止循环引入。

安全方面，include 应当只允许同源。更麻烦的是那些按黑名单过滤用户 HTML 的老论坛或评论系统：多出一个 include 标签，就多出一种执行脚本的途径。解决办法可以是写成某种 script 的 type，或者像可定制的 select 那样通过 meta 标签显式开启。顺带吐槽了现在这类 opt-in 越来越多，还调侃了 AMP。推广方面，这个特性可以用 Web 组件做 polyfill，但搜索引擎、LLM 爬虫和社交平台的抓取器都不执行 JavaScript，Sam Rose 想用它复用 head 里的 meta 标签，在这些场景下就会失效。Chris 还开玩笑说可以把它叫作 fetch 元素。

Jake 指出，这个提案在标准圈屡次受阻，是因为在服务器端拼装更快，标准制定者把客户端 include 视为倒退。他也很遗憾 GitHub Pages、Netlify 这类托管没有提供 Apache 式 SSI 那样的基本 include。Chris 则从教学角度坚持：学习者不该一想自动化复制粘贴就被推去学 PHP。Jake 认为反过来看，现状其实是大家用 fetch 拿到一整段文本再塞进 innerHTML，必须等全部下载完才能显示，比流式解析慢得多。他举了在机场 Wi-Fi 下打开 GitHub 长讨论帖的经历：整页刷新反而更快。所以更现实的路径是先做一个底层 API，把 fetch 的响应直接流式写进某个元素，比如 response.body.pipeTo 到 DOM，浏览器厂商对此兴趣不小，只是缺人去做；有了这一层再推 include 元素会容易得多。Chris 透露 Google 正在研究"声明式流式内容"，大概也受到了 AI 聊天逐字输出的推动。Jake 顺带讲了流式传输的来历：HTTP/2 下一条连接可以承载多个请求，保持响应打开毫无负担。

后半段转向相关话题。2014 年 Mozilla 否决 HTML Imports，说要等 ESM 落地再看，此后再无下文。Jake 解释，HTML Imports 本质上是打包了模板、CSS 和 JS 的组件定义文件，并不渲染内容，也不支持流式，弃用它是对的；如今真正缺少的是一种打包原语，比如能够内联 JavaScript 模块。Dave 提到 import map 只能有一个的限制，也谈到用 import 引入 JSON 时缓存永久生效的问题。他们还讨论了声明式 shadow DOM 需要在每个实例里重复写，Jake 把组件分成"交互组件"和"HTML 宏"两类，认为 Web 组件做不了后者。Chris 介绍了不带选择器的 @scope 可以把 style 的作用域限定在父元素，微软也有提案让声明式 shadow DOM 复用页面上已有的样式。最后是一些闲聊：HTML 规范里的"Jake 图"是 Domenic Denicola 起的名字；Dave 创造的 FART（flash of inaccurate color theme）进了规范；Jake 吐槽 Paul Lewis 的 FLIP 缩写，如今已被 View Transitions 取代；还聊到了 content-visibility，以及元素级视图过渡。节目结尾，Jake 透露自己当天刚从 Shopify 辞职，下一份工作已经定好（后来去了 Mozilla），但暂时还不能公开。
