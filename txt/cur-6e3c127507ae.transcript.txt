Jack：有时候你读到一条新闻，它会一辈子留在你脑子里。我就有这么一条安全新闻，永远忘不了：那是我第一次看到关于 NSA ANT 目录的演讲。你见过这个吗？简直颠覆认知。事情是这样的：某个能接触到 NSA 文件的人把 ANT 目录交给了《明镜》周刊的记者，随后被公开发表。起初我们以为是斯诺登泄露的，但现在也不确定是他还是另有一位泄密者。我在 Twitter 上问过斯诺登是不是他，他没回。那么 NSA 的 ANT 目录是什么？ANT 是 Advanced Network Technology（先进网络技术）的缩写，这本目录列出了 NSA 执行特定任务时可以使用的各种黑客手段、漏洞利用工具和网络监控设备。如果你在 NSA 工作、需要一个漏洞利用工具，就翻这本目录，然后申请其中某个设备或软件。

翻看它的时候，你会觉得像科幻小说，但这些都是真实存在的设备。举几个例子：NSA 做了一个代号 COTTONMOUTH 的设备，看起来就像普通的 USB 插头，鼠标或键盘上那种，但它实际上会截获经过它的所有数据并无线发送出去。它监听鼠标点击、键盘敲击以及其他任何经过的数据。接收端得离得近，大概二十英尺吧；如果天线够强、中间没有遮挡，也许能传得更远。有人可能就在隔壁房间，看到你的 USB 接口看到的一切。这是 NSA 在 2008 年就开发出来的下一代技术，至今市面上都买不到。目录里甚至标了价格：每个 USB 植入设备 2 万美元。天哪，真贵。ANT 目录里还有大量其他黑客工具和植入物。

有 DROPOUTJEEP，这是一个软件，只要你能把它装进一部 iPhone，就能拿到所有短信、联系人、语音信箱，还能偷偷打开麦克风或摄像头，获取手机的地理位置。有 FIREWALK，一个相当厉害的网络嗅探器。有 JETPLOW，一种固件，让 NSA 获得思科防火墙的后门访问权限。还有 DEITYBOUNCE，一种装在戴尔服务器上的植入物，同样能获得后门访问权限。不过我最喜欢的一个叫 RAGEMASTER，这是个小设备，可以接入任何 VGA 接口——也就是电脑连到显示器的那个接口。有了它，就能把 VGA 接口传输的一切无线发送出去，相当于把那台显示器复制一份，让远处的人也能看到。想象一下这些攻击会怎么实施：NSA 可能截下一台正在运往某处的思科防火墙，小心地打开箱子，刷入他们的固件，再把箱子封好。

这样他们就能随时永久地通过后门访问那台防火墙。或者，如果他们知道目标要住某家酒店，可以订下隔壁房间，潜入目标的房间，装上 COTTONMOUTH 或 RAGEMASTER，然后在隔壁监听无线信号，看到那个人敲的每一个字、看到的每一个画面。即使那个人根本没连无线网或任何网络，也能做到，这真是厉害得离谱。是的，2013 年这本目录里有五十项被公开泄露，但我们只看到了这些设备的描述，没见过实物。仔细研究后发现，这些东西是给 TAO 用的。TAO 是 Tailored Access Operations（特定入侵行动办公室）的缩写，是 NSA 内部的一个部门，主要任务是从计算机系统中收集情报。TAO 的人能接触到有史以来最先进的黑客工具。

他们有预算、有能力花好几年做研发，打造疯狂的工具，然后在需要时随时使用。TAO 是 NSA 的精英黑客部队，现在其实已经改名叫 Computer Network Operations（计算机网络行动），但在这个故事里我还是叫它 TAO。安全公司研究黑客活动时，无法确定到底是谁干的，所以会给黑客起一个独特的代号。俄罗斯黑客叫 Fancy Bear（奇幻熊），伊朗的叫 Charming Kitten（迷人小猫），以此类推。安全公司也调查过某些来自 NSA 的恶意软件，给 NSA 起了个黑客代号，叫 Equation Group（方程式组织）。一般认为，为方程式组织干活的，就是 NSA 内部的 TAO。

Jack：两周后，影子经纪人发布了第二次泄露。一开头他们就写道：“为什么‘肮脏老爷爷’在威胁要和俄罗斯打 CIA 的网络战？”我认为他们这里叫拜登“肮脏老爷爷”，是因为他几周前说的那番话——这说法真的非常奇怪，不过好吧。第二次泄露的内容只是一大串 IP 地址，影子经纪人声称这是 NSA 在全球感染的、或用来发动攻击的服务器清单。这次泄露没那么大，更像是在告诉 NSA：影子经纪人不会消失，提醒你们他们依然是个威胁。

Jack：天哪，我都不知道该说什么了。这就是活在影子经纪人阴影下的生活。这也让我想到他作为 SANS 讲师的身份。我上过 SANS 的课，如果我知道我的老师因为替 NSA 搞黑客行动而在好几个国家被通缉，我会大吃一惊。他是不是罪犯？有些国家可能认为是，但在国内，他只是在执行命令。仔细想想，我觉得 FBI 起诉那些为外国政府工作的黑客其实挺奇怪的。那些黑客只是在执行命令。为什么不起诉签署行政命令的军官、将军或领导人？到了那个地步，还不如把它当作一个国家对另一个国家的敌对行为。我不知道，当涉及国家黑国家时，该怪谁就变得很怪、很棘手。

他一般不会因为这种事点名俄罗斯。但即便他把这件事归咎于俄罗斯，那会是什么样子？那等于承认 NSA 不知怎么地失去了对其秘密黑客工具的控制，可能让美国难堪。所以这是个复杂的问题。哦，我还得在这里提一下哈罗德·马丁三世（Harold Martin III）。有一种理论认为哈罗德与此事有关。哈罗德是博思艾伦（Booz Allen Hamilton）的政府承包商，在那里期间为 NSA 做过一些工作，接触到了 NSA 内部的一些绝密信息。哈罗德决定从 NSA 的服务器上窃取 50TB 的信息，并且成功带了出去。我们不知道哈罗德把这 50TB 给了谁，或者有没有给任何人，我们甚至不知道数据里有什么。但他被抓了，目前因此在服刑九年。影子经纪人泄露的数据可能就是哈罗德偷的东西。

时间戳看起来确实吻合，但没有真正有力的证据把哈罗德和整件事联系起来。好，我们退一步，试着理解整个影子经纪人事件意味着什么。NSA 既没有确认也没有否认这些工具是他们做的。所有迹象都表明，这些是 NSA 真实制作的漏洞利用工具，被他们留作攻击敌人的武器。想想看，这意味着 NSA 有一群研究人员在积极寻找微软 Windows 等软件中的漏洞，找到后却不告诉微软，而是留给自己。NSA 曾公开表示他们不囤积零日漏洞或无人知晓的漏洞利用工具，但这里就是他们确实这么做的证据。这意味着什么？

看起来，NSA 认为进攻比防御更重要。如果 NSA 是防御导向的，他们会和软件厂商合作，找到漏洞并修复。但我们看到的却是：他们秘密地发现漏洞，不告诉软件厂商，以便日后用来攻击别人。也许这就是影子经纪人想传达的信息：让 NSA 因为这样囤积零日漏洞而承受更多压力。事实也确实如此。很多人把这当作证据，证明 NSA 的利益不在于保护我们的安全，而是把这些漏洞利用工具留给自己，以便更好地从事间谍、监控和入侵其他网络的活动。我想，如果他们用这些来发现针对我国即将到来的攻击，这也许可以被视为防御导向。但当我们看到别的国家黑进美国公司、给这些公司造成巨大问题时，这就很难让人相信了。

看，这就是适得其反的完美例子：当 NSA 制作的漏洞利用工具落入坏人之手，或者有人曝光了 NSA 的能力时。斯诺登、ANT 目录泄露，以及现在的影子经纪人，让我们非常清楚地看到了 NSA 在做什么。我认为我们都应该充分注意到这里所看到的。作为一个曾经保护网络免受威胁的人，我想花点时间谈谈我们作为防御者应该如何应对影子经纪人。当影子经纪人泄露所有这些 NSA 级别的黑客工具时，我们应该分析它们，尽可能地理解它们。原因如下：就拿那个被泄露的 Windows 事件日志工具举例。这个工具可以随时关闭再打开 Windows 日志记录，或者删除 Windows 中的单条事件日志。问题在于：历史上，管理员本来就可以开关日志记录。

好吧，但这么做时会生成一条事件，说明日志记录被关闭了。也可以清空所有事件日志，但同样会生成一条日志，说明所有日志已被清除。而且那是清除全部日志，不是一两条。但有了这个被泄露的工具，你可以在不产生“日志已关闭”事件的情况下关闭日志记录。你可以关掉它，干完坏事，再重新打开，没有任何日志被篡改的证据，这真的很可怕，但了解它很重要。它还有删除单条事件的能力。这对我们防御者来说很重要，因为 Windows 事件日志对我们极其重要，它们告诉我们发生了什么的真相。那怎么应对？现在你需要寻找“不在那里”的东西。比如，事件日志是有编号的。如果你看到第 97 条、第 98 条，没有第 99 条，然后是第 100 条呢？第 99 条去哪了？或者，如果你看到一条注销事件，却没有登录事件呢？

如果看到这类情况，你可以推断有个黑客在使用影子经纪人泄露的工具，但又不够精明、不了解 Windows 日志的工作原理——因为这个黑客聪明到删掉了自己的登录事件，却没本事删掉注销事件。这就是防御者和事件响应人员需要从影子经纪人事件中学习的东西。不仅如此，世界上每个高水平的黑客团队都认真关注了这些泄露。我刚才只讲了日志那一个，他们放出的还有七十个其他漏洞利用工具。各国政府的黑客团队很可能已经对泄露中的每一个工具做了深入分析，尽可能了解它的一切：它做什么、怎样最有效地使用，然后放进自己的工具包，随时取用。这就是为什么信息安全圈也必须了解这些。我是说，如果这些黑客工具确实是 NSA 做的，他们大概花了数百万美元做研发。

那是我交的税。所以看到他们的能力是什么，并且知道它现在落在了全世界每个黑客手里，这对任何从事信息安全的人来说都是极其宝贵的一课。我们不是每天都能看到如此精密的工具，而现在世界上任何一个“脚本小子”都拥有并在使用它们。自从这些泄露以来，数字取证和事件响应团队一直在看到大量利用这些泄露内容的攻击，直到今天仍在继续。对我们防御者来说，理解这些非常重要，尤其是那个叫 EternalBlue 的工具。EternalBlue 后来成为世界上一些最大规模黑客攻击的关键组成部分，那些攻击规模大到几乎给很多人带来了末日般的场景。下一期，我们一起深入探讨其中一起使用了 EternalBlue 的攻击。
