Are Agents About to Replace Software Engineering? | Lauren Tan and Roshan Sadanani ｜ MTS ｜ 28:41 ｜ https://youtu.be/A63sedG-p5Q

MTS 节目在 Cursor 与 SpaceX 联合发布 Grok 4.6 的当天，请来 Cursor 的工程师 Lauren Tan 和产品负责人 Roshan Sadanani，前一天他们刚上线 GrokBot 测试版。整期一半是现场演示，一半是轻松闲聊，女主持人是 Cursor 的老用户，对两人的产品热情满满。标题问 agent 会不会取代软件工程，节目里给出的回答其实是：工程师的角色变了，需求反而更大。

两人先讲 GrokBot 的来历。它最早是一个小团队给自己做的原型，后来在公司内部"找到了产品市场契合"：从销售、运营到工程、产品，几乎每个岗位的人都找到了用法。原因一是它能无缝接入大家已经在用的工具，二是每个 bot 都有自己的电脑，你不在电脑前它也照样干活。Lauren 甚至用它抢到了《奥德赛》的 70 毫米 IMAX 票。Cursor 的惯例是先在内部发布，看同事们（被认为品味很高）是否天天用，再推向外部，GrokBot 正是这样走出来的。Roshan 说设计的出发点就是"保持简单"：很多 AI 应用功能强大，代价却是复杂；Cursor 本身面向专业开发者，到处是旋钮，而 GrokBot 想回答"如果 agent 更像同事会怎样"：你不会盯着同事问他在调用什么工具，而是像跟人一样聊天，需要时看一眼他的屏幕。所以界面借鉴了即时通讯，有人已经把它分享给自己的妈妈用。它的想法也来自 Lauren 那个出名的 Slack bot "Benny"：一个以小狗为头像、在她睡觉时自动修 bug 的持久 bot。很多人问怎样做出自己的 Benny，于是有了"每个人都能定义自己的 bot，给它身份、电脑、例行任务和自动化"的思路。

现场演示里，Roshan 让他的"幕僚长" bot 去询问负责网购的 bot "Shoppie" 最近买了什么，又让刚配好的营销 bot 登录他的 LinkedIn，几十秒内就发出了一条宣传帖，还 @ 对了 MTS Live 的账号；接着让幕僚长从内部频道"GrokBot wins"收集好评、做成 Figma 幻灯片。Lauren 则让幕僚长把当天发现的 bug 分派给她的 GrokBot 团队（一群以猫照片为头像的 bot，各管一块功能），这些 bot 再去启动 Cursor 云端 agent，各自在自己的电脑上干活，最后交回 PR、视频和截图给她审查。她说现在每次有人提 GrokBot 反馈，她的 bot 都会自动去修，她只审代码，自己"几乎成了数字同事们的经理"；Roshan 补充说 GrokBot 很大一部分就是用 GrokBot 做出来的。

谈到工程的未来，Roshan 用"效率"一词概括：每个人脑子里都有很多点子，瓶颈在于从想法到实现的那条管道，而让成群的 agent 按你的品味产出高质量成果，就是在不断压缩"从念头到存在"的周期，这也是 Cursor 一路加入越来越多 agent 工具的方向。Lauren 说工程师的新职责，一是当 agent 的经理，二是让代码库保持在 PM 和设计师也能提交高质量代码的状态，例如投入重构乃至重写，把规则和风格指南变成会让 CI 失败的 lint 硬约束，让"不那么聪明的 agent"也能做好。她自己几乎一个人完成的几次大规模迁移，过去需要一个团队几个月乃至几年。她再次用"米其林厨房"作比：她不再亲手做每道菜，而是用技能和重构"训练"出一支 agent 团队，自己像主厨一样摆盘、把控质量。主持人观察到，外界以为 agent 会让工程师失业，现实里需求却比以往更大；两人都认同，原型成本大降，但品味依然需要人。

关于接下来的计划，Roshan 说会根据大量测试反馈继续打磨 GrokBot，并继续在前沿模型上投入；Lauren 最关心性能和可靠性，还透露自己早期曾"偷偷黑进"过 iMessage 支持，可以直接给 bot 发短信。这是常见需求，团队在考虑之中，因为同事不该只能在 Slack 里找到。主持人还讲了个段子："agent 在站会上说自己周末请假了。"最后谈 Grok 4.6 的成绩：在 CursorBench 3.2 上，Grok 4.6 extra high 得分 70.8%，平均每个任务 2.81 美元；Fable 5 Max 得分 70.5%，却要 17.32 美元。Lauren 说她 token 不限量，但大多数用户和公司都很在意 AI 成本，一个和大模型一样好、价格只是零头的模型是很有吸引力的选择；她日常写代码大量使用 Grok，看重它又快又便宜，也照样会用 Fable 和 Sol。Roshan 说同样 20 美元预算，单任务成本降下来就能做更多事、开更多 bot，所以他们会在效率上大量投入，同时不放松智能。主持人的结论是：这对资源有限的创业公司和独立开发者是在拉平竞争场地。
