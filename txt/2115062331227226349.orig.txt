And as a reminder, with Claude Managed Agents, the agentic loop is running server-side. And a key architectural change has occurred. Previously, the agent loop and the tool execution used to happen in the same container where the agent was hosted. This meant that every single time you had to start an agent, there was a high latency cost, and there was a single point of failure: if the container went down, your agent loop went down. With Claude Managed Agents, the agent loop is separated from the actual sandbox — the brain, the model, is separated from the hands: from the tools, from the sandbox — because not every agent use case needs a sandbox, and it can be spun up only when needed. This is a critical architectural difference, because it allows us to scale way more quickly, and for you to have much lower latency and higher reliability.
