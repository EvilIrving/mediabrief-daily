科学家怎样使用 Claude，AI 又能让研究加速多少 ｜ Anthropic Research ｜ 文章 ｜ https://www.anthropic.com/research/how-researchers-use-claude

Anthropic 的这项研究把科学工作拆成具体任务，考察科学家在哪些环节使用 Claude，以及这些使用方式与 AI 的能力有什么关系，再用经济模型讨论研究可能加速多少。作者把实际使用、模型评估的理论能力、研究者的预期和假设情景分开处理：观察到某项任务经常使用 AI，不等于已经证明 AI 提高了该项研究的产出；加速倍数也不是对未来的预测。

科学曾被称为“无尽的前沿”，探索速度却一直受研究者的时间和能力限制。AlphaFold 对超过两亿个蛋白质结构的预测、GNoME 对三十八万个稳定新晶体的预测，以及 AI 在数学问题上的进展，展现了专门系统的潜力。但通常的科研成果由许多相互依赖的任务组成，AI 能否推动整个研究流程，既取决于技术能力，也取决于科研人员在哪里采用它。

研究使用保护隐私的分类流程。分类模型读取会话，只向研究团队保留预先定义的领域、任务等标签，不提取和储存研究数据、假设、实验方法、早期结果或未发表论文的开放式内容。结果只按汇总单元报告，而且每个单元必须达到最低独立账户数。第一道分类器判断会话是否属于科学工作，第二道再把它映射到 SciNet 的学科与任务体系。SciNet 包含三十四个领域、三百一十八个子领域和七千二百六十二项任务，既有各学科通用的论文写作，也有材料科学中预测吸收和发射光谱等专门任务。

主样本覆盖 2026 年 8 月 2 日至 9 月 30 日消费者套餐中的 207,049 次科研会话：128,914 次来自 Chat 和 Cowork，文章合称为 Claude；78,135 次来自 Claude Code。Claude Science 另有补充样本。它们不是全部科研活动的代表性普查，也不包括 Claude Code 的程序化使用。

使用量首先与学科规模相关，但人数解释不了所有差异。Claude 会话中，计算机科学占 11.9%，工程占 8.4%，医学占 7.7%；领域研究者人数与会话份额的双对数相关系数为 0.79。按研究者人数校正后，计算机、数学、统计等形式科学，以及社会科学，使用相对更密集；化学等依赖实验室的物理科学和需要接触患者的医学，使用相对较少。

Claude Code 更集中于定量研究，与领域人数的相关系数降至 0.62。计算机科学研究者只占全球研究者的 4.3%，却占 Claude Code 科研会话的 32.7%。子领域里的 AI 与机器学习也类似：研究者占比 1.2%，Claude 会话占比 5.0%，Claude Code 占比 15.2%。不论隶属哪个大领域，计算生物学、计算语言学、计算神经科学等计算型子领域都更积极采用 AI；机器人研究虽然面向物理系统，也因大量依赖计算方法而有较高使用量。全球人数基准排除了 Claude 尚不可用的国家。

再看任务，作者把科研分成数据分析、写作沟通、数据采集、阅读学习、理论分析、设计开发、构思与假设生成，以及研究管理等其他工作，并以 SciNet 估计的研究时间份额作基准。这里比较的是“会话份额”和“研究者时间份额”，不是直接测量工时节省。

数据分析最突出，占 Claude 科研会话的 33.7%、Claude Code 的 48.1%，高于研究时间中的 27.6%。写作沟通占 Claude 会话的 32.0%，是时间份额 16.0% 的两倍。数据采集占研究时间的 28.6%，却只占两种产品会话的 11.5% 和 11.9%；临床或生化采样等物理工作尤其少见，在线采集等纯数字任务则可能相对过度代表。构思和假设生成占研究时间的 7.1%，在 Claude 和 Claude Code 中分别仅占 4.2% 和 2.1%。单项任务里，起草论文最常见，分别占 18.6% 和 11.1%。

配套调查的 528 名研究者，主要来自生命与健康科学，也是积极采用 AI 的人。他们报告的使用模式与会话数据一致：分析、写作更常用 AI，也更常把工作交给 AI 或与它分担；但他们认为对重要发现最关键的任务，恰恰是构思和数据采集。数据采集有物理障碍，构思使用少则可能有不同原因：科学家愿意自己想问题，认为 AI 不够强，或构思本来就穿插在其他任务中，不容易单独分类。AI 也可能确实不擅长选择值得研究的问题、设计整个研究。

专门工具可能改变任务分布。Claude Science 把分散的科研数据库和工具连成流程，例如研究一种药物是否作用于某种蛋白质时，可以联用功能、结构、已测试化合物、临床试验和论文数据库。其会话超过一半来自生物医学和生物学。在这些领域，“提出蛋白质—蛋白质或蛋白质—配体相互作用的机制模型”出现的相对概率，是普通 Claude 的 5.6 倍；它需要把结构和结合数据综合成可检验的分子接触模型。构思占 Claude Science 会话的 8%，大致与研究者时间份额相当。

在生物学和生物医学的比较中，Claude Science 的工作如果没有 AI，需要的人类时间接近其他产品的两倍；超过 80% 的内容被估计需要博士水平训练，其他界面约为 50%—70%。超过 70% 的会话有较高 AI 自主性，Claude 为 23.7%，Claude Code 为 64.1%。作者同时提醒，选择 Claude Science 的人可能本来就有更复杂的需求，因此这些是产品间的使用模式差异，不能简单当作工具导致的因果效果。产出形态也随学科变化：人文、社会和健康科学更常形成文档、报告、论文，形式科学与自然科学更常形成代码、数据等技术产物；技术产物在 Claude Code 中约为 Claude 的两倍。

为研究使用与能力的关系，作者构建“理论 AI 能力”分数。SciNet 将任务继续拆成步骤，让模型两两比较：AI 不借助人类帮助时，哪一步的典型产出更接近有经验研究者愿意接受、无需大改的水平？再用 Bradley–Terry 模型汇总比较结果，得到步骤排序并聚合成任务分数。它衡量的是相对能力，不是每个任务都经过实际实验检验的成功率。

任务使用比定义为会话份额除以研究时间份额：一项工作占研究时间的 5%，占会话的 10%，使用比就是 2。能力最低的五分之一任务，例如纯化反应混合物、参与式观察，几乎不使用 Claude；中位能力附近使用比约为 1；能力最高的五分之一，例如数据可视化和统计检验，Claude 使用比约为 2，Claude Code 约为 4。科学家似乎主要在 AI 更能胜任的地方采用它。

能力差异又与任务能否适用强化学习密切相关。结果容易验证、可以在计算环境反复模拟、反馈快速而廉价的任务，更适合通过反复尝试学习。独立构建的强化学习适用性指数与能力分数相关系数为 0.78。认知工作与能力正相关，系数为 0.69；物理、人际和受监管限制的工作则分别为 −0.57、−0.31 和 −0.38。相同特征也能解释使用比差异。聚合到子领域，能力与人均使用量的相关系数分别为 0.45 和 0.57。健康科学使用仍低于能力分数所暗示的水平，可能受医疗数据法规和接入困难影响；更依赖文字、代码的学科则高于这一水平。理论能力较高的子领域，也更愿意让 AI 自主工作。

接着，作者用研究生产函数构建三种加速情景，只考虑 AI 接手已有工作、释放人类时间这条渠道，没有估计 AI 提出更好研究问题的价值。第一种假设现有能力广泛普及；第二、三种假设未来从能力最强的步骤开始，分别把 75% 和 100% 的非物理步骤完全自动化。三种情景都保留由人完成的物理环节。它们用于说明约束，不是时间表。

模型区分两个量：AI 份额是按现有时间分配，AI 可接手多少研究者时间；研究加速则是在预算不变、支付 AI 费用并重新安排人类工作之后，能多产出多少研究成果。第一种情景把调查中的不用、辅助、共同完成、委派、自主五种用法，分别映射为节省 0%、25%、50%、75%、100% 人类时间，并按理论能力把较高使用水平分给较强步骤。因为受访者本来就是重度用户，这个分布被当作现有能力充分采用时的参照，而不是普通科学家的平均现状。

科研任务被假设为互补：一个环节做得特别快，不能完全弥补另一个环节的不足。AI 降低某些步骤成本后，研究者会转向帮助较少的瓶颈，如提出问题、增加物理实验。费用假设是研究者每小时 95 美元，AI agent 每小时 30 美元；每节省一小时人类时间，AI 运行 0.2 小时。这是按公开标价作的示例参数，不是对实际平均消费或提供服务成本的测量。

在现有能力充分采用的情景下，AI 可接手各领域 27%—52% 的研究时间，中位数 38%。但加速倍数只有艺术 1.35、 人类学 1.36、化学 1.41，到计算机科学 1.96、统计 2.02。即便高度认知型学科，也大致止于两倍，因为目前 AI 多是辅助或共同工作，人仍需参与几乎每个步骤。农业、生物医学、化学和材料科学约有 38%—41% 的研究时间用于物理步骤，而各领域中位数只有 4%；物理份额解释约三分之一的 AI 份额差异。艺术和历史虽少有物理环节，却因认知步骤能力分数较低，收益仍受限。

如果 75% 的非物理步骤完全自动化，计算机科学约加速八倍，统计及图书馆与信息科学约七倍，经济学约六倍；多数其他社会科学、数学、物理和天文学约四至五倍，实验和医学类约二至三倍。艺术、人类学、历史大约两倍或更少。这里“75%”按步骤数量而不是按工时选取，所以自动化步骤可覆盖计算机科学 82% 的非物理时间，却只覆盖艺术的 28%。

如果所有非物理步骤都自动化，艺术人文的能力限制消失，统计、计算机、经济学、数学、心理学及许多社会与人文学科都可达到十五至十六倍；仍需大量实验室或田野工作的生物、化学、材料、农业及生物医学只有三至四倍。物理步骤会接管剩余的人类时间和预算，成为强瓶颈。对没有这类瓶颈的领域，模型里的上限来自 AI 费用：完全自动化任务约花原来人工成本的十六分之一；如果 AI 费用减半，上限可相应翻倍。

这些计算没有计入大型强子对撞机这类全学科共享设施的容量约束，没有计入实验设备和材料成本，也没有考虑模拟替代真实实验。它们还固定了研究质量：AI 如果提出更好的假设，收益可能更大；如果挑选重要问题始终依赖人类，收益可能更小。

研究者对未来的期望也不等同于这些估计。调查中，38% 认为 AI 的数据分析已经达到领域顶尖研究者水平，过半预计到 2027 年达到；到 2030 年，94% 预计数据分析达到，89% 预计写作达到，构思和数据采集各为 72%。约 40% 预计 2030 年前 AI 可以独立完成整个研究项目，约 64% 预计 2035 年前做到，但 16% 认为永远不会；对重大科学突破的完全自主产出则更谨慎，约一半认为要等到 2035 年以后，甚至不会发生。历史上许多 AI 预测偏保守，但涉及现实物理操作的实验室工作是例外之一。

讨论最后转向实现收益需要面对的制度与安全问题。技术能力通常先于普及，组织必须重构流程，个人学习、基础设施和访问限制都可能拖慢采用。物理实验和选择研究问题仍可能成为瓶颈。更容易生产论文，可能使成果数量暴增、超过人类吸收和验证的能力，也可能让更全面、更高质量的研究成为可能；方向取决于研究者与期刊、资助方、机构的激励。未来 AI 或许也参与审稿、验证、传播，甚至通过机器人和自动化实验室组成自主科研群体，这又要求人类能跟踪并理解新知识。

自主性提高还会加大目标对齐和双重用途风险，尤其生物学中促进医疗进步的能力，也可能产生危险知识或材料。在选题、方法等关键决定上保留人类，设置必要检查点，可能需要主动接受较慢的进展。研究职业本身也会改变：如果 AI 接手令人有成就感的任务，满意度可能下降；如果它接手繁琐事务，则可能上升。美国联邦资助项目的负责人报告，约 44% 的研究时间用于满足行政要求，减轻这类负担就可能带来显著收益。

官方附录补充了样本、分类器、调查和模型的技术细节。最初识别为科学工作的会话有 Claude 148,734 次、Claude Code 86,884 次；经过学科任务映射并限制到核心研究任务，才得到主文的 128,914 次和 78,135 次，不能把前后口径混在一起。采样按每小时、每产品固定数量进行，因此分析使用抽样概率的倒数加权。SciNet 还细分到 90,583 个任务步骤。分类器在五千份合成会话中的准确率，领域为 83%、子领域 74%、任务 69%、任务与子领域组合 58%；这些并非真实科研会话上有人工真值的精度。高置信与高贡献子样本的稳健性检查，仍得到类似总体模式。调查向 1,813 名资助申请者发出邀请，完成者为 528 人，具有选择性。

附录的额外分析还区分职业阶段：博士生最常把 Claude 用于数据分析，占 34.4%；教授最常用于写作沟通，占 44.0%。博士生用于阅读学习的会话占 8.8%，教授为 4.9%。按完整领域而不是子领域聚合，能力与人均使用量的相关系数为 Claude 0.52、Claude Code 0.55；它们不是主文子领域层面的 0.45 和 0.57。模型进一步明确，未来情景中未被新增自动化的步骤保留现有能力情景的辅助水平，AI 费用跨情景固定，产出质量参数设为 1；这些假设共同决定了所报告的倍数。
