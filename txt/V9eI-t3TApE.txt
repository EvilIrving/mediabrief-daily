这是张小珺商业访谈录对罗福莉的一期三个半小时长谈。罗福莉目前是小米大模型（MiMo）的负责人，此前在 DeepSeek 参与过 V2 和 R1 的研发，媒体常叫她“AI 天才少女”，她本人并不喜欢这个称呼。录制时间在 OpenClaw 爆火、小米发布 MiMo V2 系列（Pro、Omni、TTS）之后。全片可以看成一份“范式转变亲历报告”：她认为 2026 年春节前后，以 OpenClaw 为分界点，AI 已经从 Chat 时代进入 Agent 时代，研究、训练、组织的方式都要随之重写。她的语气始终很兴奋，自述过去两个月的生活状态就是“亢奋，还是亢奋”。

**一、OpenClaw 带来的冲击**

她一开始很排斥 OpenClaw，觉得它不过是“Claude Code 加一个即时通讯界面”，加上创始人那些偏营销、有点“玄幻”的运营动作，更像一个交互创新的产品。转变发生在春节：一天凌晨两点她装好它，一聊就聊到天亮。第一天感到的是“有灵魂”，它会提醒你太晚了该睡觉，背后其实是 Soul.md、每轮在上下文前拼上当前时间之类的精细编排；第二天她把日常难题交给它，和它讨论怎样筛选有好奇心的人、怎样搭建大模型团队，它把讨论沉淀成了一套 Skills，成了她在管理问题上的“数字分身”；第三天她把研究任务交给它，一两个小时就做出了一个可用的 User Agent（模拟用户与 Agent 多轮交互，用于造后训练数据），这本是她以为要做很久的研究课题。

她拆解了 OpenClaw 相比 Claude Code 的优势：分层分级的持久记忆、更多消息通道、定时与心跳任务这类适合日常生活的主动机制，以及会自己找合适的模型去补齐当前模型的短板，比如收到视频就去调一个视频理解能力强的模型。单拎出来每一点都“有点 boring”，但整合起来完成度极高。最关键的是它开源：Claude Code 的记忆系统、工作流都是黑盒，OpenClaw 却可以随便改。她花了几天让 Claude Opus 4.6 帮她重新设计记忆系统和混乱的多 Agent 逻辑，改好之后再接 Sonnet、国产模型乃至 MiMo，甚至一个 3B 的端侧小模型，都表现得出乎意料。她由此得出几个判断：精巧的 Agent 框架能大幅弥补模型短板，让“中层模型”在 85% 的日常和提效场景里接近 Claude Sonnet 的水准；上限仍由顶尖模型决定，所以顶尖模型和顶尖框架应当一起进化。她把 Agent 框架定义为人与模型之间的“厚中间层”，作用是弥补模型“行动上的缺陷”，前端界面反而是最薄的一层。高强度使用的第一天，她就烧掉了快 1000 美元的 Opus。

春节后她要求团队全员使用，放话“第二天对话不满 100 轮的人可以直接走”，实际上从没考核，只是想表达“不用就要落后”的态度。她买了几台 Mac Mini 统一部署，把近百人拉进飞书大群一起玩、一起改框架，理由是个人想象力有限，看到别人能用它做成什么，想象力会成倍放大。两天后大家从玩转向研究：怎样借好的框架提升模型，又怎样让模型反过来改变框架。她说，过去三四十周的研究工作，这次三四周就做完了。

她也解释了 OpenClaw 为何在中国比在美国更火（所谓“西虾东养”）：中国开发者对效率提升的需求更迫切，国产模型又便宜好用，花 10 块钱的 API 就能干 1000 块钱的活；而湾区模型公司的人似乎不太在意它。她认为去年人们口中的 Agent 大多不算真正的 Agent，SWE-bench、BrowseComp 之类评测的框架太简单也太专门，在上面刷高分的模型接进 Claude Code 或 OpenClaw 根本不可用，所以这一版模型她们几乎完全放弃了这些 Benchmark，在范式剧变的窗口期“靠体感”判断。Skills 的价值在于把企业内部、组织沉淀下来、预训练数据里不可能有的规范教给 Agent，是对预训练的补充，也是“群体智能”的入口。她判断“OpenClaw 时刻”会比“ChatGPT 时刻”“DeepSeek 时刻”持续得更久、影响更深；OpenClaw 后来并入 OpenAI，但开源属性没变，群体共同进化的“火种”也就保留了下来。

**二、MiMo V2 系列的技术取舍**

Flash 和 Pro 是同期训练的，结构相近。设计时唯一的目标是“长上下文的效果与推理效率”：成本够低、速度够快，才可能把上下文从一兆推到十兆、百兆。当时 Kimi、GLM-5 等同期模型都沿用 DeepSeek 的 MLA，她认为 MLA 是 Chat 时代的优秀结构，但它已把计算和访存的比例压到恰好平衡的临界点，再加 MTP（多 token 预测）做投机解码就会卡在计算瓶颈上，所以这些模型都偏慢。MiMo 选择了混合注意力：滑动窗口层与全注意力层混用，Flash 是 5:1，Pro 拉到 7:1，以此节省 KV Cache，再用 MTP 把省下的算力填上，实现访存与计算的平衡，于是 Flash 能跑到每秒 100 到 150 个 token，Pro 能跑到 60 到 100 个。MTP 原本是为了提升基座能力而在预训练里加的，后来在设计推理方案时才发现计算余量大得出奇，正好拿来加速，属于“很后验”的发现。她的实验结论是：全注意力层的总层数比比例更重要，模型越大就能承受越高的稀疏度。

她认为模型结构设计现在有两条路。一条是像 MLA 那样，预训练时就想清楚推理的芯片、场景和并行方式，做出针对性的完美结构；但它隐含两个前提，一是后训练不重要、时间很短，二是推理卡长期不变，而在 Agent 时代，后训练周期拉长到半年甚至一年，前提会失效。另一条是结构更简洁、留足余量，让后训练有更大的发挥空间，MiMo 走的是后者。定价上，Flash 当时每百万 token 输入 0.1 美元、输出 0.3 美元，是按推理成本定价；到了 Pro，她认为应该按模型最终创造的价值定价，因为后训练对 Agent 框架的理解本身就有溢价。

她坚信要在 Agent 上接近 Claude Opus 4.6 的水平，1T 以上的总参数是“入场券”，再加上后训练的敏捷性；国内目前还没有哪家同时具备两者，“看看 DeepSeek 吧”。训练 1T 模型时几千卡就够，但研究用卡应该是训练卡的三到五倍；她给出的合理比例是研究、预训练、后训练 3:1:1，而 Chat 时代预训练远多于后训练，现在顶尖团队都已接近 1:1。在 Agent 范式下，写代码验证想法太快了，真正的瓶颈变成了卡。训练 1T 模型最难的是数值不稳定，比如 loss spike、激活值异常、专家负载极端失衡。很多团队把 loss spike 当正常现象，她们则坚持停下来查，最长停过两周，从结构、通信算子、norm 一路排查到怀疑“太阳黑子”，必要时借鉴 Kimi 的 QK-Clip。她说之所以能这样，是因为没有发布 deadline，MiMo 和 MiClaw 在小米内部都是按创业方式运作的，雷军给了充分信任。

Omni 是全模态模型，支持音视频联合理解，同时具备接近语言模型水平的 Agent 能力。她说它比 Pro 小，但在对世界的感知、情商和知识上体感更强，只是在任何 Benchmark 上都“纹丝不动”，所以她不愿断言多模态理解是通往 AGI 的必经之路，反而猜测“生成”才可能促进智能。TTS 采用另类的离散化路线，用多层残差向量量化（RVQ）把音频变成像文本一样的离散 token，再统一进语言模型框架。这源于团队里一群 NLP 出身的人的“执念”。结果是泛化很好：只用快慢、喜怒等少数刻板风格做过后训练，却能遵循复杂的自然语言风格描述，不过下限还不稳定。图像的离散化还在尝试。她也坦言，有了 Claude Code，两三周就能重写一套 RL 框架，为了基础设施的统一而牺牲模型结构已经不划算了。三个模型分工明确：Pro 负责认知与调度，Omni 负责感知，TTS 负责表达，目的是在 Agent 框架里像人的各种感官一样被编排起来。至于为什么不合成一个模型，是出于成本和速度考虑。Pro 正式发布前曾以匿名模型上线 OpenRouter，外部反馈与内部评估基本一致，唯一的大收获是发现长文本训练不足，随后集中补强。

**三、三年回顾与行业格局**

她这样梳理这几年：2022 年 ChatGPT 在 4K 的短上下文里通过对话把预训练的智能激发出来；2023 年开源界追赶闭源，Qwen 借 Llama 的架构纯粹做规模化和全尺寸生态，DeepSeek 则先研究 Llama 结构的问题，在算力只有几分之一的条件下用 MoE 和 MLA 做创新再扩展，两条路都对，也彼此成就；2024 年最出人意料的是 o1 和 R1。她在 DeepSeek 时看到 R1 的轻量版已在代码和数学上接近 o1-mini，最大的体会是范式切换时团队必须重新组织，只靠“加算力、外挖一个后训练团队”是错的；她没想到的是，推理能力能从代码和数学泛化到通用领域。此后她遇到看似垂直的东西，都会先问是不是自己把它想小了。2025 年是“交错的一年”：可以继续在 Chat 范式里刷 AIME 和代码榜，也可以转向 Agent。MiniMax 转得最早，用激活约 10B 的模型做出了惊艳的 Agent 能力。MiMo 的第一代 Flash 还在打 Chat 的基础，因为团队成员大多没训过大模型，需要把整个历程走一遍来成长。

代码之所以在每个范式里都是主线，是因为能达到 128K 到一兆长度的数据基本只有代码和书籍，而代码文件之间的关联远比书籍紧密；到了推理阶段，代码可以验证；到了 Agent 阶段，代码有现成的环境，软件开发本身就是超长程任务。她的说法是：代码拉高上限，其他领域保住下限。Agent 时代的 RL 不再以推理引擎的 Rollout 为中心，而是以 Agent 为中心，要兼容快速变化的框架，容忍中途断掉的轨迹、训练与推理的不一致，还要调度 GPU、CPU 和存储等异构资源，所以 RL Infra 和预训练 Infra 是两种气质的人在做。真正把 Agent RL 规模化到与预训练同一量级的团队极少，她认为 Anthropic 做到了。她判断国内 1T 级基座与 Claude Opus 4.6 只差两三个月，接下来几个月比拼的是研究敏捷度；推理需求将暴涨数倍到十倍，存储会成为卡点；而半年后谁领先，取决于此刻对下一步扩展什么、在什么芯片上扩展的决策，这些她都表示要保密。

**四、组织与个人**

MiMo 团队约百人，包括大量实习生，真正投入一代模型迭代的只有二三十人。团队不分组、没有职级，只有推动项目的人，而没有掌控者。她认为层级本身就压制创造力，也不该默认上层的人更聪明。预训练出身的人转做后训练很自然，因为他们天然在意数据多样性和数据直觉。她选人看三点：基础扎实、好奇心强、热爱驱动，并越来越重视多样性。她招了不少大二、大三的本科生，认为他们对 Agent 范式的想象力“没有被污染”；在她看来，环境比经验更重要，大模型训练的能力一两个月、最多三四个月就能学会，就像模型之间互相蒸馏长处。钱是基线，但意义感同样关键。后训练中最适应的有两类人：爱跟模型玩、维护私有测试集去探边界的人，以及能接受模糊和容错的 RL Infra 人才。

她给出的几个判断相当激进。她最大的冲击是发现 Agent 能复原她的科研成长路径，讨论问题时“跟你一样聪明”，她相信“AI 训练 AI”、自我迭代会在一两年内发生；两个月前她觉得 AGI 至少还要两年以上，现在认为两年以内，进度已到 20%，今年能到六七成。工作模式会先被颠覆，生活靠机器人会更晚。当前的 Multi-Agent 在她看来“有点伪”，能省时间和成本，却还没抬高上限。她坚持开源加速 AGI：从终局倒推，算力和推理必然分散，不可能由一家公司包揽。她已经不怎么看论文，也不想在团队的论文上署名，信息主要来自“自迭代”和团队内部的交流。她做量化时的心法是“总有方式去建模价格”，到了大模型领域，奖励信号不再清晰，她的准则变成做符合自己价值观、让世界更好一点的事；她甚至设想，等工作被替代 90% 之后，做一个支持基础研究的公益组织。谈到减压，她说自己的脑子像“滑动窗口注意力”，忘得很快，睡一觉就过去了。她每天早上 11 点开始工作，常常到凌晨三四点，只需要睡四到六个小时。
