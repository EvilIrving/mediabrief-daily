谁在害怕中国模型？
Ben Thompson ｜ Stratechery ｜ 2026-07-20

我常讲一个故事，关于我在凯洛格管理学院上 STRT-431 第一天的经历。那是每个一年级 MBA 学生必修的入门课。我翻看了阅读材料和案例，失望地发现课表上没有一家科技公司。我就是我，下课后去找教授问为什么，得到的回答是：这门课的目标不一定是了解具体行业，而是揭示普遍适用的原理，可以应用于任何行业的任何公司。

按我通常讲这个故事的说法，我对这个回答并不满意：在我看来，科技的本质——尤其是软件和分发的边际成本为零（交易成本也为零）——是一种根本不同的东西；往公式里代入零，往往会把一切搞得一团糟！不过我很快意识到，这正是我的机会。支撑“聚合理论”（Aggregation Theory）的根本洞见是：零边际成本导致的价值链，与人们曾经对互联网的期待截然不同——在一个控制需求比分发供给更重要的世界里，出现的是集中化和规模化。

然而，AI 的迷人之处在于，那些古老的普遍原理正在多大程度上重新回到舞台中央。这一点在刚过去的这个周末表现得再明显不过：X 上围绕 Kimi K3 的影响爆发了激烈争论。Kimi K3 是又一个来自中国的开源权重模型，其能力已接近业界最先进水平。归根结底一句话：边际成本强势回归了，无论是从最先进的免费模型的短期影响来看，还是从行业的长期结构来看。

### 销货成本与研发

关于开源权重模型的讨论中，最常见的误解之一是它们更便宜——甚至是免费的。毕竟，你可以直接下载权重，省去打造自有模型所需的时间、费用和能力。这当然没错，但这里的“免费”指的是你需要在研发上花的钱；研发是一项固定支出，与你创造的收入无关。如果你在研发上花了 100 万美元，那么无论你的收入是 10 万美元还是 1 亿美元，你在研发上都花了 100 万美元（当然，这会影响你的盈利能力）。

与收入相关的是 COGS——销货成本。而在 AI 领域，COGS 是实实在在的，这在软件行业已经很久没有出现过了。具体来说，在模型上运行推理——不论这个模型是 Kimi 还是 Fable——都要花钱，而 AI 提供商在推理上花的钱，至少在大多数商业模式中，与收入直接相关。沿用上面的例子，创造 1 亿美元收入与创造 10 万美元收入相比，很可能需要 1000 倍的 COGS。具体来说，如果生成带来 1 美元收入的 token 需要花 50 美分，那么 1 亿美元的收入就有 5000 万美元的 COGS；10 万美元的收入只有 5 万美元的 COGS。

就开源权重模型而言，要点在于：提供它们的服务并不是免费的。Kimi K3 每百万输入 token 收费 3 美元，每百万输出 token 收费 15 美元；这比 Sol 的每百万输入 token 5 美元、每百万输出 token 30 美元便宜，但这甚至可能不是正确的衡量方式。

### Token 与智能

英伟达 CEO 黄仁勋把英伟达正在打造的东西称为“token 工厂”，从英伟达的角度看，这种框架是合理的。英伟达 GPU 不挑模型：它们生成 token，并以最快、最高效的方式生成。这就引出了每秒 token 数、首 token 延迟、每瓦 token 数、token 成本等衡量指标，黄仁勋认为这些指标将成为决策的依据。

在 AI 的第一个范式——ChatGPT 时代，token 直接交付给终端用户——这种框架确实说得通。然而，AI 的第二个范式——推理时代——让这种衡量方式失灵了。推理意味着思维链 token 的爆炸式增长，而不同模型需要不同数量的推理 token 才能得出正确答案。例如，据报道 Kimi 使用的 token 明显多于 Sol，这使它的价格优势变得无关紧要。智能体也带来了类似的动态：在执行智能体工作流所需的 token 数量上，一些模型比另一些更高效。

这意味着 token *不是*大宗商品。大宗商品的决定性特征是可互换性：一加仑石油就是一加仑石油；一吨铜就是一吨铜；一蒲式耳小麦就是一蒲式耳小麦。然而，一个模型的 token 与另一个模型的 token 并不相同。可以互换的是由 token 构建出来的东西，也就是智能。换句话说，如果 Kimi 和 Sol 都生成了正确答案，那么这个答案是可互换的；而为得出这个正确答案所生成的 token 数量差异，则是造成 COGS 差异的因素之一。

智能的 COGS 取决于以下几个因素：

- 模型体量：权重和运行时状态决定了每个服务副本需要多少昂贵的内存和多少加速器。
- 推理效率：架构选择（例如混合专家模型 MoE）减少了每生成一个 token 所需的计算量。
- 显存效率：架构选择可以降低 KV 缓存需求，从而支持更多并发请求，提高 GPU 利用率。
- 服务效率：批处理、调度、前缀缓存及其他推理优化手段可以最大化利用率，并在请求之间共享工作。
- Token 效率：得出正确答案所需的 token 越少，推理成本越低。

这之所以重要，是因为我们正在迅速接近这样一种状态：对于许多有经济价值的任务而言，智能实际上就是一种大宗商品。比如，任何人要构建一个基础的 CRUD 应用，很可能都可以使用多家提供商的模型来完成。而在大宗商品市场中，盈利之道不在于收取更高的价格——再说一遍，你可以（或很快就能）用多个模型做出一模一样的应用——而在于拥有更优的成本结构。

### 理解大宗商品市场

这里的机制值得逐步梳理，因为正如我几个月前在《亚马逊的持久力》一文中指出的，科技行业的人一般不熟悉大宗商品市场的动态：

- 在大宗商品市场中，所有人收取相同的价格，因为所有人卖的是同样的东西；这个价格由供求决定。
- 大宗商品的需求取决于价格弹性：商品越便宜，需求越大，反之亦然。
- 大宗商品的供给取决于生产该商品的边际成本。

需要理解的关键是，生产该商品的边际成本因供应商而异。这在实践中意味着，成本结构最差的供应商最终会以其边际成本出售商品（如果它还能生产的话）；其他所有人的利润，取决于他们的成本结构比这家边际供应商好多少。

举个例子：

- 供应商 A 能以每单位 10 美元的成本生产 10 单位商品
- 供应商 B 能以每单位 15 美元的成本生产 10 单位商品
- 供应商 C 能以每单位 20 美元的成本生产 10 单位商品

假设价格弹性使得在 20 美元的价格下，该商品的需求为 25 单位。这意味着：

- 供应商 A 将以 20 美元的价格卖出 10 单位，每单位赚 10 美元
- 供应商 B 将以 20 美元的价格卖出 10 单位，每单位赚 5 美元
- 供应商 C 将以 20 美元的价格卖出 5 单位，每单位赚 0 美元

这并不完全准确：供应商 C 之所以承担缺口，是因为供应商 A 和 B 能够在价格上略微压低它，而这当然会影响需求（需求是有弹性的），但这足以说明问题。供应商 A 的生意很棒，供应商 B 的生意不错，供应商 C 则会破产。

破产风险正是固定成本重新回到舞台中央的地方：供应商 C 既有固定成本（比如可能的研发支出），也可能为购置生产该商品所需的设备而背负了债务。它无法把这些成本考虑进商品定价——记住，市场出清价格近似于满足需求所需的最高成本单位的边际成本——但这些成本绝对可能把这家供应商逼出市场。而如果这家供应商倒闭了，价格就会上涨，直到另一家供应商决定进入（或其他供应商扩产）。

### 智能市场

我们回到模型上来。眼下，上述分析都不适用，因为前沿模型供不应求，而供给受限于算力的匮乏。这种算力短缺不仅意味着英伟达这样的算力供应商能获得极高的利润率，也意味着英伟达的客户，比如 SpaceXAI，可以转手以高利润率把算力转售给 Anthropic 这样的公司。与此同时，Anthropic 之所以能付得起这笔加价，是因为它能以更高的加价出售 token。

不过，给 Anthropic 带来高利润率的不只是过剩的需求：凭借模型能力、服务规模和 token 效率，Anthropic 和 OpenAI 很可能拥有最低的单位前沿级智能成本之一。它们在竞争对手之前就以特定能力水平提供模型长达数月，同时又在用最好的模型来优化这些成本。

同样值得注意的是，市场尚未把智能当作大宗商品对待：需求特别针对 Anthropic 和 OpenAI，对没那么好的模型需求要少得多（因此 SpaceXAI 和 Meta 才把产能卖给 Anthropic）；对推动成本优化的一种理解是，它是按智能水平来定义“待完成任务”的结果，这样智能的买家就能创造出一个智能被商品化的市场。然而从长远看，谁处在前沿，谁也就最有条件主导非前沿市场——非前沿市场不过是“前沿减去 n 个月”，也就是前沿模型厂商一直在优化其服务成本的那几个月。

说了这么多，我想表达的是：我认为对 Kimi 以及整体上对中国模型的反应相当夸张，至少从经济角度看是如此。眼下存在一把由算力短缺带来的价格保护伞；我非常怀疑中国模型在边际成本基础上真的服务起来更便宜，它们只是看起来更便宜，因为 Anthropic 和 OpenAI 的供给受限如此严重，以至于它们的收费远高于有足够供给来满足智能需求时的水平。

### 前沿实验室的偏执

那么，为什么偏偏是模型厂商对中国模型显得如此惊慌？

首先，我认为前沿实验室的思维还锚定在训练成本主导财务模型的世界里。只要训练消耗的 GPU 多于推理，最大化推理收入以帮助资助下一轮训练就至关重要，而这意味着对推理收取非常高的价格。

然而展望未来，我预计推理市场的增长将远远快于训练成本（这已经包含了训练成本会继续飙升的假设），这意味着它们真的可以以量取胜。仅仅八个月前，情况还不明朗，但智能体范式带来的解锁是如此巨大，前沿实验室应该更有信心：（一旦拥有足够的算力）它们不仅能在更低的价格下生存，还能蓬勃发展。

其次，智能实际上并不是完美的大宗商品，部分原因在于被应用的智能会让自己变得更聪明。具体来说，谁在运行推理，谁也就在收集数据，而这些数据会被用来让下一代模型变得更好。一方面，这更有理由让前沿实验室随着更多算力上线而降价、扩大使用量；另一方面，这也是微软等公司越来越热衷于帮助企业运行自有模型的原因。如果中国模型是一个可行的替代品，这条路就可行得多。

第三，前沿实验室不仅能与中国模型、还能彼此之间形成差异化的另一种方式，是继续向上整合到客户体验中。Claude Code 和 Codex 展现出的黏性令人瞩目；你开始用哪个工具框架，很可能就会一直用下去，而对非技术用户而言，这一点预计会更加明显。从长远看，这种向技术栈上层移动的必然要求，确实意味着前沿模型对软件提供商——包括微软——构成绝对的威胁。反过来说，目前掌握客户体验的软件公司能在多大程度上获得有竞争力的模型，就决定了它们能在多大程度上抵御前沿实验室的侵蚀。

最后，尤其是 Anthropic 的意识形态角度不容忽视。这是一家相信只有自己才能被托付 AI 的公司，而开源权重替代品的存在，对这一假设构成了致命打击。

### 中国的动机

Kimi 并不是唯一的中国新模型；来自彭博社的报道：

> 阿里巴巴集团控股有限公司股价周一一度上涨 5.4%，此前该公司推出了旗舰模型 Qwen3.8 Max 的预览版，称其仅次于 Anthropic PBC 的 Fable 5。这次周日的发布距离初创公司月之暗面（Moonshot AI）推出一款强大的新产品仅过去几天，那款产品搅动了市场，并在美国引发了对中国正在缩小与 Anthropic、OpenAI 等全球领先者差距的担忧。Qwen3.8 Max 拥有 2.4 万亿参数，与月之暗面的 Kimi K3 一同跻身重量级行列。K3 拥有 2.8 万亿参数，可与顶级产品匹敌，阿里巴巴也在设定同样高的期望。
>
> 开发者现在可以通过阿里巴巴的编程平台（包括 Qoder）使用 Qwen3.8 Max。阿里巴巴计划很快开放该模型的权重，将访问范围扩大到预览版之外。人们对这些中国制造的人工智能系统和模型兴趣如此之高，以至于月之暗面在周日深夜被迫暂停接受新订阅，以应对汹涌的需求。

Qwen3.8 Max 也将开放权重，这一点值得注意。阿里巴巴今年早些时候停止了发布其最前沿模型的权重，但似乎已经撤回了这一改变；我猜测这一转变与上周习近平关于 AI 的讲话有关，那次讲话加码了开源权重路线：

> 我们要坚持开放共赢，推动创新发展。人工智能作为世界经济增长的新引擎、新旧动能转换的加速器，正在从数字世界走向物理世界。我们要抓住这一难得的历史机遇，鼓励开源开放、协作共享，推动人工智能技术创新、产业发展和场景应用，统筹推进传统产业转型升级、新兴产业培育壮大、未来产业前瞻布局，让各行各业都能从人工智能中受益。

（注：此段为据英文转述回译，非讲话原文。）

中国的战略显而易见：把你的互补品商品化。注意，习近平明确把开放与 AI“从数字世界走向物理世界”联系在一起；物理世界是中国占主导地位的世界，而中国在机器人等领域的领先将从广泛可得的 AI 模型中获益巨大。

同理，中国不希望美国在 AI 领域获得不对称优势；中国越是能削弱美国前沿实验室、同时增强美国所有潜在对手就越好，而且它还能从依附于开放生态的创新中获益。

### 蒸馏问题

出于同样的原因，别指望中国会对针对前沿实验室的蒸馏攻击采取任何行动。我认为把中国实验室的全部成功都归因于蒸馏是错误的，但假装蒸馏没有给中国实验室带来巨大优势也同样是错误的。在过去一年里，随着后训练强化学习对模型性能变得越来越关键，这一优势真正显现出来。中国实验室不必从零开始搭建强化学习环境，而是可以直接把前沿实验室的模型当作老师，以低得多的成本实现快速提升（这不是中国模型开发成本更低的唯一原因，但是一个重要原因）。

有意思的是，中国模型在西方最重要的用途之一，恰恰就是蒸馏。例如，刚刚发布了一款开源权重模型的 Thinking Machines，就依赖中国模型来解决强化学习的冷启动问题。红杉资本的 Dean Meyer 和 Konstantine Buhler 在 X 上写了一篇出色的文章，解释蒸馏为何意味着西方开源权重模型相对于中国处于根本劣势：

> 蒸馏并不能解释中国在开源模型上的全部领先。中国实验室拥有世界级的研究人员、可观的算力、强大的预训练模型、软硬件协同设计，以及快速提升的后训练能力。但蒸馏压缩了从强大基座到接近前沿系统之间那段代价高昂的最后差距。即使蒸馏在中国模型总体能力中所占的份额较小，它在中国模型相对于美国开源模型的优势中也占了相当大的份额。
>
> 新的执法机制将让中国公司的大规模蒸馏变得更难、更慢、更昂贵。然而，执法无法消除有国家行为体支持的蒸馏。因此，西方的每一次前沿进展都为中国实验室创造了又一个老师。西方的构建者要么独立复现这些能力，要么等着向中国模型学习。这一差距给了中国实验室相对于西方公司一种反复出现的结构性优势。

这一点值得反复强调：由于美国的开源权重模型厂商必须遵守前沿实验室的服务条款，它们（1）比中国的替代品差，而且（2）最终是在“蒸馏蒸馏的结果”，只不过绕道经过了中国实验室。如果西方开源权重模型厂商能够直接从源头学习，岂不是更好？

为此，关于蒸馏还有一个更有意思的问题：它到底为什么是坏事？毕竟，大语言模型不就是对开放互联网上全部知识的蒸馏吗？这些知识被前沿实验室抓取，蒸馏进模型，而这些模型本身又在被蒸馏。到底是谁受了委屈？

事实上，这个悖论就是答案。我相信开源权重模型有利于创新（而且如上所述，我认为处在前沿的实验室会没事的），但依赖中国是个问题。美国应该通过一项法律：（1）明确规定为训练模型而收集数据属于合理使用；（2）至少对美国公司，禁止在服务条款中禁止蒸馏。阻止蒸馏——它实际上就是查询 API——几乎是不可能的；美国应该反其道而行之，拥抱一种新的版权政策，既为实验室免除责任，也保证它们学到的东西能为其他所有人的进一步创新提供燃料。

### 值得害怕的理由

整篇文章都在试图化解对 Kimi K3 具体而言、以及对中国开源权重模型总体而言的过度反应；然而，有一个理由值得担忧，那就是网络安全。看看 The Stack 的这篇报道：

> Hugging Face 表示，其生产基础设施在上周早些时候遭到一个“自主”AI 智能体系统的入侵。该平台的安全团队称，他们的事件响应（IR）最初受阻于某些未具名的美国大语言模型前沿模型的护栏，这些护栏“无法区分事件响应者和攻击者”。于是 Hugging Face 的防守者转而使用中国智谱 Z.ai 实验室的开源模型 GLM 5.2——在自己的基础设施上运行它，来分析攻击者留下的 17,000 多条日志或足迹。
>
> 对于总部位于纽约的 Hugging Face 来说，这是一次引人注目的公开承认。该平台让用户在模型、数据集和应用上协作，今年夏天年经常性收入（ARR）达到了 1 亿美元。在一份事件报告中，该公司建议防守者“在事件发生之前，就准备好一个经过审查、可以在你自己的基础设施上运行的强大模型（斜体为我们所加），既是为了避免被护栏拒之门外，也是为了防止攻击者的数据和凭证离开你的环境”。

特朗普政府对 Anthropic 发布 Fable 的恐慌式反应错得有多离谱，怎么说都不为过，尤其是它加剧了 Anthropic 最糟糕的倾向——认为只有自己才能被托付强大的 AI。在一个只有一种 AI 的世界里，把最强大的网络安全能力留给美国政府和可信盟友或许是合理的；但我们并不生活在那样的世界里。

现在和将来都会有完全有能力对现有基础设施发动网络攻击的模型，而这些模型将会——实际上已经——广泛可得。最好的防御——事实上也是唯一可行的防御——是确保防守者也能用上最好的模型。眼下，由于特朗普政府的指令，防守者实际上被禁止使用 Fable 或 Sol 来做网络安全；这意味着最好的替代方案，是使用一个多年来一直试图削弱我们网络防御的国家的模型。这简直疯了！

更好的路径很清楚：第一，放宽对 Fable 和 Sol 在网络安全方面的限制；第二，确保美国开源权重模型厂商与中国处在公平的竞争环境中。是的，前沿实验室会对此大吵大闹，但政府应该意识到，听信它们的歇斯底里，已经让美国陷入了美国公司依赖中国来进行防御的境地。让前沿实验室靠做得更好来取胜；不要让它们来定义安全，也不要让它们抽走人类集体知识的梯子。与中国竞争本就够难了；让中国扛起开放与创新的大旗，无异于拱手让出我们最大的优势。
